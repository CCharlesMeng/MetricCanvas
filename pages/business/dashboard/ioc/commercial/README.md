# 合同商务看板

## 合同商务总览

入口 `/pages/contract-business-overview`。[页面 JSON](contract-business-overview.json)。选择全球或清空区域时检查地区部指标明细，选择地区部时检查所属代表处，选择代表处时检查所选代表处。从地区部或代表处清空后刷新，表格仍按地区部展示。正文共用六张指标卡。当前地图和七列表格使用同一份 DQE 组织明细，包含测算销毛与核算销毛偏差和代表处 SDT 决策时长。普通 Playground 需要接入业务 DQE 和 IOC Region 候选；本地合同总览预览可以使用合成候选与 DQE Sim。

悬浮地图点位检查大标题和四行指标。净商务折扣、净付费金额各与同比同排，随后是框架执行率和测算销毛与核算销毛偏差。点位名称后用 400 字重显示净商务折扣。顶部折扣卡与地图折扣均用同比。提示数值默认黑色，正向变化用绿色、负向变化用红色。通过 Playground 浏览器用例延迟折扣、毛利率成员，核对组织行先显示点位，折扣回来后追加标签数值，毛利率差最后补齐。用例使用合成 HTTP 响应。

选择地区部后，检查代表处图钉位于名称框内左侧。从名称框点选代表处，页头区域与地图镜头一同切换。本地预览仅为地区部提供显式视口。代表处选中后按底图边界自动取景。可用中国地区部和上海代表处验收中国底图聚焦，用拉美地区部和巴西代表处验收世界底图聚焦。

点击五张指标卡的主指标检查目标地址与统计期间。全球和地区部使用既有业务结果指标、行权效率和行权规范入口。代表处的净商务折扣、框架执行率、决策意见闭环率和重大／高风险合同率进入 `/pages/rep-business-result`，并通过 `business-result-tab` 定位对应页签；SDT 决策时长进入 `/pages/rep-office-execution-efficiency`。测算销毛与核算销毛偏差只展示数值。普通点击与新标签页应携带相同参数。模拟结果只用于检查本地交互。

统计期间链接只传期间值。「近一年」由目标页按自己的定稿月计算；目标页缺少可用定稿日期时按当前月计算。明确选择的年、季、月以期间值传入，目标页应用自己的时间边界。

宽屏下右表约为 1.6 张指标卡宽。点击表格右上角放大按钮后，表格占满整行、同行地图收起。再次点击恢复并排布局。

## 商务决策明细：审批人下钻筛选

页面：`business-decision-all-details.json`，沿用户提供的业务 JSON 局部修改。主目标是 URL 查询参数 `approver-name` 经主表的 `paramBindings` 下推到 DQE 字段 `审批人姓名`；它不是维度候选筛选器，商务基本信息补列不消费它。标题继续读取同一个参数。

入口：`/pages/business-decision-all-details?approver-name=合成审批人甲&mtime=month:2026-11`。

本地预览使用 DQE Sim 的合成数据，页面不包含 inline、initial 或专用模拟开关。在当前工作树分别启动：

```sh
DQE_SIM_PORT=18387 pnpm --filter @metriccanvas/dqe-sim dev
DQE_SIM_PORT=18387 pnpm --filter playground dev --host 127.0.0.1 --port 5187 --strictPort
```

浏览器 Network 过滤 `execute` 后刷新，可检查对象主表请求的 `filter.fields` 含 `审批人姓名 = 合成审批人甲`，补列只带原有区域／代表处业务条件及商务 ID 关联条件。没有独立审批人候选查询。组织树候选由 Playground 复用现有 IOC Region 合成候选 Adapter 提供，业务数据仍经标准 execute HTTP 查询 Sim。

验收：甲共24条；将参数改成乙共6条；无匹配姓名显示空结果；省略参数共30条。原有期间、区域、搜索、商务类型筛选、导出和本地完整关联分页保留。IOC Header 承接标题、期间、单选组织树及原说明。根据用户最新收口重点，本轮不切换后端分页，也不添加未经真实数据上下文确认的记录唯一字段。

此页需包含记录成员独立消费参数修复的引擎／校验器。生产 DQE 字段、权限、数据与稳定分页未由 Sim 证明。浏览器证据见 `docs/evidence/2026-11-02-record-join-query-params/business-page/`。

商务类型使用6.80列声明 `enumValues`：字符串0显示项目商务框架，字符串1显示项目非框架；表头是前端完整枚举，不请求动态候选，筛选仍提交原编码。单元格与Excel均显示中文。需要本轮支持列枚举的引擎；此能力不改变审批人参数或既有分页。

合同商务总览地理资料由 Operation Map 统一接入，部署时同步提供 regionDepartment 展示事实。详见 [OM 地图接入](../../../../../docs/operation-map-geography.md)。
