## 伙伴健康度本地模拟验收

主项目运行 `pnpm --filter playground dev --port 5193 --strictPort` 后访问 `/pages/partner-health`。该页面在页面试验场默认使用专属模拟网关，顶部黄色提示标明模拟性质；无需业务DQE、凭据或浏览器拦截脚本。页面JSON及其真实查询声明不内嵌模拟值。其他页面和平台继续使用各自原有网关。

默认中国区顶部总分81.3，切海外为70.8；Chart按地区部/代表处切换。下表默认列出4个地区部，独立切至代表处后有8行。共享区域筛选可选择中国区/海外、地区部或具体代表处；先切顶部“海外”，再在地区部层级选“亚太地区部”，顶部总分78.6，下方代表处表格只剩新加坡、泰国。统计日期切换后预设分数会变化。广州代表处包含部分缺项；智利代表处（全缺项示例）全部子项与总分为0。无命中范围显示无数据。

模拟网关返回原始queryField并经过DQE归一化、现有计算和统一运行时。各组织粒度分数是预先声明的合成值，期间变化只用于验收重查，不代表真实指标计算或跨组织聚合规则。声音和服务能力查询也有模拟明细；其余原inline明细仍为原示例。完整操作和截图见 `docs/evidence/partner-health-preview-20261028/`。
