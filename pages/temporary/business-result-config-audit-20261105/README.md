## 同比与环比

主表同比沿用本期和去年同期两条查询；图表改为本期、上期、去年同期三条完整查询，由页面引擎计算：

- 同比＝本期净商务折扣－去年同期净商务折扣。
- 环比＝本期净商务折扣－上期净商务折扣。

结果为百分点差，不是相对增长率。图表三期保留相同区域和站点绑定，不再请求后端同环比指标；均值仍使用本期原后端指标。计算复用 `unionKeys → joinAggregate → delta`，图表保留三期组织并集。完整比较与完整图表系列需要完整结果，不能用一个分页窗口替代。

查询以 `net-discount-through` 可信截止事实对齐进度，使用日边界和时间聚合。事实必须由集成应用提供，不能用机器日期或页面自报时间替代。查询成功但缺组织记录时沿用原页补0策略；显式 null 保留，失败不补0。主表最终仍以原主查询组织为准。
