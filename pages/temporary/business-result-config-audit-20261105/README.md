# 业务结果指标情况

入口 `/pages/business-result-metrics-2`，JSON为同目录 `business-result-metrics-2.json`，Schema6.92。引擎源码同步后即可识别；无需专属displayInputs、固定截止日、前端Sim适配器或本地组织字典。业务数据与组织候选都通过宿主配置的真实DQE网关、同一接口及鉴权查询。Playground也直接使用普通网关；本地HTTP Sim仅作为后端仿真。

## 独立合计与期间

- 全球：地区部表和代表处表均使用独立 `output_dims:[]` 汇总。
- 选择地区部：代表处表合计使用独立 `output_dims:["地区部"]`，绑定所选地区部，不累计或平均明细。
- 选择代表处：只展示该代表处，隐藏合计。
- 本期与同比共用指标、组织粒度和筛选，时间分别为页头已应用期间及前移一年。2026-10对应2025-10；季度三个月、年度十二个月、近一年已应用十二个月整体前移。图表环比按所选期间前移一期。
- 完整期间查询使用月编码和 `is_aggregate:true`，让服务端聚合比率。没有浏览器日期或统计截止值参与这次查询。
- 净商务折扣同比为本期百分数减去年同期百分数，以 `points-1-signed` 显示P。真实空值保持空；失败不补零。

## 真值刻度与接入边界

用户提供回执中的净商务折扣（原价）、框架执行率、重大高风险合同率、云计算BU禁止条款风险合同率是小数比例。通过已有ratio(scale:100)转换一次；闭环率已乘100，不重复转换，不截断超过100%的值。`percent-scale-unit`的数值1仅用于单位换算，不是业务数据。

运行时的普通DQE网关已支持用实际维度查询提供当前声明层级的候选，不伪造父子关系；额外时间/布尔上下文不能表达时拒绝，不丢条件查询全量。内网须保持正常的接口地址、认证与后端指标/维度授权，这些属于真实系统接入，不是本地预览依赖。真实服务尚未直接访问，不把HTTP仿真、回执回放与浏览器检查称为内网实测。
