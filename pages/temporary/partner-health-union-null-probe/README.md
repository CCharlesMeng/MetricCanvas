# 伙伴健康度并集与缺项 Mock

独立验收页，数据为合成查询响应。浏览器通过真实 `POST /rest/cdi/cdinl2databuilderservice/v1/dsl/execute?fixture=partner-health&state=...` 请求本地 DQE Sim，再经过实际 DQE 归一化和统一运行时计算，不是预先算好的15行快照。Network 可查看每个请求的 `dsl_list` 与逐项 `results`。正式 `/pages/partner-health` 不携带这个合成场景选择器。

运行 `pnpm dev:dqe`，访问 [Mock 页](http://localhost:5173/pages/partner-health-union-null-probe)。已有18228服务时可用 `DQE_SIM_HOST=127.0.0.1 DQE_SIM_PORT=18229 pnpm dev:dqe`。仅启动 Playground 无法提供此 HTTP Mock。页面筛选候选值来自本地分层的地区部/代表处候选，业务数据查询全部走 HTTP。

数据真源为 `apps/playground/fixtures/organization-union/mock.json`；HTTP处理器为 `tools/dqe-sim/src/partner-health.ts`。分别返回1、10、13条的查询保留各自组织键，其他组织查询返回空数组，浏览器运行时最终取并集15条。模拟期间/区域数据固定，不证明真实内网字段、权限或期间筛选；顶部一次获取国内、海外两组整体记录，按钮切换复用计算结果。内存网关仅保留给确定性测试使用。

页面与正式页复用11项查询及组织并集/分类/总分声明。图表与表格均取同一计算结果；区域、代表处分别展示15个组织。ORG-01的声音闭环得分是真实0；ORG-03单项缺失显示 `--`、总分0；ORG-04的客户评价空字符串显示 `--`，总分7；ORG-06为8+(-2)=6；ORG-15只在第三组返回，总分10。固定合成响应不证明真实数据库的期间/权限/筛选结果。

顶部保留正式页“中国区 / 海外”控件与5张卡片的布局，复用11项整体查询，每项同时返回国内、海外两行。整体分数是人为构造的每范围唯一记录，与下方ORG组织行没有汇总关系。默认中国区显示总分35、感知20、满意度`--`、能力与贡献17、风险-2；点击海外显示30、4、15、14、-3。缺失分类保留`--`，总分对缺失按0处理。`?state=overviewMissing`验证全部单项缺失时4张分类卡`--`、总分0；`?state=overviewZero`验证5张卡均为真实0。两种状态只改变顶部，表格仍为15行。

顶部按用户确认移除地区部投影，对象只输出得分及`国内或海外`，条件同时请求国内、海外；其他7项保留指标查询形式，以同名范围维度分组。每范围应为唯一整体记录，多条相同范围记录仍报错，不因少投影字段就在前端求和。实际服务能否提供该粒度仍需真实DQE回执验证。完整候选、可执行请求JSON及截图见[顶部整体Mock验收](../../../docs/evidence/partner-health-union-null-20261029/overview/README.md)。

通过 URL 参数 `state` 验收：默认 `ready`；`?state=emptyMain` 声音闭环查询空但仍显示14行；`?state=empty` 全部为空，图表/表格为空；`?state=error` 合成失败、`?state=truncated` 已知计数不完整、`?state=duplicate` 来源组织重复，均不产出部分总分；内部快照与诊断保留错误分类，当前统一呈现策略将错误显示为空数据。非法声明、键类型、字段省略及迟到响应等由行为测试补充。切换图表与表格的区域/代表处页签验证两种粒度；表格本地分页/导出复用计算结果。

原始 Mock、可运行诊断脚本、日志和截图见 [诊断报告](../../../docs/evidence/partner-health-union-null-20261029/README.md)，后续修改见 [整改方案](../../../docs/plan/2026-10-29-partner-health-union-and-missing-scores.md)。

`?state=zeroTotal` 保留全部合成行，只将每份 DQE 响应的 `total_count` 设为0。地区部、代表处仍各有15个组织，表格分页可看到全部行，图表与总分保持；顶部中国区35、海外30。Console 保留 `TOTAL_COUNT_MISMATCH` 和 `completeness: unverified`，原查询总数不改写。计算只描述已返回行，不能证明真实服务完整性；严格对象完整导出仍拒绝矛盾计数。正式页面无需改 JSON，需部署修复后的运行时。

下方查询不消费顶部中国区/海外筛选，也不附加国内/海外条件。区域树一次提交层级与具体组织，使用 `levelQueryFields` 将地区部、代表处分别映射为中文查询字段；顶部11项整体查询不消费区域筛选。

地区部与代表处使用不同合成数据：地区部为 ORG-01…ORG-15，代表处为 REP-01…REP-15；代表处采用不同得分分布，例如 REP-06 总分3、REP-12总分9、REP-15总分5。两者均保留1/10/13条来源、15条并集及 null/0/空字符串。图表和表格页签独立，切换图表可观察组织标签与柱形变化；不修改正式页面查询或引擎。

顶部请求与缓存：初次取数时，11项各取国内和海外两条独立整体记录；先按范围关联、计算四类及总分，再由 `pivot`/`selectField` 按按钮选择展示值，保留5张卡。顶部不请求地区部/代表处字段，不再使用data_site_type。切换顶部不新增任何查询，也不改变下方结果；图表和表格共用同粒度结果。选择具体组织后卡片直接复用该粒度计算源，代表处结果在初次取数时已加载。SourceProgram统一调度、网关将并发查询合入dsl_list；受并发上限和依赖顺序影响，可以有多个HTTP批次，不承诺整页只有一次HTTP。

## 全球与具体组织视角

空区域选择表示全球，与保留的层级值无关；页头使用一个区域树，不再单独显示层级按钮。仅选择层级、不选择具体组织，不构成组织视角。

| 区域选择 | 顶部按钮与卡片 | 图表页签 | 表格页签 |
|---|---|---|---|
| 全球（空选择） | 展示中国区/海外，复用两组整体分数 | 地区部、代表处 | 地区部、代表处 |
| ORG-06 地区部 | 隐藏按钮，复用地区部得分：6、-2、8、--、-- | 仅代表处，REP-04/05/06 | 两个页签一直展示 |
| REP-06 代表处 | 隐藏按钮，复用代表处得分：3、-1、4、--、-- | 仅代表处，REP-06 | 两个页签一直展示 |

先在全球选图表地区部页签，再选ORG-06，会自动显示仍可见的代表处页签；清空区域恢复全球。全球切海外只改变顶部35为30，下方组织与得分保持。图表、卡片分类缺项为null，真实0仍为0，总分对缺项按0相加，不为无记录生成行。查询过滤使用mock.json中明确声明的合成父子关系；下拉只按层级分组，不虚构跨层归属，沿用现有fetchDimensionValues候选端口，全球空选择不要求新版候选接口；实际组织候选仍须集成应用提供，不证明内网候选或查询权限。
