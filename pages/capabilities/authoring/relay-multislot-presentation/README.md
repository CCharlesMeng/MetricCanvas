# 受控多槽与创作呈现

入口 `/pages/relay-multislot-presentation`，显式 Dashboard，全部为内联合成数据，不需要 URL 参数、DQE 或 Relay。按仓库 Playground 正常启动方式访问。

表格主槽为 a、b；辅助槽为 b、c。辅助槽按稳定 `region` 行键横向关联：a 的辅助度量为空，b 显示对应值，c 不生成新主行。列的字段所属槽各自明确，数据源行未预先合并。空辅槽、重复/非法行键、unknown/失败槽与查询分页窗口的正反例由同一受控装配测试覆盖，不用伪造页面错误混入日常演示。

下面的柱图、折线图复用 Tokens 字段 `compact-million-1`，原值为百万级 Tokens。检查数值轴、标签与 Tooltip 使用相同百万格式；表格继承同一字段默认格式。没有把原值改为“百万数”，页面使用既有通用格式枚举。

运行 `page.presentation` 的 `inspect` 可做无 DOM 的最终绑定适用检查；显式覆盖冲突由工具报告并保留。合法金额百万格式仍通过产品页面校验，此处“百万仅用于 Tokens”仅约束 AI 创作选择/纠错。
