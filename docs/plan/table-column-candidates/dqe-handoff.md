# DQE 对接说明：一次请求返回表格数据和列筛选候选值

日期：2026-10-21。状态：需求和待联调样例，尚未真实服务验证。字段名、取值、身份和工作区按真实业务替换。

## 要实现什么

表格按条件分页展示；某列筛选选项来自这张表全部匹配行中该列的去重值。候选请求保留权限、固定业务条件、页面条件、其他列筛选和已提交搜索，只排除目标列自身的表头筛选。

例：页面选 2026 年 1—9 月，区域列选中国区，代表处列选北京。表格只显示北京；打开代表处筛选仍能看到同一时间、中国区内其他实际出现的代表处。候选值不能只来自表格当前页，也不能来自与本表无关的维度字典。

产品已确定：已有表格统一采用上述规则，无需增加 scope 配置。失配已选值保留；稳定值保留字段原始类型，显示名独立；首批不提供 null“空白”选项。沿用非成功码带非空数据的消费规则（包括 NO_PERMISSION），不改为仅消费 SUCCESS；消费后仍需分别验证结构和候选分页完整性。

## 建议联调请求

一次 POST，dsl_list[0] 取表格，dsl_list[1] 取代表处候选。下例依据现有接口调查（原工作区 调查报告/dqe.md，仅本机保留），只覆盖普通维度条件；不包含搜索和度量筛选。

~~~http
POST /rest/cdi/cdinl2databuilderservice/v1/dsl/execute
Content-Type: application/json
X-Auth-Token: <token>
X-Operator-Id: <operator-id>
X-Workspace-Id: <workspace-id>
~~~

最小验收：①候选跨越表格当前页；②时间/区域变化收窄候选；③代表处勾选北京后仍可见其他候选；④同字段固定条件仍保留；⑤超过一页无漏项/重复；⑥受限账号不泄漏；⑦带度量条件时保持原粒度。

正确性对照：在可控小数据集上，以“原表查询仅排除目标列表头条件后的完整结果”投影目标字段并去重，作为期望集合；新候选查询应与它一致。包含多粒度收入和稀疏记录的用例，避免仅改输出维度后换了模型或聚合粒度也看似通过。

请按“已支持 / 需要新增 / 不支持”逐项回复，并附可执行请求、响应和必要限制。如现有 DSL 无法表达，请提供“对受控原查询结果按字段去重”的正式能力，不约定未实现字段。每个选项的匹配数量本轮不是必需。

引擎负责排除当前列表头条件、状态隔离与刷新；DQE 负责约定查询范围内的正确执行、权限和可验证分页。引擎实现现状与完整 gap 见[分析](analysis.md)。
