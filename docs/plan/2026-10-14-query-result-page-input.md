# 任意列排序驱动查询结果绑定与分页窗口更新

日期：2026-10-14。按用户最新澄清修订方向：任意可排序列的交互都可能改变其他数据源；不预设金额排序或固定 A→B→C 执行链。用户已授权实施；运行时、共享单次执行及5173示例已接入。验收见[分页场景证据](../evidence/query-result-where/paged-scenario.md)。

## 业务语义

排序属于被操作表格的数据源查询状态。用户可改变任意已声明可排序列的字段、方向及多列优先级；每次排序变化都让该查询从第一页开始。分页仍由该数据源管理，不把页码、offset、limit作为查询结果绑定的业务输入传给下游。

查询结果绑定消费上游本轮实际返回的原始行：先按绑定自己的where过滤，再提取绑定field、去重，形成下游维度输入。上游表格复用本轮返回的全部行。分页表格中的“全部行”是本轮查询窗口，并非整个业务范围。

每个查询通过resultBindings声明自己使用哪些数据源、哪些字段及条件。引擎据此推导依赖图与受影响范围，不能在引擎中写死表格名称、列名称或调用次序。依赖图可分支、汇合和多层传递；无依赖的查询可以并行执行。执行的先后由本轮输入是否就绪决定。

“任意排序都有可能触发其他变化”不意味着所有组件必然重查。任何合法排序变化均进入同一机制；只有依赖该数据源的查询参与重新解析输入。若仅改变行次序，过滤后得到的字段集合相同，则下游有效查询可复用缓存。若改变当前页成员，或改变绑定提取出的值，下游按新的输入更新。

## 通用事件流程

1. 表格提交排序规则，运行时更新该数据源的查询状态并重置其页码为第一页。
2. 从依赖图求出直接和间接受影响的查询；使旧结果失效，取消过期请求，受影响的下游分页查询也重置为第一页。无关查询保持原状。
3. 上游在服务端先排序，再取第一页窗口；不能用只排序已返回行的方式代替查询排序。
4. 上游新结果就绪后，各下游独立计算where与字段集合。只要所有输入都已就绪，就执行或复用对应有效查询；多个下游不互相等待。
5. 下游新结果继续驱动其依赖者。旧轮次的迟到结果不能覆盖新轮次。

后续翻页同样进入依赖失效和就绪流程，只改变被翻页数据源自己的查询窗口。下游仍只接收其绑定声明的字段值，不接收上游的分页参数。

例：项目表的金额、时长、名称、状态等列都可提交排序规则；风险表和评估表分别使用项目表的不同过滤结果；汇总查询可同时依赖风险表和评估表。金额没有特殊地位，风险表与评估表也没有固定执行先后。

## 已查明的实现基础及限制

- RuntimeSurface在query分页模式下将表格列头排序提交给setQuerySort；当前完整结果示例只做展示排序，无法验证本需求。
- orchestrator.refetch已经由queryResultDependencies求传递依赖，publish按输入就绪恢复等待查询，并已有请求代次、取消和查询缓存机制。
- setQuerySort当前拒绝所有被查询结果绑定引用的上游；validate-query-results当前拒绝查询分页窗口作为绑定输入。这两处已统一扩展，窗口解析同步使用本轮实际请求大小。
- 已准备80个项目：tools/dqe-sim/fixtures/query-result-where-paged.json。5173示例已切换为80行查询数据，首轮10行。

## 协议与实现方案

不再增加inputScope或把排序、分页参数复制进resultBindings。沿用source、field、queryField、where及表格现有query分页声明，新增允许“查询分页数据源被结果绑定引用”的组合语义。该组合能力下限为6.20；TS/Python校验器与版本门禁同步，6.19继续可读但拒绝使用新组合。

窗口输入解析应使用运行时实际请求窗口大小，包括用户修改每页条数后的值。totalCount表示业务范围总条数，不能要求与本页行数相等。分页源不能同时声称resultScope为complete。旧完整结果与固定有限选择的范围规则需明确保留，不能因放开分页而被悄悄扩大或改写。

已允许符合新窗口语义的上游接受通用查询排序；具体列由字段映射确定，无列名特判。共享单次执行回填第一页并按该页级联；运行时按当前窗口级联，两条路径使用同一解析规则。

导出也必须明确同一时刻的窗口和依赖结果，不能自动把当前页输入扩展成全量。已核对并实现捕获时的当前窗口导出；无级联的普通分页表继续完整导出。

## 验收标准

80行数据，首轮仅返回10行且totalCount为80。验证多个不同类型列的升降序与多列排序，均发送真实查询、回到第一页，并按本轮成员集合更新依赖查询；验证翻页、改变每页条数、分支与汇合依赖、多层传播、无关查询保持、集合相同时缓存复用，以及空结果、错误与迟到请求。

同时覆盖浏览器、共享单次执行、导出、TS/Python语义校验、旧版本拒绝新组合、契约及Skill分发。真实DQE/Relay/Java证据与本地DQE仿真分别报告。
