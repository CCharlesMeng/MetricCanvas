## 技术落点

`packages/page` 拥有查询类型识别、输出/绑定契约、参数解析和默认排序读取；`packages/data-execution` 拥有协议编码、结果归一化及完整范围执行；组件仍只消费页面字段与共享状态。

object 的 `output_fields` 不自带 dimension/measure/detail 角色。使用显式结果字段契约及可信对象字段说明，不从字符串或数字样例推断。`columns: null` 不影响按 `queryField` 归一化。

字段候选与文本搜索继续由可信数据网关能力提供，保留完整匹配结果语义，不能从当前页造候选。多列排序若真实上游仅支持单列，须提供可信适配或明确阻断，不降级成本页排序。
