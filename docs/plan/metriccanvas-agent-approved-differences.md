## 登记规则

1. 先记录差分证据，再判断是缺陷还是候选差异；默认按缺陷处理。
2. 候选差异必须有接受的 ADR，明确受影响用户、回滚方式和复审时间。
3. 临时豁免必须有到期日；到期未复审即恢复为阻断项。
4. 修复或撤销后保留历史行，将状态改为 `closed`，不得删除证据。
5. M8 删除旧实现前，本表不得存在 `proposed`、`expired` 或无证据的 `active` 行。
