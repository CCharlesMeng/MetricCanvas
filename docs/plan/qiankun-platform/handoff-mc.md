## 目标

在当前 `apps/platform/` 原地改造，输出可由主应用加载的 HTML 微前端静态目录，同时保留本地独立运行。按 [整体方案](./integration-plan.md) 执行，必要时核对 [官方研究](./official-research.md)。

本交接替代原 npm 包双入口方案：不发布 `@metriccanvas/platform`，不执行仓外 npm 消费验收，不采用内部内存导航。主应用管理平台路由前缀，platform 管理前缀内的 URL、前进后退与深链接恢复。

## 1. 复用已完成的通用实现

读取 AGENTS.md、CONTEXT.md、ADR-0093/0094 与现有实施证据，核查工作区。平台已采用普通 Svelte 和客户端 URL 路由，独立/微前端分开构建。Kit 探针已有结论，不重新迁移。

本轮优先完善独立部署 Adapter 契约和清理，以及完整静态产物组合验证。测试主应用使用标准 loader 和合成接线；实际私有补丁/身份链路保留在独立部署项目验证。部署前缀运行时提供，不与资源路径混用。

## 2. 接入隔离与业务复用

在 `src/microfrontend/` 集中生命周期导出、容器处理与通用契约验证；门户配置映射只存在于仓外独立部署项目。业务仅使用规范化配置、实例服务和内部 URL 导航接口。内部 mount/destroy 可保留，不作为 npm 公开接口。

复用已有工作台、管理列表、详情和 RevisionPreview，不复制业务视图。page-assets 单例改为实例工厂，Java/DQE 协议与保存回执核验不重写。管理操作也注入身份，不能遗留全局读取。

application-runtime 保留独立入口与页面试验场现有全局语义，页面资产仍不依赖 DQE 端点完整。对话/可信创作按实例接线，未接通时如实展示不可用。

## 3. URL 路由与生命周期

主应用进入前缀时挂载，范围内导航不重挂，离开时卸载。平台提供内部路径映射、链接、编辑离开保护；详情/编辑 URL 保留 page/resource 语义。取消内部导航或后退离开时，URL 与当前视图一致。

每请求现读配置；同身份 token 更新不重建。身份/目标变化停止旧会话操作并通知外层。挂载只等待有限本地初始化；失败自行清理；销毁可等待且幂等，清理路由/事件监听、请求、DOM 与自有 SDK 资源。

不得通过卸载自动保存/发布。已发写入无法保证撤回，未知结果保留并停止，不重试掩盖。固定服务目标为首版部署约束；保留原 IndexedDB key 和记录，不增加跨数据域恢复隔离或迁移。

## 4. 构建与交付

交付 `dist/microfrontend/` 的 HTML、JS、CSS、必要静态资源和版本清单，另给完整归档及 SHA-256。独立与微前端使用当前两种构建且输出互不覆盖；内网消费归档的声明和组合脚本，不深导入平台源码。

正式契约描述主应用 props、routeBase、readConfig、subscribeConfig、稳定事件、可选 guard/SDK。产物不得依赖 Svelte 编译插件、workspace 私有路径或 DEV 凭据。

qiankun 2.x 的 UMD 生命周期 + HTML 是候选后备路径，不等于已完成；必须通过实际 loader 识别和生产资源加载验证。不把 JS URL 当 HTML entry，不引入第二套 qiankun 主应用。

## 5. 验证与文档

复用现有配置、页面资产、保存恢复、对话测试，补实例与路由契约。必要浏览器验证覆盖挂载、内部 URL、后退/刷新、编辑保护、容器/弹层、卸载重挂和快速切换。

分开报告：本地类型/测试、静态构建、测试主应用真实 qiankun、目标门户、真实服务。缺失环境标 NOT_RUN。人工业务闭环先完成，AI 单列。

实施时同步 host-contract、ADR 与主题页，明确修改 ADR-0073 中全局配置/部署入口的旧限制；不要把本次方案更新当成实现完成。
