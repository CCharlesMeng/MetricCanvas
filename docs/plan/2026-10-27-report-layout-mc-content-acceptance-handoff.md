布局检查与数据检查分别报告，先说布局效果。主判据是阅读是否成立，不是 Schema 正确或没有横向溢出。

- 原因留在对应对象附近；阶段数据保留为一张有分组表头的表，不采用已拒绝的 C3-B 阶段拆小表。
- 小环图不得单独占据宽屏通栏。若选择并排构成主题，必须来自输入已有主题；允许条形图或仅明细替代，不能发明第二个主题填空。
- 章节顺序、标题层级、卡片宽度与内容量相称；主次清楚，图表明细相邻，没有巨大空白、无价值重复和凭空新增业务结构。
- 页签按阅读任务决定，不能藏起必须同时对照的证据；不强制用齐 11 项。
- 实际工具能力单独核对：`compose_page` 不能自动装配的 compositeCard/tabContainer，不可编造工具成功。local-authoring 全 Page JSON 与在线装配工具边界不同。原型中心合计、局部尺寸及共享色板不能直接假设为协议能力。
