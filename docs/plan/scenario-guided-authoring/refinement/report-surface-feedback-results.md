## 修订

| 现象 | 原因 | 修订 |
| --- | --- | --- |
| “目标口径 / 本页不计算……”与查询范围同时出现 | 模型正文复述执行限制，v3 程序又追加技术范围文本 | v3 停止自动追加；只清理历史保留 ID 的自动说明，保留显式业务正文。Skill 区分执行说明和必要业务提示 |
