# T01：拆出可独立运行的盘古对话接入边界

状态：拆分已获认可，已发布为 [#127](https://github.com/CCharlesMeng/MetricCanvas/issues/127)，标签 ready-for-agent；尚未启动实现。

## Parent

[规格 #126](https://github.com/CCharlesMeng/MetricCanvas/issues/126)；关联规划 [#95](https://github.com/CCharlesMeng/MetricCanvas/issues/95)。

## What to build

让侧边栏对话模块能够独立开发，并通过同一接口嵌入现有工作台。

责任：C6 主责，C2 只提供工作台接入点。

## Acceptance criteria

- [ ] 提供独立运行入口和受控事件替身；工作台挂载同一模块，导航、文档工具栏、画布及属性面板保持可用。
- [ ] 封装盘古专有配置与事件，工作台只交付必要上下文并消费结果；不直接改工作副本或实现保存发布。
- [ ] 复用 #108 已完成的保留旧页和迟到结果隔离；用公开接入行为验证，不重新实现该状态控制器。
- [ ] 独立适配与运行配置不侵入上游源码，交付兼容接口下更新上游后无需手工补改源码的演练；真实盘古验证续接 #107/#108。
- [ ] 实施时集中 grill 模块加载、适配和配置保存细节；未知盘古事件不得被替身伪装为已支持。

## Blocked by

无，可立即开始。

## 与既有规划的关系
