# T03：为 layout 新字段建立版本化兼容读取

状态：拆分已获认可，已发布为 [#129](https://github.com/CCharlesMeng/MetricCanvas/issues/129)，标签 ready-for-agent；尚未启动实现。

## Parent

[规格 #126](https://github.com/CCharlesMeng/MetricCanvas/issues/126)；关联规划 [#95](https://github.com/CCharlesMeng/MetricCanvas/issues/95)。

## What to build

在旧页面仍可读取的前提下，验证新版 layout 字段能够表达相同布局形态。

责任：C0 主责，统一拥有协议及生成产物。

## Acceptance criteria

- [ ] 按 ADR-0051 冻结新版本、旧文档接收策略、唯一写出形式、双字段冲突规则及升级顺序，不静默替换 6.0 字段。
- [ ] 先扩展明确版本的读取和规范化边界，旧调用方继续工作；不在同一文档保存两份布局真源。
- [ ] 新旧文档分别在公开校验及统一运行时入口验证 report/dashboard 等价行为，未知版本仍失败关闭。
- [ ] 共享契约仅从指定作者源生成，跨语言样例和错误行为一致。
