## 目标与 AC

沿用 tasks.md 中 AT-01～05。来源为当前会话逐次选定的 C 原型，最终批准语句“可以，开始实施”，2026-10-19。原型渲染入口 http://127.0.0.1:5198/dialogue?variant=C；冻结为 evidence/design-source/index.html 和 approved-c.png。这里只针对画布交互，不扩展分析/查询/发布架构。

## 文字规格

属性面板保留页面配置/组件配置及页面设置切换；选中后只有返回“全部组件”和类型属性标识，无蓝底摘要卡、重复业务标题、技术 ID 或常驻移动/删除按钮。业务标题仍在属性输入框编辑。画布上选中组件外侧右上方显示标题、上移、下移、删除；首末位置禁用相应移动，删除可撤销。小拖动手柄仍就地可见。

蓝色渐变细描边、极淡底色过渡、轻圆角及轻阴影，以冻结原型抽取事实和渲染事实为准。选框不拦截点击。正式页面与预览不出现搭建装饰；工作台保存期间停止编辑。操作条在可见滚动区域内跟随组件；目标完全离开可见区域后隐藏，不覆盖面板，不增加查询。

## 对接模式与数据

工作台继续持有双投影草稿，画布只发出 select/move/delete/edit 意图；所有改写仍经 document-edit 与现有 coordinator。上下移限制在当前分区，拖动支持跨分区；不回收共享数据源，保留至少一个组件。操作条通过原生 popover 的顶层呈现避开布局容器裁切；定位监听随目标/编辑状态清理。不变更 AuthoringIntent 既有语义。

## 当前代码事实

第一阶段已经具备手柄拖动、删除、单步撤销与显式保存，但操作仍在摘要卡或组件角落，选择仍为紫色光晕。本次基于同一会话工作树继续，不触及原检出的并行改动。

## 风险与依赖

共享搭建画布包及运行时组合入口，须覆盖独立消费、状态保持、事件监听清理、滚动/缩放与预览；原生 popover 与现有 Select 相同浏览器基线。真实 Java/DQE/Relay 非本次变更的真实接缝，不将受控保存验收称作外部联调。
