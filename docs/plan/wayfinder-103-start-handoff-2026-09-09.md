- #103 旧正文“唯一可外部化的 JS 产物是 embed”早于四交付物落地。按现行四交付物方案发版；异构宿主使用 embed 的自包含 JS 挂载入口，`packages/embed` 不是独立应用。
- 普通 HTML/Vue/React 等异构宿主可加载 JS 后调用 `mount`，返回实例支持 `update`/`destroy`。单页接入不要求微前端协议；是否运行在 IOC 子应用中由实际集成应用决定。
- 宿主提供页面文档、容器几何、数据网关及请求身份；视觉呈现归引擎。仅内联页面可以不提供数据网关。动态取数可以按 ADR-0069 使用边界替代，不必等待生产 DQE，但须明确证据范围。

## 终点验收

| 验收项 | 必须留下的证据 |
| --- | --- |
| 真实发布与安装 | 明确内网 registry、四包同版版本与产物记录；真实宿主从发布版本取得产物，使用公开入口 |
| 真页面渲染 | 指定宿主/环境和仓库真实页面，记录 JS 加载、挂载成功、实际浏览器表现及浏览器版本 |
| 输入与生命周期 | 完整输入替换、update/destroy、重挂载和容器宽度行为；保持创作/渲染依赖隔离 |
| 导航 | 6.0 URL 协议的绝对/相对地址、复制链接/新标签页，行字段/页面参数/指定筛选值的显式传参；按需接管导航 |
| 筛选与数据 | 验证可选 filter-change URL 同步，避免原样回灌 update；标明使用真实 DQE、仅内联页面或边界替代 |
| 版本与失败 | 不支持的页面 schemaVersion 给出可行动错误，不白屏或错渲染；相关失败与恢复路径有证据 |
| 集成成本 | 宿主接线文件、胶水职责和实际代码量；改动、测试结果与剩余外部条件可追溯 |

按改动风险执行已有相关门禁；本票至少需要真实宿主浏览器验证。只有新的改动或失败才扩大重复测试。若任务转为对照外部设计源还原视觉结构，按根 AGENTS 进入 SDD；普通接线、逻辑和缺陷修复按对应工作流推进。

本地最小 Vue/React 示例可用于诊断和阶段证明；真实宿主未接入时，#103 保持未完成。
