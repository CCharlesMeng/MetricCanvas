# 点击与视觉修复规格

延续已批准OpenTiny OS3.32.0官方CSS/SVG来源。官方CSS真源为docs/evidence/platform-ui-os-theme-2026-10-12/sources.json；精确几何和颜色从SHA验证的源CSS及其组件token取得。用户要求修复当前控件而非新增交互模式；不新增协议或数据语义。

1. 标签文字、标签间空隙和右侧箭头均能鼠标打开/关闭，搜索输入获得焦点；使用原生Popover时不能在同次按下/松开序列中被自动关闭。删除与清空独立操作，禁用不可变更，横向滚动不受阻。
2. 固定单行32px，官方默认标签为light基础型（灰底深色文本），不是info主题蓝色；标签高度、圆角、间距与字体采用官方token。箭头始终可见且与32px输入垂直居中，清空/删除图标使用官方布局，不与标签重叠。
3. 搜索使用官方面板内下划线结构与padding/margin；树行32px，描边加减号16px，浅灰1px连接线。所有真实几何由最终浏览器计算样式验证，不能只看源码。
4. 保持已有键盘、Escape回焦、父子规则、值删除和候选状态；搜索与展开不提交。完整页面作为鼠标回归入口，Chrome/ShadowRoot及仓外包消费验证。
