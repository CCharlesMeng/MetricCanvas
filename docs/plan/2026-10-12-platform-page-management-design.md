## 页面与跳转关系

界面收敛为三个关键页面：页面管理负责查找与整理；页面详情负责查看内容、历史和发布；页面搭建工作台负责新建或编辑页面。预览是详情或工作台的阅读模式，切换模式不增加页面层级。

侧栏保留“创作”和“页面管理”。创作回到同一个页面搭建工作台，恢复当前正在处理的页面及未保存修改；没有当前页面时展示空工作台。“新建页面”是明确的新建动作，只有用户点击它才开启新页面。页面管理里的编辑打开指定页面在同一工作台中的编辑状态，页头始终显示当前编辑对象；处于编辑或编辑预览时侧栏创作为选中项。

保存草稿后留在工作台，只更新保存状态。工作台顶部提供“返回页面管理”，一步恢复目录条件与位置；从列表或详情进入编辑都遵循这一规则。切回管理保留当前工作副本，不自动保存或丢弃。再次点击创作继续当前任务；重新选择另一页面编辑时，原页面的未保存工作副本也应保留。

| 入口动作 | 到达状态 | 返回或关闭 |
| --- | --- | --- |
| 管理列表点击名称 | 页面详情 | 返回页面管理 |
| 管理列表点击预览 | 页面详情的阅读模式 | 返回页面管理 |
| 列表或详情点击编辑 | 工作台编辑指定页面 | 返回页面管理 |
| 阅读模式点击进入编辑 | 工作台编辑该页面的当前草稿；工作台预览则恢复原工作副本 | 返回页面管理 |
| 管理或工作台点击新建页面 | 工作台新建状态 | 返回页面管理 |
| 侧栏点击创作 | 当前工作台状态，或空工作台 | 返回页面管理 |
| 工作台点击预览 | 同一工作台的阅读模式，含未保存修改 | 继续编辑，保留原工作副本 |
| 详情点击展开预览 | 同一详情的阅读模式，固定当前修订 | 退出预览，恢复原版本与历史选择 |
| 保存草稿 | 当前工作台，更新已保存状态 | 用户主动返回管理 |
| 复制成功 | 新页面在工作台中的编辑状态 | 返回页面管理 |

产品按钮使用明确目标，不以浏览器后退代替返回管理。实际导航可保留正常浏览器历史；产品返回动作不制造“先回详情再回目录”的强制链路。

## 现有能力与缺口

当前 `/manage` 支持全部、草稿、已发布筛选，20 条分页、刷新与新建。详情支持当前内容预览、编辑、草稿历史摘要、按指定版本恢复和删除。名称展示不一致：列表突出页面 ID，详情把描述作为标题；页面文档实际已有 `meta.title`。[列表](../../apps/platform/src/lib/views/ManagementList.svelte)、[详情](../../apps/platform/src/lib/views/PageReading.svelte)、[页面标题规则](../../packages/page/src/page-list-entry.ts)。

当前 Java 接入对同一资源进行草稿保存和发布状态更新，不保证独立发布副本；平台没有独立的发布内容读取链路。历史接口只返回摘要，恢复接口返回恢复后的完整页面，但没有恢复前历史正文读取、恢复追加修订或跨窗口基线检查保证。[现行生命周期结论](../adr/topics/page-lifecycle-and-publish-governance.md)、[ADR 0080](../adr/0080-java-assets-single-attempt-save-and-status-publication.md)、[Java 契约](../../service/platform-java.yaml)。

历史由外部 Java 页面资产服务负责。当前契约没有说明历史生成时机、数据库结构、快照或差量格式、保留期限。浏览器 IndexedDB 保存工作副本、未同步操作和管理操作保护记录，不是远端历史版本库。[浏览器存储](../../apps/platform/src/lib/workbench/authoring-storage.ts)、[管理保护](../../apps/platform/src/lib/page-assets/management.ts)。

## 信息结构与视觉原则

保留平台全局导航，主要页面为目录、单页详情和页面搭建工作台。详情与工作台各自具有阅读模式，沿用同一页面上下文；详情沿用已有资源身份，不用抽屉承载完整页面预览、历史和发布。

目录顶部只有标题与新建按钮，第二行是搜索、状态筛选与排序。列表采用轻量表格或对齐行，只显示名称与一行描述、状态、最近修改时间、预览、编辑和更多。预览用于直接阅读，名称用于进入管理详情，编辑用于继续创作。技术 ID、精确修订及诊断信息收进详情的页面信息区。页面名称可换行，描述最多一行；全文可通过详情和可访问提示读取。

视觉用平台现有字体和中性色，留白区分层次，细分隔线划分行，不给每页套卡片。色彩只辅助状态，必须同时有文字；删除仅在动作本身和确认处使用危险色。不增加统计卡片、缩略图墙、固定侧栏分类和常驻批量选择。

窄屏把每行重排为名称、状态与时间、操作三层；保留预览、编辑和更多。短屏保持自然页面滚动，确认面板内容可完整读取。按钮支持键盘，菜单可按 Escape 关闭；弹窗关闭后焦点回到触发处，错误与结果通过适度的状态播报呈现。

## 目录与状态

建议默认按最近修改倒序，提供最近修改正序和名称排序。搜索覆盖名称、描述及页面 ID，面向全部有权访问的个人页面；去除首尾空格，中文按包含关系匹配。搜索、状态、排序、页码写入可恢复的导航状态；改搜索或筛选回第一页，返回目录恢复原条件和滚动位置。

首期建议每页沿用 20 条。分页不能为每次翻页拉取全目录；全目录搜索和排序交给服务。搜索采用短延迟提交，旧响应不覆盖新结果；刷新保留已有结果并显示轻量加载提示，首次进入才用骨架。

| 页面状态 | 用户看到的状态 | 主要动作 |
| --- | --- | --- |
| 没有发布内容 | 草稿 | 编辑；详情预览后发布 |
| 当前草稿与发布内容一致 | 已发布 | 查看；编辑 |
| 当前草稿与发布内容不同 | 已发布，有待发布修改 | 编辑；详情核对草稿后发布 |
| 状态无法确认 | 状态待核实 | 查看已有内容、核实状态；阻止依赖已确认状态的写入 |

以上是目标状态，不从本地时间、修订数字大小或页面标题差异推断。服务需给出草稿修订与发布修订的可信关系。最后修改时间表示页面修改时间，不冒充数据刷新时间。页面标题优先来自当前草稿，已发布标题在发布视图中呈现；标题修改尚未发布时两者可以不同。

有结果时不反复显示教学文案。目录为空时引导新建；搜索无结果时提供清除搜索与筛选；加载失败保留条件并可重试。单个页面已删除或无权限时解释当前页面不可用并提供返回目录。

## 单页详情

顶部是返回目录、页面名称、状态和最近修改时间。常用操作为编辑；当前存在未发布草稿时可进入发布确认。更多承载复制与永久删除。已有发布内容时提供发布访问入口；这个入口只能读取发布内容。

主体默认展示待发布草稿；没有待发布修改时展示已发布内容。只有确实存在两个不同内容时才显示草稿与已发布切换，标题同时标明当前预览对象与修订。历史通过单一的“历史版本”入口按需展开，选中版本进入历史预览，显示时间、备注和版本身份，并可恢复为新草稿。

发布内容、历史内容使用对应精确修订，不随新保存漂移。切换预览不改变页面的草稿或发布状态。页面参数按文档声明请求，预览参数不写回页面；不猜出不存在的默认值。

历史预览锁定的是旧页面定义。查询页面数据源可能查询当前数据；仅在页面内确有内嵌初始行等证据时呈现对应保存数据。界面不能把历史定义预览称为“当时数据回放”。

## 阅读模式

列表每行直接提供预览，直接打开页面详情的阅读模式。页面内容为主体，顶部提供明确返回目标、页面名称、预览对象、精确修订和“进入编辑”；从列表进入时还可切到同一页面的管理详情。阅读模式不放保存、发布、恢复和删除动作。

“进入编辑”直接打开该页面在同一工作台中的当前草稿，保留已有未保存工作副本。发布内容预览注明“进入编辑将打开当前草稿”；历史预览的入口明确命名为“编辑当前草稿”，不隐式恢复历史版本。工作台内的预览点击“进入编辑”恢复原编辑状态，包括未保存的新页面，不创建修订。进入工作台后仍一步返回页面管理。

预览有待发布修改时默认查看当前草稿；没有待发布修改时默认查看已发布内容；仅有草稿时只显示草稿。草稿与发布内容不同且都可读时，可明确切换两者，不以草稿冒充发布内容。详情的展开预览携带当前选中的精确修订，包括历史版本，返回详情恢复原选中对象和历史展开状态。

详情阅读模式固定选中的页面修订，不随后台保存变化。工作台阅读模式展示当前编辑内容，包括未保存修改，并明确标注；关闭后继续同一编辑状态。页面声明的筛选、Tab、分页和下钻等渲染期交互只影响当前预览实例，不产生页面保存。页面参数仍按声明收集。返回列表保留搜索、筛选、排序、页码和滚动位置；按 Escape 可退出当前阅读模式。实际实现复用统一运行时，不新增第二套页面渲染逻辑。

## 交互旅程

### 直接预览

1. 从列表点击预览，按明确状态选择草稿或发布内容，并读取精确修订。
2. 只读呈现完整页面；有两份不同内容时可切换草稿与发布内容。
3. 页面渲染期交互只作用于预览实例。用户需要修改时直接点击“进入编辑”，需要查看历史等管理操作时进入详情。
4. 从列表进入阅读模式时一步返回页面管理；从详情或工作台进入时退出阅读模式，恢复原版本选择或编辑副本。

### 找到并继续创作

1. 用户进入目录，以名称、描述或 ID 搜索，可结合草稿或已发布筛选。
2. 点击名称进入详情认页，或直接点击行尾编辑进入页面搭建工作台。
3. 工作台读取当前草稿与精确修改基线。首次修改已发布内容时在草稿侧形成可编辑状态，发布内容保持不变。
4. 保存成功后仍留在工作台并显示草稿已保存；只有服务确认存在发布差异才显示有待发布修改。
5. 用户点击返回页面管理，一步恢复查询条件、页码和位置；若页面已不符合原筛选，保留筛选并明确提示状态已变化。再次点击创作恢复当前工作台。

### 从详情发布

1. 详情展示已保存的精确草稿修订。工作台仍有未同步内容时提示先处理，不把浏览器未保存内容当发布候选。
2. 用户点击发布，确认面板展示页面名称、目标修订、首次发布或更新发布的影响，以及该修订的预览入口。
3. 用户确认后，服务以该精确草稿作为候选，并核对当前草稿和发布基线。期间有其他修改则停止，由用户重新核对；不能默默改成最新内容发布。
4. 服务确认成功才更新已发布状态和访问入口。详情与工作台复用同一流程。
5. 超时或无法信任回执时展示发布结果待核实，保留候选与操作记录，核对原操作或发布引用；不让用户再次点击产生重复发布。

### 历史预览与恢复

1. 展开历史版本，按时间倒序查看时间、备注和版本。
2. 选择一个历史修订，读取对应正文并预览；服务没有正文能力时如实显示历史预览不可用，不能回读当前正文冒充历史。
3. 点击恢复为新草稿，确认文案说明将创建新草稿修订，已有发布内容不变。
4. 服务按当前草稿基线创建新修订，记录来源历史修订；原草稿和原历史仍可追溯。
5. 成功后进入新草稿预览，提示可继续编辑或发布。若基线已变化，保留选中的历史版本并要求重新核对。

### 在编辑中修改标题

1. 进入页面搭建工作台，在页面标题处编辑当前草稿的 `meta.title`。
2. 普通标题去除首尾空格并拒绝空值；随草稿一起保存，保持页面身份与 URL 不变。
3. 目录展示新名称；已发布内容的标题保持原样，等待人工发布。列表和详情不再有独立重命名入口或确认面板。

页面级标题修改不自动改正文里各组件的标题。参数化标题沿用结构化文本语义，在工作台编辑声明，不把某次参数解析后的文本悄悄写回固定字符串。历史页面缺少 `meta.title` 时按统一回退规则显示，标题编辑后显式设置页面标题。

### 复制

1. 从更多进入复制，明确复制当前查看的草稿或发布修订；建议预填“原名称 副本”，用户可修改。
2. 创建独立页面身份与新资源，首次保存为草稿；复制页面文档，不复制原发布状态、修订历史、本地未同步队列或操作记录。
3. 成功后在同一工作台打开新页面，明确显示副本身份与已保存草稿状态。原有查询、筛选、页面参数和内容结构保留；已有跨页链接继续指向原目标，界面说明需要时在工作台调整。
4. 复制不自动创建整套关联页面，也不自动重取数据或发布。内容中的时间与已有采集快照保持其原语义。
5. 创建结果未知时保留拟创建身份与原操作，停止再次创建并提供核实出口。

### 永久删除

1. 删除入口放在更多的末尾，与普通动作分隔。
2. 普通草稿用一次确认；曾有发布内容的页面要求输入当前展示名称确认。说明整个页面的草稿与发布内容将删除、历史不能恢复、后续发布访问将不可用。
3. 有本地未同步工作、未确认管理操作或页面状态未知时，先处理或核实，不通过删除清空这些事实。确认后服务核对页面删除基线，防止误删确认期间新产生的内容。
4. 服务确认成功后回原目录，保留条件并显示结果；若末页空了，回到上一有效页。
5. 发布读取和执行必须拒绝已删除页面。已经在外部浏览器加载的文档无法由管理页召回；跨页链接不自动修复。引用检测不列为本期已具备能力。

## 异常旅程与操作克制

| 情况 | 页面行为 |
| --- | --- |
| 读取失败 | 保留上下文，原地重试 |
| 修改基线冲突 | 保留用户内容与选中修订，重新读取并核对后再操作 |
| 写入结果未知 | 持久化原操作，展示核实入口，不自动重发 |
| 身份或服务目标变化 | 停止原范围操作，保留原恢复记录，要求重新打开 |
| 预览中查询失败 | 保留已确定的页面与修订，按真实查询错误提示，不将失败当作页面不存在 |
| 历史正文缺失 | 明确此版本不可预览，保持历史选择，不展示其他版本代替 |

新建、编辑和复制不加多余的二次确认。发布、恢复、删除各有一次与具体后果对应的确认。通知只报告成功、失败或需要行动的状态；不在每次筛选、返回和切换预览时弹消息。

## 公共平台与外部服务配合

本仓负责管理界面、导航状态、统一预览、工作台接入、页面资产公共消费契约与 Adapter 转换。Java 存储、修订和服务实现归提供方；Relay 接线与保存回执同步也需按实际消费者单独核验，不在本仓复制外部实现。[服务所有权](../adr/0070-consume-host-java-page-assets-api.md)。

| 配合项 | 产品所需保证 | 当前契约情况 |
| --- | --- | --- |
| 目录摘要和查找 | 返回可展示标题；全目录搜索、排序、分页、可信总数 | 只有描述、状态和分页，没有搜索与排序参数 |
| 草稿与发布隔离 | 保存只更新草稿；发布绑定精确修订；发布读取与执行消费发布内容 | 当前为同一资源状态更新，不提供隔离保证 |
| 历史正文 | 按稳定历史身份读取确切页面定义 | 当前只有摘要 |
| 安全恢复 | 核对草稿基线，追加新草稿修订，保留历史和发布引用 | 当前 rollback 不承诺这些行为 |
| 永久删除 | 按已确认页面身份整体删除并停止后续发布读取和执行 | 当前只声明删除指定资源记录，历史和访问后果未明确 |
| 操作核实 | 以原操作或精确状态证据判断结果，不把最终一致下的一次未查到当失败 | 当前缺少通用核实闭环 |
| 现有资产兼容 | 明确旧已发布记录的发布基线及历史映射，保留身份与链接 | 需要服务盘点与迁移策略，不能由前端猜测 |

目录仍按资源身份区分记录。同一 `pageId` 有多个资源时不能只保留最大修订，也不能只凭名称合并；必要时在辅助信息中显示短资源标识。复制使用独立页面身份，前端内部读取与写入继续携带资源身份。

这些是提供方配合需求，不是已存在的 API，也不是授权本仓实施 Java 服务。接口路径、具体存储方式、保留策略与发布原子更新方式，应在服务能力盘点后确定。必要的现行架构规则需更新 ADR 0080 的对应结论，再进入实施。

## 实施与验收顺序

1. 整体确认交互设计及建议默认值，盘点外部服务能否供给目标保证。
2. 冻结目录、草稿、发布、历史读取、恢复、删除和核实的消费契约，明确旧资产映射与回退方式。
3. 实现目录和详情的展示、导航状态与只读预览，并验证窄屏、短屏和键盘旅程。
4. 接入编辑标题、复制与精确发布；接入历史预览、安全恢复和整体删除。缺少服务保证时如实呈现能力未开放，不伪造成功。
5. 分别验证本地契约与状态逻辑、浏览器模拟、真实 Java/Relay 接入和发布访问；这些证据层次不可互相替代。

关键验收：保存草稿后发布内容哈希及访问行为不变；确认修订 A 期间产生修订 B 时不能发布 B；恢复历史 A 产生新草稿且现有发布引用不变；搜索与排序跨多页正确；名称修改不改变身份；复制没有原历史与发布状态；整体删除后新发布读取和执行不可用；未知操作不重发；返回目录恢复条件与位置。

回退时保持新草稿、发布引用和未确认操作记录。若旧版本无法理解隔离后的资产，先停用新写入并保留只读或修复入口，不能把新草稿覆盖回发布资源来伪装兼容。

## 实施默认值与外部条件

十三项关键决策、移除独立重命名及预览进入编辑已确定。沿用最近修改倒序、20 条分页；搜索名称、描述和 ID；详情有待发布修改时优先预览草稿；复制当前明确查看的修订并保留原跨页目标；标题编辑只改页面级标题；历史预览不承诺过去业务数据回放。正式实施前仍需核实服务能力及对应消费契约。
