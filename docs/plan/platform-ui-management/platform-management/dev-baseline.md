| F3-6 | 旧记录 | format 1/2 未决命令 | 原样保留，不自动重放；服务来源未知的记录不迁为新发送任务 |

### F4 — 接口

Java 消费沿用 service/platform-java.yaml；仅支持当前记录读写、历史摘要/草稿回退、删除当前记录。全目录搜索排序、标题摘要、独立发布读取、历史正文/追加恢复、复制、整页永久删除均保持受限。HTTP fixture 不是 Java 部署或真实门户验收。
