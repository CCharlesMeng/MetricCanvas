## 你该知道，但不用动

- **load 在既有复杂度基础上加入 localOnly 路径，当前共有18个 if 分支。**（`apps/platform/src/lib/workbench/authoring-coordinator.ts:257-305`）
  本地恢复、远端读取、旧记录保护及刷新保护集中在同一函数；修改读取策略时需核对多个早退和失效条件。localOnly 已有两个判定位置，增加遗漏相邻路径的维护风险，未观察到因此产生的当前错误结果。。建议：后续有读取策略修改需求时，提取存储范围及恢复记录读取函数，用具名策略决定恢复本地或读取远端；保留 load 对 scope、signal 和 finally 的统一失效处理。本建议不要求为本轮验收重写模块。
