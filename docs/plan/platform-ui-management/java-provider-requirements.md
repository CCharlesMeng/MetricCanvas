# Java 页面资产提供方配合清单

2026-10-12。MC 仅消费接口与验证，Java 存储、修订、索引、发布引用及历史保留由提供方维护。当前事实源：`service/platform-java.yaml`、平台 `page-assets/contract.ts` 与 `java-adapter.ts`。本清单不定义猜测的 URL/DTO，不声称现有服务满足目标。

| 能力 | 当前缺口 | 提供方需交付的保证/验收向量 |
| --- | --- | --- |
| 目录 | 仅状态与分页 | title 摘要；搜索覆盖全部有权记录的名称/描述/ID；排序/可信总数；跨页搜索及并发响应顺序 |
| 草稿/发布 | 单资源状态更新 | 独立可信内容引用；编辑草稿前后发布定义与访问保持；旧已发布记录映射 |
| 发布 | 无精确候选原子约束 | 确认 A 后出现 B 不发布 B；发布基线冲突可识别；原操作结果可核实 |
| 历史 | 仅摘要 | 稳定历史身份读取确切定义；不可读历史明确失败，不返回当前正文替代 |
| 恢复 | rollback 不承诺追加 | 基于当前草稿追加新修订；历史与发布内容保留；并发冲突停止 |
| 删除 | 单记录 DELETE 204 | 身份与基线核对；涵盖草稿/发布/历史；后续发布读取及执行拒绝；已下载内容不可召回 |
| 未知结果 | 无通用查询闭环 | 已发生/未发生/无法确定的可信证据；原操作核实；最终一致下一次未查到不当失败 |
| 旧资产与旧客户端 | 未提供迁移盘点 | 真实旧资产样例、发布引用/历史映射；新双引用模型启用前阻止旧单资源写入破坏 |

请提供正式版本化协议、字段/错误闭集及可用测试环境。MC 在获得依据后扩展公共消费能力与 Adapter；夹具、本地浏览器、真实 Java、Relay/身份、门户和发布读取/执行分别留痕。当前未获保证的目标功能保持未开放；已有资源 ID 与 URL 不改变。
