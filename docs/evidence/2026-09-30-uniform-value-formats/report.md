# 统一单位与完整结果验收

采用用户确认的固定单位策略，不新增 compact-adaptive。同一查询字段及相同业务单位的度量统一使用原值、万或亿，图表轴、标签、Tooltip 和表格继承 defaultFormat。固定格式保留一位小数，任一非零值可能舍入为零时退回较小单位。已明确提供的格式优先；已有万元等尺度不重复缩放；不完整或总数未知的结果不替未见数据选择尺度。

原值模式显式写入 number，避免柱状图旧的隐式万格式覆盖。金额不再自动使用逐值变单位的 cny-adaptive。reportForecast 数值轴不再用第一个系列覆盖共享轴的格式判定。现有页面格式枚举和版本未扩展。

普通查询模型证据与初始数据保留全部返回行，显式容量上限超出时返回错误。未分页的部分初始结果触发重新查询。完整未分页表格默认提供 20 行分页，分类柱图/折线图提供滚动窗口，均保留全部数据。只有用户明确要求 Top N 才允许按排序限制排名，本批未新增 Top N 查询协议。
