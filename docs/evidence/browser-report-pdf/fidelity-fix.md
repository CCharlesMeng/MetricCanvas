# 导出与页面呈现差异修复

2026-10-14，承接背景与完整图表修复，核查并修正多列布局、卡片尺寸、标题渐变、间距及响应式上下文。旧验收记录保持原样，本记录说明后续实现与复验。

## 原因

1. 编码 iframe 的样式把 `.section-grid`、`.cell` 改成全宽 block，并把分区间距替换成 6mm，破坏了页面的列轨与间距。
2. 样式复制只保留部分 CSS，遗漏 height、min-height、嵌套 Grid、行对齐轨等属性。浏览器复现中并排的 349px × 120px 卡片变成竖排的 718px × 48px 卡片。
3. html2canvas 不能正确绘制渐变文字的字形裁剪；旧示例改用纯紫色补偿。撤掉补偿后，像素检查确认截图器会绘制整块渐变矩形。
4. 静态视图脱离 `mc-runtime` 容器、使用另一套宽度与盒模型。组件因而采用不同的响应式规则；图表在挂载后才修改宽度，还会把尚未缩放完成的 Canvas 误判为过宽内容。
5. 原分页器只支持一张续页表头。恢复多列后，并排表格需要同时保留各自表头。

## 改动

- 静态视图在挂载前捕获当前页面的内容宽度、容器宽度、主题、内容与分区内边距及间距，复用页面的 border-box 规则。保留封面允许的铺满外边距，不把它误判为横向内容。
- 编码文档复制完整计算样式及有内容的伪元素，不再强制单列或覆盖分区间距。A4 缩放与分页由编码器处理。
- 渐变文字通过浏览器 SVG/HTML 绘制为局部透明图片；正文仍逐页截图，不生成全报告巨型 Canvas。
- 短卡片保持完整，并排表格续页同时绘制各自表头，按最大表头高度占位。
- 完整数据、期间文字、取消清理、失败不下载部分结果等既有行为保留。页面正常阅读不使用编码文档的样式。
