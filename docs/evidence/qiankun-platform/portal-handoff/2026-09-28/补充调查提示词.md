# 在内网仓执行的补充调查提示词

请只读补充调查 CBCBICloudBIWebsite 及可访问的真实子应用/网关仓。不要修改代码、安装依赖、登录真实账号、发送业务写请求或部署。目标是补齐 MetricCanvas 的真实接入契约，而非重新全仓盘点。

背景：MetricCanvas 已提供 HTML + UMD + CSS 微前端产物，主应用按前缀加载，平台管理内部 history 路由。GitHub 仅维护通用平台；门户变量、身份与网关映射、SDK、私有补丁、部署配置必须由内网独立项目维护，不能复制进 GitHub。内网 Adapter 在 mount 时将真实能力映射为平台配置，并负责自己的连接清理。平台本地 mount 不等待 SDK/业务网络。

请优先完成以下四组问题，每项附完整仓库相对路径、行号和脱值代码片段；分清源码事实、文档、推断、未找到与未运行。

## 1. Java/DQE 请求与身份链路（最高优先级）

- 找一个实际子应用调用 CDINL2DataBuilderService/user-page-metadata 或 DQE dsl/execute 的调用点。若没有，找同网关同鉴权机制的最接近实例，但明确替代证据。
- 展示浏览器构造 URL、fetch/axios 配置、headers、credentials，到 /rest 网关再到后端鉴权的路径。
- authToken、operatorId、workspaceId 是否真的必填？来源分别是什么？服务端认 Cookie 会话还是 X-Auth-Token/X-Operator-Id/X-Workspace-Id？是否由网关从会话注入/覆盖这些头？定位转换与鉴权代码。
- cftk 仅作 CSRF 校验还是还有其他用途？appId/x-language/X-Requested-With 对这两类服务是必需、条件必需还是惯例？不要把主应用 Angular 拦截器自动等同于子应用请求行为。
- workspaceId 的业务含义是什么，有无真实来源？不要用 siteId/appId 默认替代。说明 operatorId 应映射哪个用户字段，列服务端依据。
- 登录失效如何处理？身份/角色/工作空间变化是否一定整页重载，能否原地改变？若有事件，给 subscribe/unsubscribe 的真实接口和触发时机。
- 输出一份脱值请求样例（不要实际写入）；不要输出 token、Cookie 值、真实用户资料、密钥。

## 2. 精确 loader 基线与真实子应用样例

- 从 lockfile 确认 qiankun、single-spa、import-html-entry 的实际解析版本与 patch-package 执行位置，不能只读 package.json。
- 提供 qiankun 私有 patch 全文或完整相关 diff，解释全局变量、样式、事件清理变化。
- 找一个当前工作的子应用仓：其 HTML、入口生命周期、生产构建配置、资源 publicPath 和路由 base。
- 给实际生产入口结构或脱值构建样例，明确 UMD/IIFE/ESM；不要用未构建的 import/export 示例冒充产物。
- 确认 activeRule/name 的生成规则、前缀边界、范围内导航保持实例，以及主应用对未知 query 参数是否保留。
- 如只能访问主应用，明确缺子应用代码，列出需提供的最小文件。

## 3. 盘古共享实例与就绪（不阻塞人工路径）

- 锁定实际 SDK 版本、loader 与动态依赖版本；确认是否存在 pangu.instance(id)，实例是否提供 renderChat/destroy。
- 给 SDK 类型/源码/既有调用证据；全局 renderChat/closePangu 不等于实例 API。
- 是否允许门户云宝与平台内对话同时存在？谁拥有脚本、全局配置、DOM、事件和实例销毁？
- afterMount 后才加载时，子应用如何订阅就绪？如何取消等待或清理迟到初始化？没有接口就说明未找到，不要求子应用 mount 等网络。
- Relay 的浏览器可信程序 Adapter 是否已有？若存在只给接口与身份绑定方式，不输出业务对话内容。

## 4. 内网独立交付方式

- 应用注册表/权限/菜单由谁登记，entry 与 WCM 覆盖谁优先，最终 HTML 地址如何形成？
- 内网独立 Adapter 项目能否把一个经典 JS 脚本放入子应用 HTML，排在平台 UMD 前由同一 loader 执行？确认 CSP、沙箱可见性、预加载和脚本顺序。
- 平台、Adapter、环境配置如何独立锁版本、组合部署、校验摘要、回滚？优先复用现有流水线，避免要求 GitHub 构建携带内网配置。
- 本地联调由同源代理还是独立资源域提供？列脱值配置结构及负责人。
- 提供离开 guard 的真实支持情况；不存在则明确跨区域无法保证阻止卸载，不发明接口。

交付：一页阻塞结论；Java/DQE 身份字段映射表；版本与 patch 清单；真实子应用最小样例；SDK 能力与时序；内网 Adapter 的输入/输出及剩余责任人。附每个仓库 SHA。只读调查不能标成生产验收通过。
