- U03：未用截图替代组件；地图背景和缺失装饰资源不补造。浏览器视觉仍待主验收。
- U04：全部数据源为明确 inline 演示数据，没有 DQE query、服务器或网关声明；筛选联动和分层地图下钻因此不完整。
