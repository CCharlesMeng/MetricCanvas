# ioc-project-overview 页面特征摘要

## 业务内容与阅读目的

页面用于在一个宽屏概览中同时扫描全球/区域机会点、项目分层分级、复盘执行、地域管道支撑率和代表性项目明细。数据期间为 2026-03，金额原值均为元；输入 CSV 是匿名合成演示数据，其中汇总样例与代表性项目样例粒度不同，不能相加对账。

## 信息层级

1. 顶部是“全球/区域作战地图”标题与月份、仅看重点国代、地域、项目等级、产业筛选。
2. 第一层业务摘要由三张并列白底业务卡组成：机会点概况、项目分层分级管理、复盘总结。每张卡内部保留主指标、比率或变化，以及完整分类值。
3. 第二层以地域地图为主要视觉内容，地图旁是“概览 / TOP预签项目 / 丢单项目”三类明细切换。
4. 明细表承担完整字段读取、数值排序和项目详情入口；窄屏时应由表容器承接横向内容，而不是压缩丢列。

## 展示关系

- 机会点概况同时呈现数量、预签金额、年度销售预测、环比增减、管道支撑率，以及卓越/战略/核心分类演示值。
- 项目分层分级卡同时呈现已立项数量、已立项预签金额、立项率、近60天项目分析会召开率、赢单率，以及公司特级/公司级/地区部级/代表处级分类演示值。
- 复盘卡呈现应复盘、已复盘、复盘率和金牌/银牌/红牌/黄牌数量。奖惩颜色代表固定类别，不表达数值正负。
- 地图以世界底图国家作为可着色几何单元，用代表国家承载业务地区标签；提示展示地区、机会点数、预签金额、年度销售预测和管道支撑率。没有输入数据的地区保留未知值，不补零。

## 交互

- 筛选器有明确默认状态，但 inline 数据不会随控件值重新计算或过滤，因此控件只表达当前选择，不能视为取数联动完成。
- 三个 Tab 切换到不同数据表；金额和百分比列保留数值字段并声明可排序。
- TOP 项目名称、丢单机会点名称声明到 `/pages/ioc-project-detail` 的导航，传递项目标识和当前月份。
- 地域访问目标是全球→地区部→代表处→机会点清单；当前输入只能可靠呈现全球层的地区汇总和一个静态清单入口，缺少代表处层级全量地图行及真实查询联动。
