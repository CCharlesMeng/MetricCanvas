## 页面职责与范围

展示全球/区域机会点状况、项目分层分级管理、复盘情况和地域差异，并提供从汇总走向项目明细的入口。本次只做页面内容，不生成门户全局导航、另外三个页面或生产接入。新页面 id 为 ioc-project-overview；导航目标可声明 /pages/ioc-opportunity-list 与 /pages/ioc-project-detail。

## 可见内容

F01 页头：全球/区域作战地图。日期、仅看重点国代、区域、项目等级、产业选择。设计参考日期是示例日期，不是当前系统日期。可独立输入的日期筛选按测试样例月份设计；设计稿显示日点，业务数据采用月粒度，不能隐式将日值当月值。
F02 机会点概况：机会点数、总预签金额、年度销售预测、机会点数及金额较上月的增减、年度管道支撑率；卓越/战略/核心三类的数量和预签金额。数量单位个，金额原值以元计，显示单位明确。
F03 项目分层分级管理：已立项数量与已立项预签金额，公司特级/公司级/地区部级/代表处级四类数量与金额，立项率、近60天项目分析会召开率与赢单率。图形表达分类分布，不能让图形替代类别和值。
F04 复盘总结：应复盘、已复盘、复盘率；及时奖惩含金牌/银牌/红牌/黄牌数量。不同颜色的含义明确，不把分类颜色当正负数。
F05 地图：世界地域分布，至少覆盖中国、欧洲、亚太、中东中亚、北部非洲、南部非洲、拉美、俄罗斯。地域着色/标记与管道支撑率有关；图例为0、1%~50%、51%~80%、80%以上。提示可看地域名称、机会点数、预签金额、年度销售预测、管道支撑率。原图背景资源缺失，图形完整性后续独立验收。设计文字中“管道支持率”和“管道支撑率”并存，本测试统一用“管道支撑率”。
F06 明细区：概览、TOP预签项目、丢单项目三种内容切换。概览至少显示排名、区域、代表处、预签金额、管道支撑率、项目分析会召开率、立项率、本月新签单金额；分析会召开率与立项率使用各自口径，不互换。TOP项目至少显示项目名称、预签金额、年度销售预测、赢率。丢单项目至少显示机会点名称、预签金额、丢单原因。金额数值排序，不能按带单位的字符串排序。列完整且可访问。
F07 信息层级：原始设计中，分析内容包含机会点概况、项目分层分级管理、复盘总结三块白底卡片，地域地图为大块视觉内容，表格有明确切换入口。门户页外框不属于本页面。原图宽屏内容布局以截图实际能观察到的部分为准；截图资源缺失不证明空白区域就是需求。窄屏优先确保内容可访问，可采用表格内部滚动，不要求将所有列塞进窄视口。

## 独立数据与口径

data/aggregates.csv 是本次新编写的匿名汇总样例；data/projects.csv 是代表性项目样例，不与汇总行相加对账，不是完整业务项目集合。金额均为元。用你自行设计的稳定字段 id 和显式契约表达；不复制任何历史查询字段或 Page 结构。
- 机会点较上月增减=本月机会点数−上月机会点数。
- 预签金额较上月增减=本月总预签金额−上月总预签金额。
- 管道支撑率=剩余有效机会点金额÷(年度目标−存量预测−已实现收入)，显示百分比。分母0的样例结果取0；保留非零结果真实数值，不钳制超过100%的比率。
- 立项率=运作中已立项数÷应立项数；项目分析会召开率=近60天已召开分析会数÷近60天应召开分析会数；赢单率=赢单数÷已关闭机会点数；复盘率=已复盘数÷应复盘数。本次分母0统一取0，是测试样例口径，不声称生产口径。
- 原图没有证明这些指标共同使用相同的分母，不能互换。
- 提供基础数值的场景用Skill允许的具名算子表达派生值，无法表达时单列，不把没有来源的常量伪装成计算结果。
- 源图分类分布缺独立精确数据，允许你另外生成分类演示行并标明其性质，不把分类演示行与汇总样例强行等同。
