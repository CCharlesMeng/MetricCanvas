# 创作期结果字段契约来源核查

日期：2026-09-23。范围：本仓平台创作主流程；仓内调查样本是历史响应，不是本轮内部服务联调。

## 已核对的材料

- `调查报告/数据/tokens的dqe查询结果.json`：`results[0].data` 的实际行键为 `Tokens流量` 和 `周期(month)`；`columns` 同时给出 `caption`、`alias`、`id`、`level_type` 和格式 JSON。该样本的时间请求使用 month 粒度。
- `调查报告/dqe.md`：DSL 的 `output_dims` 使用基础维度名，公式指标使用 `{formula, alias}`；执行项返回 `data` 和 `total_count`。
- `docs/plan/2026-09-20-data-context-semantic-evidence.json`：公式中存在除零时返回 null 的表达式，并记录一处名称与公式时段冲突。该文件声明为讨论证据，不充当执行契约。
- `调查报告/DataFilterType 数字格式规则说明.md`：同为百分比或金额存在不同缩放和显示规则，不能由单位或名称唯一确定。
- 中立 Schema 元数据、`data/executable_units.py`、`data/source_mapping.py`、`data/query.py`、DQE HTTP Adapter 和页面字段校验。

## 来源与处理结论

| 所需信息 | 已有来源与验证 | 处理 | 仍需内部核对的精确缺口 |
|---|---|---|---|
| 规范字段名、角色、类型、单位、可空性 | 数据上下文快照的指标和维度声明；DQE 行值验证 | 内部派生；别名仅用于发现，不能当输出键 | 某些真实执行若输出重命名，需提供该查询的实际列键和对应选择 |
| 时间粒度列 | 查询定义的 `output_dims` 与 `filter.time.period`；已给样本返回 `周期(month)` | 内部派生 `基础名(period)`，页面校验兼容既有基础名映射 | 其他粒度或服务版本若返回不同命名，给出响应列和行键 |
| 公式列 | 查询定义的 `formula` 与 `alias`；历史语义公式可返回 null | alias 作为输出键；公式字段保守声明 nullable | 真实 DSL 对临时公式的类型、列名与非空保证若有不同需回传样本 |
| 重名、别名 | 查询定义和实际行键；同一结果中的映射必须唯一 | 先拒绝重复输出名，再验所有返回行 | 同名不同投影若确需并列，需确定性区分后的真实输出键 |
| 返回行和空结果 | DQE HTTP `data`；共享行校验 | 所有已返回行逐字段验真；空结果依声明，不能推断类型 | 无 |
| 新页面的稳定字段 ID | 数据上下文版本、业务域、查询定义中的选择身份、公式表达式和时间粒度 | 内部生成按选择稳定的页面作用域 ID；不宣称它是上游永久 ID；已有页面字段 ID 不迁移 | 若跨数据上下文版本追踪同一逻辑字段，仍需上游稳定身份映射 |
| 金额、百分比尺度及显示格式 | Schema 元数据可给 unit，历史响应 `columns.cell_value_data_format` 可给格式事实，但当前中立快照与执行端口未保留完整尺度语义 | 未知时保留原数值，不自动转换或套百分比、金额格式；已有额外描述可选提供并严格验证 | 需要特定格式时提供按字段绑定的比例、币种、基准单位及版本化来源 |
| 外部重命名、logicalId、projectionId | 现有额外描述提供方契约 | 可选扩展；存在时仍核对查询摘要、上下文版本、字段覆盖、尺度及行值 | 只有真实输出与内部规则不同时才需装配；不能以显示名冒充永久身份 |
| descriptorRef、descriptorVersion、providerNamespace | 仅额外描述契约使用 | 内部派生路径不再需要；可选扩展保留审计字段 | 无 |

结论：一般受治理查询不需要额外的“源描述服务”。本仓平台查询在提供方缺席时派生新的字段 ID、按样本修正时间列并验证全部行；已有提供方仍可选择装配，覆盖重命名或明确的尺度语义。此结论不证明所有内部 DQE 形态均已覆盖，遇到未能确定的真实列名或尺度时应限制该查询或呈现格式，并按上表回传精确样本。

## 兼容边界

已有页面局部编辑沿用原文档 `dataSources` 和字段绑定，不改写旧 `field-1` 或额外描述路径的字段 ID。新平台查询的 ID 不依赖输出顺序；同轮查询引用仍受 binding、数据上下文版本与授权约束。时间列在页面校验中增量接受 `基础名(period)`，既有基础名页面仍有效。保存前后的查询定义与预览行键保持一致。
