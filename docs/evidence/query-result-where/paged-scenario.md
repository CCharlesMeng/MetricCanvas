## 已实现及数据范围

项目清单使用查询分页，80行本地仿真数据，初始金额降序，每页10行。编号、名称、状态、金额和执行周期均可提交服务端排序，Shift追加多列；每次排序回到第一页。翻页和每页10/20/50条选择改变上游查询窗口。

两组评估只消费当前窗口的进行中项目，分别按金额>300万元与≤300万元筛选，再提取项目编号集合。上游保留当前窗口所有行；下游请求只有编号维度条件，没有上游页码或窗口参数。空集合直接呈现空结果。

调度使用现有依赖图，支持分支、汇合和多层传递；受影响下游分页回到第一页，旧请求取消且迟到结果被忽略。无关查询保持原结果；选中字段集合相同可复用缓存。

共享单次执行使用第一页窗口；导出重新取捕获时的当前窗口与依赖结果，保留排序和修改后的每页大小，普通无级联分页表继续完整导出。
