## 关键行为

- 组件目录只推荐明确演示该组件且实际包含该类型的变体；不会因为业务页碰巧包含组件而自动推荐。Dashboard 与 Report 目录也按实际声明筛选变体。
- 同一场景跨组件与数据目录复用。相同变体的实例保持，已应用的表格或图表筛选不会因切换阅读入口而清空。
- 跨页流程保留显式传值；演示到达清单或详情后，变体、说明、配置和试改输入同步到目标页。通知只接受同源、当前 iframe 和当前场景引用范围；其他页面不改变目录选择。
- 当前场景试改带入实际 JSON 和可信场景绑定的网关、展示输入与初始条件。编辑 JSON 的 id 不决定适配器；草稿不写回文件。
- 全部文件目录移至 `/files`，保留组合筛选及滚动快照。推荐目录的搜索、主题和变体进入自己的 URL；详情回退返回实际来源目录。
- 临时评测不进入默认推荐搜索，可通过次级入口找到全部 25 页。普通文件仍自动发现，不要求登记推荐场景。
- 复用 `@metriccanvas/ui` 的 Tabs、Select、Input、Textarea、Button 及原页面正式组件；没有替换产品控件样式。

## 浏览器观察

表格精确搜索「星河项目」返回两行，不含「星河项目二期」。局部指标切到订单量，合计为 5,579，跨到数据目录后仍保留该选择。内联与查询子表都显示 `C01-001` 起的明细。跨页详情实际回显 `project_code=P&中文/001`、`sales_month=2026-09`、人民币及南北区，旁边说明同步到详情。

当前 JSON 试改可变更页面标题；非法 JSON 明确显示语法错误，恢复按钮还原当前示例。目录返回保留文件搜索，推荐搜索的浏览器历史恢复关键词。IOC 集中状态入口可切到只读，产业控件禁用。维度方向键导航修正为保留焦点，实际可由数据与联动切到布局。

报告在聚合 iframe 内触发下载后，工具未收到下载完成事件；未据此判定产品失败。通过「独立打开当前页面」在同一浏览器完成 PDF 下载并取得文件路径。内嵌下载回执仍单独标为未确认，PDF／PNG 的完整视觉与文件内容没有在本批全量复验；导出准备与结果范围由上述运行时回归覆盖。
