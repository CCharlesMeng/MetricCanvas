# 选择面板间距检查（2026-10-24）

用户截图入口：`http://127.0.0.1:5173/pages/table-cell-selection`。

## 原因与修复

`@metriccanvas/ui` 的 `Select` 与运行时维度筛选器共用 `Selection.svelte`。主题仅给 `.mc-ui-option[data-tag=mc-ui-option]` 设置选项 padding，而当前组件没有此属性，实际回退为浏览器按钮左右 6px；搜索栏左右为 16px。选项按钮同时没有铺满面板，悬停与点击区域随文字宽度收缩。

组件局部恢复现有 `--tv-Option-padding`（左右 16px），并设置 `width:100%` 与 `box-sizing:border-box`，覆盖普通候选、清空、全选和重试行。多选行的 `gap:8px` 与主题 SVG 的 `margin-right:8px` 曾叠加成 16px，局部清除 SVG 外边距后恢复 8px。未修改固定主题资源、树层级缩进、公开 API 或页面协议。

## 检查范围与结果

- 修复前实际页面：选项左距 6px；第一行宽 40px，面板宽 240px；搜索栏左距 16px。临时浏览器断言期望 16px，实际 6px，退出 1。
- 独立 UI 页面同样复现，排除 Playground 页面覆盖。临时补主题属性只恢复 padding，不恢复整行宽度，确认两处独立缺失。
- 单选、多选、树选择、重试和空状态：普通 DOM / ShadowRoot × 1440px / 390px，共 20 组。普通候选行及操作行左右均为 16px、行宽等于面板宽；多选图标到文字 8px；树首个展开图标距面板 16px；状态文案 padding 16px；弹层均在视口内。
- 单选候选和重试按钮的右侧空白可点击；单选禁用项仍不可选。
- 实际 `table-cell-selection` 页面选择中国地区部，明细保留 3 行，排除华南地区部；桌面与 390px 截图通过。
- 实际 `table-search-options-demo` 表格搜索字段下拉：16px 内边距，点击选项右侧空白成功切换项目编码。
- 同类排查：主题中仅该选项 padding 规则依赖 `data-tag`；Dropdown 已显式设置左右 16px 和整行宽度；树、状态文案、日期弹层、数值范围及旧 MultiSelect / TreeSelect 各有独立 padding 规则，没有相同的主题命中缺失。现有 UI 浏览器套件覆盖输入、页签、分页、菜单、日期与弹层交互；不据此宣称所有组件的全部视觉状态均已验收。
