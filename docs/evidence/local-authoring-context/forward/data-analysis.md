# 页面用数匹配报告

当期签约金额已有事实：签约月份、可用维度 `region_name`，组织/月可求和；业务口径为统计期内已签约且未撤销合同、按合同编号去重。累计签约金额已有事实：从当年年初到所选月、组织可求和、跨月不可再次求和。这些是候选分支事实，不表示已为页面选择分支。

达成率返回 `0..100`，42 表示 42%。Skill 的 `fields.format` 说明 `percent-*` 直接加百分号；原页 `percent-1` 与该刻度兼容，无需乘 100。金额 `compact-wan-1` 是展示缩放，不能把查询源的“元”改成“万元”。本次不修改呈现。

需要优先补齐的共用问题：

1. **时间范围与粒度**：统计哪年哪月或起止范围？达成率是否与金额同期间？
2. **组织/区域范围**：全量还是指定组织？固定条件需要合法编码，`华东示范区` 仅是合成值。
3. **行粒度和消费方式**：表格是否每区域一行？指标卡显示汇总还是指定区域？原单行演示不证明多行情况下的选行/汇总意图。未确认前不能折叠现有行或平均比率。
4. **金额口径**：当期还是年初累计？两处金额共用字段，需统一选择。
5. **达成率契约**：DQE 标识、目标金额、分子分母、零分母、维度和跨区域汇总方法。
6. **完整性与分页**：页面表格 `pagination.mode: none`，未声明排序；服务输出是否完整、限制与排序分页方式仍未知。不能默认为未截断。

页面未声明筛选器/参数，所以不存在可据以填写的筛选或参数绑定。没有可信连接键或基数，不能推导跨表连接。共享数据源能否同时满足区域明细与卡片范围，需要先澄清消费契约。
