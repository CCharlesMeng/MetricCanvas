# 合成页面用数分析示例

输入是仓内演示页面与合成指标说明。本报告由作者按原文补全，用于演示可审阅产物，不是独立模型评估。

| 页面元素 | 字段 | 匹配 | 条件与缺口 |
|---|---|---|---|
| amount-card、summary-table | amount | 多候选 | 文档有当期/累计两种口径，需用户选择；统计期间未给 |
| rate-card、summary-table | rate | 未解决 | 百分刻度已知；缺分子/分母口径、零分母规则及DQE标识 |
| summary-table | region | 有据匹配 | MD明确声明region_name；页面没有固定地区筛选，不从演示行推断业务范围 |

先补全共同统计期间，再确认金额口径及达成率定义。5个字段位置合并为3个问题。保留原页面，不生成未验证initial，不宣称真实查询成功。逐条证据行号、原文及输入哈希见analysis-reviewed.json。
