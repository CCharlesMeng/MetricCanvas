# 普通查询完整性验收

普通查询不再默认截取 20 行：模型证据、页面初始数据保留全部返回行。显式部署容量上限超出时返回 MODEL_EVIDENCE_LIMIT，不丢行。只有用户明确要求 Top N 且排序依据已确认时才允许限制排名；本批没有增加 Top N 查询协议。上游本身不完整或总数未知仍保留覆盖缺口。

完整的未分页表格超过 20 行时，运行时提供本地分页；显式 pagination 配置优先。页面协议保持不变。分类柱状图和折线图增加滚动窗口，保留所有分类与系列值。未分页的部分初始数据不再阻止重新执行查询。
