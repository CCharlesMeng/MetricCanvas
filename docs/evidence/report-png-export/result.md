## 实现

Schema 6.30在Report顶层页头增加`pngExport: {filename?, scale?}`；默认3倍、可选4倍。既有仅PDF页面保持原按钮，同时启用时共用菜单。平台属性面板可启用、改倍率和文件名，保存重开保留配置；PNG名称和文件名在生成时捕获。

数据准备沿用既有查询作用域、表格状态、部分数据和完整性策略。静态视图从开始就在独立iframe文档中挂载正式组件，组件自带注入式CSS，字体资源与受限主题单独带入；不复制门户样式、伪元素或URL背景，不隐藏原页面水印。图表及渐变文字按3/4倍原始绘制。

有界截图按整数像素行进入Worker的单个Zlib流；使用fflate 0.8.3、RGB8/Sub过滤，一个IHDR、连续IDAT和一个IEND，始终只保存一张完整PNG。失败、超限均不下载半成品、不降低倍率或改格式。PNG最多一块截图在处理；不创建整图画布。既有PDF继续A4连续分页，并从顶层文档发起下载，避免沙箱阻止保存。

沿用每结果10000行、准备60秒和编码无进展60秒。整图宽8192、高32767、面积134217728像素，单块16777216像素，编码128MiB；这些是支持预算，不能据单个样例声称最大预算已在所有查看工具验收。结果最多保留5分钟，保存/关闭/过期及实例更新/销毁释放。
