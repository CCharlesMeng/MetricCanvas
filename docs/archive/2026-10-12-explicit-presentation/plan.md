## 已确认的需求

用户确认颜色是通用的页面声明能力：决策时长增加为红、减少为绿；效率最好榜的时长固定绿、最差榜的时长固定红。颜色规则由页面元数据就地声明，统一运行时不根据字段名称、页面 id、Top/Bottom 名称或查询排序推断业务好坏。

最终采用 `red` / `green` 的直接颜色声明，保留 `colorRule` 的固定与正负两种模式；不采用 `good` / `bad`、`tone` 或组合业务含义命名。普通文字颜色是未染色状态，不是第三种可选业务色。

图表的系列图例与绘图区需要分开；类别名称尽可能全部展示，允许倾斜，先展示实际效果再由用户判断密度。使用现有 ECharts 配置与文字测量能力完成实现。

新增要求：本页所有柱状图、折线图及柱线混合图的每个有效数字数据项均常驻显示对应数值标签，不依赖 hover；混合图中的柱与线分别显示各自数值。

## 当前事实与证据边界

- 表格 `visual: "signed"` 按原始值正负染色，正绿负红，零与缺失中性，没有列级固定绿/红和反向映射。
- 指标卡 `changes[].tone` 支持固定颜色与自动正负规则；本页使用自动规则。箭头当前跟颜色绑定，需要拆开。
- 本页决策人 `bottom10` 是最快榜、`top10` 是最慢榜；代表处 Top10 也是时长最长榜。声明必须按真实业务场景填写。
- 本页代表处图采用 `barChart` 的显式柱线混合分支。这个分支使用共享 GRID 和顶部系列图例，没有声明类别标签显示策略。普通柱状图与折线图在类别超过 20 个时另有默认窗口行为。
- 折线图已有 `showPointLabels`，普通柱状图已有 `showSegmentLabels`（主要为柱内标签），混合分支尚未处理节点数值标签。本页目前未启用这些数值标签；直接开启现有柱内标签不能完整满足“柱顶显示数字”的要求。
- 本地调用真实 `barOption` 和已安装 ECharts 的 SVG 渲染，在 1190×250 的绘图尺寸下，60 个代表处中仅 9 个名称出现在 SVG 文本中。此证据证明本地默认呈现会省略名称，不代表已复验用户浏览器或部署版本。

## 数字颜色的声明

新增共享的 `colorRule` 声明，第一批消费者是表格数字列和指标卡变化项。声明放在具体展示位置，与字段引用并列，不放在页面数据源的字段定义中：同一字段在两个位置可以合法地使用不同颜色。

第一期只提供两种互斥模式，可选颜色闭集是 `red | green`，不开放 CSS、表达式或脚本。这里声明的是颜色，`positive` / `negative` 仅表示原始数值的正负分支。

按正负映射的表格列示例：

```json
{
  "field": "avg-decision-time-change",
  "title": "平均决策时长环比上月",
  "align": "right",
  "colorRule": {
    "mode": "sign",
    "positive": "red",
    "negative": "green"
  }
}
```

固定颜色的最快榜列示例：

```json
{
  "field": "avg-decision-time",
  "title": "平均决策时长(天)",
  "align": "right",
  "colorRule": { "mode": "fixed", "color": "green" }
}
```

最慢榜声明 `color: "red"`。指标卡变化项采用相同的 `colorRule` 形状。不新增一套指标卡专属映射。

规则与冲突约束：

1. 一个展示位置只能有一个 `colorRule`；固定模式不能携带正负映射字段，正负模式不能携带固定颜色。
2. `colorRule` 与旧 `visual: "signed"`、指标卡旧 `tone` 同时出现时校验报错，迁移时移除旧声明。不给互相矛盾的规则设置隐藏优先级。
3. 不同展示位置独立执行自己的声明。没有页面级或数据源级颜色继承，也不自动合并另一个组件的规则。
4. 正负模式按原始有限数值判断，格式化不影响方向；零使用普通文字颜色，不需要声明 `zero`。例如正数四舍五入显示为 `0.0` 时，仍执行 positive 分支。
5. 固定模式对所有有效数字生效，包括零；缺失值始终显示为中性。声明全列绿色不意味着把缺失值判为改善。
6. 箭头按原始数值独立判断：正值 ↑、负值 ↓、零和缺失无箭头。颜色不控制箭头或数值正负号。
7. 红绿映射到现有统一主题颜色变量；页面不声明十六进制色值。允许主题管理具体色值，但不能交换红绿语义。
8. 本期规则绑定 `number` / `money` 数字字段；不与字符串枚举的 `dangerValues`、语义 HTML 内部语气混用。对不支持的字段类型或冲突声明校验报错，避免由 CSS 优先级决定颜色。

兼容策略：保留旧页面已支持的 `visual: "signed"` 与 `tone` 读取行为，其语义记录为历史规则；未声明新规则的旧页面不改变呈现。本页迁移到显式 `colorRule`。新创作需要染色的位置直接声明规则，不染色的位置不声明；不由运行时从“时长”“增长”等名称推断方向。

扩展策略：未来需要阈值或区间时，通过增加新的 `mode` 分支扩展，保持当前 fixed/sign 声明有效；颜色仍由统一闭集控制。本期不预设阈值、区间、表达式或新的颜色。

## 图表类别标签与间距

普通柱状图、折线图、柱线混合图共用受控的类别标签声明，建议形状：

```json
{
  "categoryLabels": { "mode": "all", "rotate": 45 }
}
```

`mode` 为 `auto | all`；`rotate` 是受控角度，具体范围在 Schema 中约束。缺省保留既有行为。对横向柱状图，该声明作用于类别 Y 轴；对本页图表作用于 X 轴。

`all` 的执行约束：

- 使用 ECharts 类别轴 `axisLabel.interval: 0`，不抽样跳过名称。
- 使用 `axisLabel.rotate` 旋转，关闭标签重叠隐藏，保留完整原始名称；不使用省略号或截断 formatter。
- 首尾标签明确展示，并为旋转后的文本预留空间。
- 展示整个类别集合，不执行当前“类别超过 20 个就默认只展示前 20 个”的窗口规则。
- 保留全部类别、系列数据与顺序，不通过减少数据点达到标签清晰。
- 允许图表随标签占用空间增加高度；如仍拥挤，以实际截图交给用户决定下一步，不自动退回隐藏名称。

系列图例间距属于统一运行时的通用几何职责：为图例及其换行、纵轴名称与绘图区预留互不重叠的空间，不向页面元数据开放 `grid.top` 等像素定位配置。优先使用 ECharts 的图例和 grid 布局能力，必要的空间测量集中在图表公共模块，不在各个图表分支重复实现。

ECharts 官方坐标轴说明展示了 `axisLabel.rotate` 和双轴用法：https://echarts.apache.org/handbook/en/concepts/axis/ 。`interval`、`hideOverlap` 等选项同时已从仓库安装版本的类型定义核对。实施时仍需在浏览器验证文字边界与图例换行，不能仅用 option 对象正确作为验收。

## 图表常驻数值标签

新增通用的 `showValueLabels: true` 声明，支持普通柱状图、折线图及柱线混合图。本页所有此类图表均显式启用；其他存量页面保持原有声明与显示行为。与类别标签组合的示例：

```json
{
  "categoryLabels": { "mode": "all", "rotate": 45 },
  "showValueLabels": true
}
```

呈现约束：

- 正值柱状图数字放在柱顶外侧，横向柱状图放在柱条末端；负值放在对应数值端外侧。堆叠柱逐段展示该段的数值，不以总计代替每段数值。
- 折线图每个有效节点旁常驻显示数字，优先位于节点上方。混合图逐系列独立执行，柱与线不能只显示其中一类。
- 数字使用对应系列字段的格式：组件绑定 `format` 优先于字段 `defaultFormat`，与同系列 tooltip 的单位和小数位一致，不改变原始数值。
- 有效零值必须显示；缺失值不生成假节点或 `0` 标签。
- 优先使用 ECharts 系列 `label`，必要时使用布局避让；调整位置、预留上下空间并在需要时增加高度，避免最高值标签被边界裁切或覆盖系列图例。
- 不通过重叠隐藏或抽样省略数值标签。允许必要的局部位置调整；过密时先保留全量并展示真实截图，由用户决定是否需要下一轮密度调整。
- 保留 hover 交互作为补充；常驻标签不依赖 hover，静态导出同样保留。
- 数值标签不自动继承表格的红绿规则，也不根据数字正负自行染色。

兼容与冲突：保留旧 `showPointLabels`、`showSegmentLabels`、`showStackTotalLabels` 读取行为。启用新的 `showValueLabels` 时，不允许同时开启旧标签开关，避免重复标签或由执行顺序决定位置。迁移时统一使用新声明；本期不额外展示堆叠总计。

## 商务 SDT 页迁移范围

- 指标卡中的决策时长变化：正红、负绿、零中性。
- 代表处与地区部表格的决策时长环比：相同的显式映射。
- 最快榜的主要平均时长列固定绿，最慢榜固定红，按实际查询口径确定所属榜。
- 环比列继续表达自身的改善或恶化，不继承排名时长列的固定色。次数与其他列不继承时长颜色规则；已有次数变化若保持当前颜色，须把原规则显式写入该变化项。
- 项目榜的阶段时长、次数、名称等列不随主时长列自动染色。
- 本页各柱状图、折线图、混合图显式启用全部类别标签；类别较多的图从 45° 开始做真实呈现验收。
- 本页各柱状图、折线图、混合图均显式启用 `showValueLabels: true`；代表处与地区部混合图同时显示时长柱值和次数折线节点值，近六个月趋势图逐点显示时长值。

3. 统一三条图表分支的类别标签、常驻数值标签与间距处理；验证容器尺寸变化和图例换行。
4. 更新本页声明；同步正式协议、参考示例、生成契约和 authoring bundle，生成文件通过现有导出命令更新。
5. 先验证显式规则的冲突拒绝、正负/零/缺失、固定色、颜色与箭头独立、同字段不同场景，以及旧版本不能声明新增能力。
6. 验证三条图表分支均在 all 模式保留并呈现所有类别；浏览器检查代表处 60 个名称、地区部与月份标签的数量、完整性、首尾边界及图例/绘图区不重叠。逐系列核对每个有效数据项都有常驻数值标签，包含零、负值和重复值；缺失数据不伪造节点。检查数字格式、最高值边界及混合图柱/线标签的对应关系。桌面和窄容器分别保留截图。
7. 静态导出视图复用相同颜色、类别标签和常驻数值标签策略，核对冻结图表未丢失类别和数值标签。生产 PDF、真实 DQE、内网部署分别报告，不把本地结果当作其通过证明。
