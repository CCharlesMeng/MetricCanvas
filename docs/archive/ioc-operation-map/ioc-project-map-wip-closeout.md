# IOC 项目地图 Schema 5.2 WIP 收口记录

## 结论

本轮把项目总览与项目详情页面元数据迁移到 Schema 5.2，并保留机会点明细列表的 Schema 5.1 契约。所有页面数据源仍为内联页面数据源；GraphQL、真实筛选枚举、地区编码、认证、权限与生产指标口径不在本轮交付。

## 设计源裁决

- 项目总览与项目详情：有效设计原型决定结构与视觉，既有文字规格决定字段、计算与交互。
- 机会点明细列表：继续以文字规格为准，保持 11 个筛选/搜索条件、40 列、分页和详情导航。
- `archive-not-a-source/opportunity-lits.html` 已失效，不是设计源；其中的 KPI 卡片和透视表结构不得迁入机会点明细列表。
- 历史设计审查记录保持原样，本文件记录本次裁决与收口结果。

## 已交付

- 项目总览：铺底地图、三张组合卡和总览 Tab；组合卡跨度为 4 / 4 / 3，Tab 下一行跨度为 4。
- 项目总览：四个百分比改由 `ratio.scale: 100` 计算且零分母返回空值；管道支撑率保持预计算值。
- 项目总览：地图保留八个地区部，六个未知编码继续使用 `TBD-*`；新增管道支撑率四档图例和包含年度费用的提示字段。
- 项目详情：基本信息单列；项目规范性用一张组合卡并列经营规范性与客户关系规范性；销售预测的十二个月、小计、总计和合并逻辑保持不变。
- 项目详情：叙事调整为六个展示区块；两个合成展示字段只存在于内联页面数据源中，不构成未来 GraphQL 结果字段契约。
- 机会点明细列表：结构不迁移，仅由回归测试保护 Schema 5.1、筛选、40 列、本地分页和导航。
- 通用能力：组合卡嵌套遍历、独立数据快照与加载状态、类别值稳定配色、地图安全区和编辑器原子化顶层编辑均由既有公共实现承载，不增加页面 id 分支。
