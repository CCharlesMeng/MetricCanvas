# initial 首屏复用修复方案

## 目标与范围

默认查询状态下，非查询分页数据源存在 initial 就使用其内嵌初始行，即使 rows.length 小于 totalCount，也不为补齐结果自动查询。保留真实总数，在组件旁提示“当前载入 N 条，共 M 条（部分数据）”。提示依据原始数据快照而非表格本地分页后的行数。

仅修改 MetricCanvas 统一运行时、组件宿主提示和正式协议说明；不修改 DQE、Relay、页面 Schema 或生成器。没有 initial、查询条件变化、查询分页交互继续查询。查询分页完整第一页检查、执行 bootstrap、页面参数失配和跨数据源计算一致性检查保留。未知总数不推断完整性。

## 实施与验收

1. 修改已有截断样本测试，增加空 initial、五数据源混合与缺失 initial 的覆盖，先确认新断言失败。
2. 非查询分页 initial 复用不再依赖完整性；查询分页继续按完整第一页规则复用。
3. 组件宿主使用全页数据快照提示部分数据；查询分页不重复提示，完整结果和未知总数不提示。
4. 运行运行时与宿主测试、类型检查；在 preview 粘贴用户原始 JSON 检查零 DQE 请求和提示。
5. 同步正式数据源说明；完成后归档本方案与验证结论。

## 回滚

恢复本次 initial 复用判断、提示接线与配套测试即可回到截断时自动查询；没有协议迁移或持久化数据变更。
