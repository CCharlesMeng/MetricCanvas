# 仪表 gauge

用环形刻度突出一个比率或完成度类 KPI。适用于管道支撑率、完成率、达标率这类单值百分比 KPI。数据形状：单行记录；一个 measure 数值字段。

取主数据源单行measure。运行时min缺省0、max缺省100；进度夹到0–1，非法范围不产生有效进度。variant唯一显式值mini，用于紧凑环形仪表。max在Schema必须大于0；这不代表任意min/max组合都有有效区间。
