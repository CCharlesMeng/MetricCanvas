# 页面试验场作为按需使用的开发工具保留

#102 去留讨论中，用户确认保留原 `apps/canvas` 的开发价值，并要求改名避免与搭建画布、渲染引擎和产品平台混淆；名称确认为**页面试验场（Page Playground）**，目录 `apps/playground`、包名 `playground`。

页面试验场保留仓库页面浏览与 JSON 即时校验、渲染，复用正式 `RuntimeView` 和共享运行配置读取器；不保存页面资产，移除旧 `VITE_PLATFORM_URL` / 平台 API 来源。它按需启动和构建，退出默认产品启动、构建与 CI 产物上传，但继续参加测试和类型检查。这样保留无需页面资产服务即可验证页面的便利，也避免维护第二套产品入口。

本决策补齐 ADR-0074 / #102 中该应用的去留单项，并收窄 ADR-0062 的参考应用定位；`MetricCanvas` 搭建画布、渲染引擎和平台的名称与职责不变。其余旧服务清理和平台静态化仍归 #125/#104，不能由本项完成替代。
