# 表格列声明默认筛选意图并复用会话查询视图

页面作者可以用 select 叶子列的 `filterable.defaultValues` 声明固定原始值；用户实际选择仍属于会话态。此条局部澄清 ADR-0086 的“表头条件不进页面文档”：持久化的是作者的初始意图，不是消费者每次操作后的视图。省略与空数组都表示初始无该列条件，其他筛选模式和行内子表不因此开放新能力。

默认值由共享执行层在首次有效读取前一次性转成现有 TableQueryView 谓词，TableSession 继续唯一持有已提交状态，UI 只投影和上抛操作。静态 main 字段和现有数据源所有权约束避免局部默认值污染共享消费者；inline 和明确完整且无窗口的结果保持实例内本地筛选。按需 pagedJoin 维持 ADR-0125 的单成员规则，默认条件和默认排序跨成员时拒绝，不逐列覆盖或隐式全量回退。

显式恢复视图完整优先，包括已清空条件；翻页、刷新、候选更新与普通业务条件变化不重新应用默认值。列隐藏清除条件，重显不恢复；组织父子表的完整重置恢复当前声明默认。失配已选值按 ADR-0114 保留，导出冻结当前已提交条件。普通 initial 和执行回执缺少视图证明时不能冒充已按默认条件读取的结果。

不把默认值写回查询定义或新增数据源级默认条件：前者使用户清空后仍受隐蔽约束，后者会影响共享查询定义及其他消费者。Schema 仅增一个属性；查询协议、网关端口和表格查询视图形状不变。实施方案与冲突清单见[主计划](../plan/2026-11-03-table-header-filter-defaults.md)。
