# 创作输入容错与同轮元数据快照

创作期的模型输入可以有轻微偏差，最终页面仍必须合法。可选展示值使用已有默认值，未知表现可在不改变字段与行选择时回落明细表；查询项与内容块分别校验，独立成功项继续。未知查询属性、业务范围和身份授权不能被展示兼容规则忽略。局部失败不等于整轮失败，核心证据不足仍明确未完成；工具返回具体调整与受影响位置。

完整且有覆盖证明的元数据在同一可信创作轮次内固定复用，发现、查询和结果消费不再各自重新读取整批 dataset。缓存身份包含完整可信轮次、数据源、数据集范围、凭据指纹与投影配置；只持久化在程序状态通道，身份/轮次检查和精确查询授权每次仍执行。新轮次、可信范围或配置变化产生新读取；partial 和超限快照不作为完整缓存。此决策细化 ADR-0091 的版本检查：采用该能力的 Adapter 检查与本轮固定版本一致，而不是每个工具调用都实时读取源版本。未采用的 Adapter 仍可按原方式读取，不能宣称已消除后端重复请求。

代价是同轮内不会仅因上游元数据变化立即刷新；实时权限撤销必须由可信集成上下文与授权提供方传达，不能依靠已取消的重复元数据 HTTP 偶然发现。禁止绕过取消/撤权；集成若不能提供这项保证，应先保持原读取方式。跨轮结果不自动借用，runId/requestId/contextRef 继续按原协议隔离，结果字符串可以直接用于 sources 映射。

只读瞬断可有界重试，成功结果不可变；失败或失联查询可通过受限执行尝试恢复。保存未知保持既有原操作核对，不自动重发。拒绝所有轻微偏差与建立通用自动恢复系统都不作为默认策略：优先采用明确默认值、局部隔离与现有状态存储。

补充：首次发布前允许对明确失败或缺失的 dataset 有界补取一次，保留初次成功来源。服务提供按 dataset 的最终一致性，因此合并快照明确标注 per-dataset，不要求不存在的跨来源原子版本。补取后仍缺失时，可显式固定保留授权范围内的可用模型；coverage 保持 partial，已取得来源可继续查询，缺失业务域不能猜测替代。私有查询视图携带覆盖 warning，neutral current() 保持完整性要求。发布之后不在原轮偷偷换版；进一步刷新建立新可信轮次。
