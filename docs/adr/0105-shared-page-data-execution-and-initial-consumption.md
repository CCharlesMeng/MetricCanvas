# Relay与浏览器共用页面查询执行，单次入口返回完整页面文档

报告召回需要在Relay环境执行已有页面查询。查询结果绑定形成的级联、参数物化、字段归一化与浏览器动态查询必须调用同一实现。只有共享Schema、另写Python调度不能满足同源目标。

新增纯TS/JS交付物`@metriccanvas/data-execution`，依赖`@metriccanvas/page`，不依赖引擎、Svelte或ECharts。提取既有数据网关端口、DQE适配器、生效查询构造及原始结果输入解析。引擎依赖新包，既有根入口类型与`./dqe`保留兼容再导出。新包与页面协议、引擎锁步发布；这局部修订ADR-0071的交付物与实现归属，不删除旧执行启动接口。

业务Interface为`createPageDataExecutor({gateway}).execute(metadata) -> Promise<PageDocument>`。参数值直接位于完整metadata的params，网关在部署初始化注入。每次调用重新查询主页面全部可执行query源，包括各Tab、辅助源和snapshot详情；query详情沿用点击后绑定上下文执行，同样消费查询核心。inline保留原行，Top5、初始分页窗口和完整辅助源维持声明范围。

成功源替换initial；源级失败或依赖失败不改原initial，独立源继续执行。内部依赖只读本轮成功的原始快照，保留的旧initial不驱动本轮下游请求。空上游以空结果结束下游，不发送无约束明细请求。非法文档或缺必需参数拒绝入口。输出只有完整页面副本，不增加执行封套、成功状态或计算快照；已有旧initial不能证明本轮查询成功。

initial继续序列化查询原始字段行；结果集合读取归一化原始维度，compute声明保留，引擎计算最终展示行。浏览器已有initial直接使用，缺失才补查，不因级联无证明或capturedAt不同重取整链。接受同条件刷新失败时跨采集时刻组合；填参入口在实际查询条件改变时清除受影响源及其依赖下游initial，同值初始化和展示参数修改保留数据。动态筛选仍使受影响链失效，保留取消与代次机制。此条明确修订ADR-0099的首版initial/回执无证明整链重取结论，不恢复任意结果输入或SQL。

Relay允许新增Node单次执行进程，直接使用共享DQE适配器，可信接入程序供给绝对端点、当前调用身份和超时。完整JSON通过程序通道输入输出，不把凭据放入页面。此条局部修订ADR-0060/0061的Python-only执行依赖约定，不新增常驻Node服务，不迁移Python创作期发现、查询生成、授权或真实查询验真。

返回文档用于本次展示，不自动保存发布，不新增采集快照存储，现行保存去除query initial保持。导出复用查询核心，但完整取数策略与具名算子计算仍归导出流程；共享单次入口不替代创作主计划的保存前计算验真。

未采用额外执行证明封套：用户只需要完整metadata，失败保留与缺失补查是明确消费约定。未复制一套Node专用规则：新包提取现有实现并保留兼容面。未统一成每次交互整页execute：引擎仍拥有交互生命周期，只共享查询核心。

裁决、代码影响与实施顺序见[实施主计划](../plan/2026-10-14-shared-page-data-execution.md)。本地测试、独立安装、浏览器与真实Relay/DQE证据分别报告。
