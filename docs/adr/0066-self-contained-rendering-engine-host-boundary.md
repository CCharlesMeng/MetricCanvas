# 渲染引擎提供固定呈现与 JS 挂载入口，应用集成归宿主

[#97](https://github.com/CCharlesMeng/MetricCanvas/issues/97) 与 [#98](https://github.com/CCharlesMeng/MetricCanvas/issues/98) 裁决了渲染引擎独立交付的宿主边界。IOC 会用一个独立微前端子应用承载元数据页面，也存在只在普通系统中嵌入单页的场景；后者不应被要求实现完整应用的接入能力。

## 决策

- 延续 ADR-0065 的两种消费方式：Svelte/创作宿主使用 npm 编译期入口，异构或普通 HTML 宿主通过 JS 地址加载预构建引擎，再调用 `mount(target, options)`，使用返回的 `update`/`destroy` 管理实例。创作入口仍为独立包的 `MetricCanvas`，正式渲染仍为 `RuntimeView`。
- 宿主不指定字体、颜色、间距或其他视觉配置；不开放主题、字体 prop 或宿主可写的 `--mc-*` API。引擎负责呈现，页面文档已有的声明式布局与组件配置继续生效。延续现有系统字体回退，不新增字体文件或跨操作系统字体完全一致的承诺。
- 宿主负责获取页面文档、加载失败与重试，再传入 `document`；不把 `PageRepository` 加进渲染入口。动态数据通过宿主提供的 `dataGateway` 执行，端点、请求凭据与登录恢复归宿主。引擎不增加身份端口，不承诺自动登录、重试或恢复原分页。宿主可在网关内部更新凭据，避免仅为凭据变化替换网关实例。
- `update` 接收完整运行输入，省略可选项即不继续使用旧值，不是局部 patch；文档、网关或初始查询串变化沿用既有初始化语义，不承诺状态无损热更新。仅选中/切换创作控件不重启查询的 ADR-0065 不变量不变。
- 引擎通过现有 `filter-change { search }` 通知筛选变化，宿主决定是否同步 URL。参考用法替换当前 URL，不把同次变化立即回灌 `update`；真正切页或前进后退恢复时，再传完整输入初始化。不承诺仅靠查询串恢复未被编码的分页、排序或滚动状态。
- 引擎不关心微前端协议。IOC 子应用和 platform 按各自应用需要处理路由、菜单、登录与微前端生命周期；直接调用 `mount` 的应用是宿主，不要求最外层门户逐页接线。导航目标另由 ADR-0067 改为普通 URL。

“渲染引擎”是统一运行时的称呼，不另立“嵌入渲染器”领域概念。描述交付形式时称 npm 入口或 JS 挂载入口；`packages/embed` 是包，不是“Embed 应用”，也不是另一套运行时。

## 取舍

| 形态 | 成本与适用边界 | 本次结论 |
|---|---|---|
| JS 挂载入口 + Shadow DOM | 少量生命周期接线即可；函数对象可直接传入；预构建产物携带运行依赖与样式，体积由发布门禁评估 | 保留为异构入口 |
| 自定义元素 | 引入另一套元素注册和属性/对象传值契约；仅放标签仍不能通过 HTML attribute 传函数对象 | 当前不增加 |
| iframe | 独立页面及通信协议，可提供文档/源隔离；需要部署页面地址并处理跨文档状态通信 | 当前不增加；真实需求要求独立文档或跨源隔离时再评估 |
| 引擎直接接微前端框架 | 将完整应用的生命周期和路由约束带入单页渲染消费 | 不采用；有完整应用需求时先在 platform 或 IOC 子应用解决 |

Shadow DOM 用于样式封装，不是安全隔离。npm 入口不承诺与宿主任意 CSS 物理隔离；宿主需遵守引擎 DOM/样式边界。相较开放主题，这个选择降低公开 API 与兼容成本，代价是宿主接受引擎外观。

## 实施与历史对账

当前 JS 入口已存在，ES module/IIFE 为现有格式；正式包名、版本、依赖打包、公开 API 与产物门禁归 #100，本 ADR 不裁决新的发布矩阵。#103 验证真实异构集成及这份宿主边界。#101 落实静态 platform 的数据与身份接线，#3 仍是生产身份/DQE 前置，本次不宣称真实身份已接通。

ADR-0002 的 Svelte 选择继续成立；其中 shadcn-svelte 选型未落地，当前是自建组件，不将安装该库作为引擎消费契约，也不为偿还文档漂移而引入它。#13 的“已选 iframe / Web Component”描述由本裁决纠正；形态决策与真实登录态接线分开，后者继续开放。
