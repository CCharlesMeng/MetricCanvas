# 公开页面采用命名数据源,统一 inline 与 query 取数

> 原编号 ADR-0008(与 `0008-immutable-page-revisions-and-publish-leases.md` 编号冲突,于 2026-08-05 重编号为 ADR-0022;标题与正文未改动)。
>
> query 来源与字段契约已由 [ADR-0014](./0014-query-artifacts-replace-metrics.md) 调整为查询执行引用与结果字段契约；inline 字段契约及命名数据槽决策保持有效。
>
> query 数据源的可选内嵌初始行和查询分页语义由 [ADR-0020](./0020-embedded-initial-rows-and-query-pagination.md) 补充；本记录中 query 首次必查和仅本地分页的描述不再适用。
>
> 「静态页面」一词与它附带的「不得声明 `filters` 和 action」约束已于 2026-08-25 修订：该词退休，约束按下文第三段的不变量重新表述。这一段是本 ADR 正文唯一被改写过的地方。

看板页面公开声明 `dataSources`。每个页面数据源同时给出 `fields` 输出契约和带判别字段的 `source`:查询数据使用 `source.type: "query"` 与结构化查询,固定时点数据使用 `source.type: "inline"` 与 `rows`。组件不携带查询或数据行,只通过 `data` 命名数据槽引用页面数据源；单源组件通常使用 `main`,多源组件可使用 `compare`、`target` 等语义槽位。

统一运行时直接消费看板页面,不再使用区分 `live` / `snapshot` 的渲染输入信封。inline 与 query 进入同一数据源编排路径:前者同步产生终态数据快照,后者把结构化查询与筛选状态合成为生效查询,经数据网关取数并维护加载、错误与竞态状态。同一字段契约可在 inline/query 之间切换,混合页面按组件实际绑定的数据源精确派生实时能力。

全部页面数据源都是 inline 的页面称为**仅内联页面**。本记录最初把它叫「静态页面」并据此拒绝 `filters`、actions 和远程分页,理由是避免"界面已变化、数据未变化"的假交互。这个词把两件不一定同时发生的事捆在一起——**数据来源是否固定**与**界面是否有交互**——而 IOC 作战地图的三份页面是纯 inline 却有层级筛选器驱动地图三级下钻、行点击跨页导航和页面参数:数据固定,界面一点也不静。因此该词退休,约束按真正的不变量重新表述:

**交互必须在页面自己能观察到的状态上产生可见效果。** `writeFilter` 被拒不是因为数据源是 inline,而是因为它写的筛选值只在生效查询里才有意义,而仅内联页面没有生效查询,写了不产生任何可见效果——这才是当初说的"假交互"。层级筛选器能驱动地图下钻,是因为地图直接读筛选状态的当前层级,不经过查询,效果可见,因此合法。**"数据源是不是 inline"只是这条不变量的一个相关性很高的代理变量,不是不变量本身。**

校验器据此放松:接受仅内联页面的页面级 `filters` 与组件上的 `navigate` action,继续拒绝 `writeFilter`(只允许绑定 query 数据源的组件)与远程分页(`pagination.mode: "query"` 要求 query 数据源)。query 页面数据源可声明筛选订阅。元数据快照只校验 query source 的指标与维度供给,inline rows 则按自身字段契约校验字段完备性、值类型和多余字段。

## Consequences

- 固定报告、实时看板及两者混合的页面共享一个公开协议、一个页面仓储接口和同一套纯渲染组件。
- 页面数据来源与数据行在单份 JSON 中自描述；AI、校验器和评审者无需理解外部交付信封或按组件匹配快照键。
- inline rows 会随页面资产固化,不会自动刷新,也不具备筛选联动语义；需要实时数据时使用 query source。
- 页面可内嵌受字段契约约束的 inline rows,但仍禁止表达式、HTML、脚本、自定义样式和绕过数据网关的远程取数,ADR-0003 的严格声明式约束不变。

## Considered Options

- 保留 `live` / `snapshot` 渲染输入信封:使公开交付出现第二套顶层协议,并要求快照按组件键组织,被否决。
- 直接给每个组件增加数据行或结构化查询:把取数、字段契约和展示耦合到组件,无法复用数据集或表达多源组件,被否决。
- 把固定数据伪装成数据网关实现:会让静态来源藏在依赖注入中,单份页面无法自描述,被否决。
- 页面与固定数据拆成两个文件:模型清晰但不满足离线交付的单文件要求,保留为外部存储可采用的物理实现,不作为公开页面协议。
