# 层级选择通过显式父级定位驱动父行视图与完整子表导出

父级指标必须保持地区部整体，选择代表处只收窄该表的父行范围和子查询。候选值及代表处明细不能保证携带父级字段；把代表处编码直接绑定地区部维度，或遍历全部地区部试查，都会制造错误谓词或额外请求。

6.70 在 rowExpansion.selection 中就地声明层级筛选引用、父子层级、父表匹配字段和专属 complete 普通定位查询 parentLookup。定位查询通过隐藏私有输入读取所选子级，结果必须只有一个不同的原始字符串父值，再与完整父结果的 parentField 严格匹配。rowKey 只拥有行身份，仍支持数字。候选合法性与归属定位分别验证；等待、无权限、空归属或多父值均失败关闭，不扩大为全部父行。定位只消费显式声明的归属条件，不因产品或统计期间无业务记录推断无归属。

父源不绑定层级选择；父行范围是组件私有投影，不写入共享 raw、计算阶段或查询结果绑定。子表 source:selection 是局部输入联合的新增分支：未选/选父级时明确不适用并删除该条件；选子级时注入稳定值并验证当前父行归属。旧 row/filter/param 缺值失败语义与全局导航绑定保持。

局部修订 ADR-0113：仅显式启用 selection 的表格，在层级身份变化时恢复默认；共同条件变化保留仍可见行的展开/手动收起、合法搜索排序和每页条数，父页保持，子页在第一笔新请求前回第一页。控制器按稳定行身份管理期望展开，查询程序可更新；同选择的重新定位不会反复打开手动收起的子表。权限修订继续硬失效整个运行时会话。

局部解除 ADR-0113/0122 的父表 Excel 禁令：只有 toolbar.export.rowExpansion:{scope:"all",parentFields:[...]} 启用完整双工作表任务。冻结业务条件、父表已提交视图与有效列，补齐未展开子表，忽略子表局部搜索/排序/页码。统一超时、取消、总行预算和严格失败，全部成功才生成下载；父关联列与子列分开命名空间，隐藏列不能作为关联列泄露。页面 PDF/PNG、未启用的新旧子表导出禁令保持。接受实时 offset 读取，不声称后端事务快照。

取舍是增加一条显式受控查询及一个局部输入分支，避免扩展通用表达式、候选端口或隐含组织推理。完整父结果和定位模板受严格语义校验，按需执行复用 SourceProgram。旧页面不补字段、不迁移、不增加定位请求。
