# 固定筛选按钮组成为独立页面组件，旧图表声明受控迁移

图表左上角筛选原由 `chart.props.filter` 声明，协议限制一个控件只影响所属图表。用户需要同一控件控制带符号指标卡等多个组件，并根据页头筛选值独立显隐。用户明确选择统一采用新组件，识别并更新旧声明，不保留旧协议入口。

## 决策

新增 `filterGroup`，支持 Dashboard 正文及组合卡内部。控件声明 `filterId` 和固定 `{label,value}` 选项，引用普通独立维度筛选器，default 为候选中的恰好一个值。不开放动态候选、层级、级联、多选、空选、Report 或详情视图。

按钮组不承载数据，不强制卡面或标题。复用原按钮样式、键盘、换行和统一 FilterState；查询的 filterBindings 是作用范围唯一真源，多个查询和多个结果消费者均可使用，不增加另一份组件 ID 列表。独立控件无需依赖其消费者的加载、空结果或错误状态。页面只读时禁用按钮。

组件和筛选声明沿用 ADR-0112 的就地 visibleWhen 及集中求值。自身、筛选声明和祖先门禁组合，隐藏控件保留已应用状态及查询条件；内容分别声明显隐，隐藏不自动停查。静态导出捕获同一状态并显示所选标签。

组合卡闭集补入 filterGroup 以及既有柱、线、地图组件，用已有容器表达迁移后的“筛选器 + 图表”，保留原图表跨度、筛选器 ID、默认项、稳定值和查询绑定；仍不允许递归容器。相对 ADR-0053 只扩充这四个叶子成员，不开放任意嵌套。

移除旧 chart.props.filter 的 Schema 和渲染分支，残留旧字段给明确迁移诊断。仓内 pages、有效契约夹具、生成示例、协议文档和 local-authoring 分发统一更新；保留原页面 URL。识别与迁移范围有扫描测试，不以静默解释旧结构代替迁移。

## 对 ADR-0051 的本次明确例外

本批写出版本为 **6.45**。新增组件和闭集成员本可增量表达，但删除 props.filter 是破坏性变更：已有页面与夹具确实行使该字段，**不符合零使用例外**。用户在了解“应升主版本”与“专门记录本次受控迁移例外”两个方案后，明确选择后者。

本例外仅覆盖图表 props.filter 的删除及其独立组件迁移；不授权任意次版本删除其他字段，也不把“迁移后零残留”倒推为“历史零使用”。不使用该字段的既有可读版本保持原读取策略；含该字段的外部旧文档会被拒绝，必须先形成迁移后的新文档或修订。旧发布修订、模板引用及冻结报告不能被本仓扫描证明全部已迁移，不宣称它们自动保持可读。

采用 6.45 而非 7.0，是用户对此次完整移除旧入口的明确裁决；隔离旧读写分支、兼容解释旧 JSON 和扩大到全仓主版本迁移均不作为实现路径。验收要求包含旧字段诊断、仓内有效文档无残留、能力版本门禁、完整页面浏览器和独立 local-authoring 分发。

## 验收与证据边界

`filter-group-page` 覆盖一控多、带符号指标卡、卡内独立组、页头驱动控件与内容各自显隐、状态恢复及无关对照。`chart-local-filter-page` 保留四类图表独立查询、URL、加载、失败和迟到响应验收。证据集中在 [本批验收](../evidence/standalone-filter/result.md)。本地合成数据、静态校验和浏览器检查不证明真实 DQE/Relay、真实模型或部署验收。
