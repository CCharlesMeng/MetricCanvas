# 内容分区可声明受控权重列轨

IOC 项目概览页的外部设计源在 1632px 内容宽度上并排 580/580/440px 三张组合卡，间距均为 16px。ADR-0038 建立的 12 列等权网格无法表达这个比例：ADR-0053 暂用 `span: 4/4/3` 保留相对比例，但会留出一列，且宽度不能收敛到设计事实。

## 决策

**内容分区新增可选 `columnTracks: number[]`，表示最多 12 条受控的正整数权重轨。** 缺席时仍为 12 条等权轨；声明时，统一运行时只把数字翻译为 `fr` 比例。页面文档不能写 CSS 字符串、`px`、gap、坐标、宽高或对齐方式。

`[29, 29, 22]` 是 580:580:440 的最简正整数比。在 1632px 内容宽度与两个 16px 间隔下，可用轨宽为 1600px，三轨正好得到 580/580/440px。三卡及下方 Tab 均用 `span: 1`；`backdrop` 不占轨，仍可保留 `span: 12`。

该能力只改变分区顶层网格。非 `backdrop` 顶层组件的 `span` 不得超过轨数；组合卡内仍是 12 列等权自动流。小于等于 760px 时仍按统一规则回流为单列，不保留权重轨的桌面几何。

该字段必须被创作态布局保留，编辑器显示与夹取 `span` 时以所属分区的实际轨数为上限，不能静默改回 12。

**按 ADR-0051，这是 Schema 5.3 的纯增量能力。** `section-column-tracks` 登记为 5.3 能力，声明 5.2 的文档使用该字段时必须报到 `/sections/{index}/columnTracks`。同批的筛选空选展示文案 `emptyLabel`，以及恢复外部设计所需的若干显式呈现字段（紧凑/嵌入式闭集、指标短上下文、键值单位、地域固定摘要）都是可选字段或封闭闭集新增成员，同样登记为 5.3；它们不改变本 ADR 的布局决策，因而不另立布局 ADR。

## Consequences

- ADR-0038 的现行结论修订为“内容分区缺省 12 列等权网格，真实结构无法表达时可声明受控权重轨”；“布局不开放自由 CSS”不变。
- ADR-0053 的 4/4/3 近似只是当时无列轨能力的权宜表达，由本 ADR 的 29/29/22 三轨取代。组合卡的容器语义与卡内 12 列网格不变。
- 权重只保证比例；主区宽度、内边距与间距仍由宿主和统一运行时的通用布局规则决定。

## Considered Options

- **声明 `[580, 580, 440]` 并把数值解释为像素。** 否决：把单一视口的实例几何写进页面协议，不能随容器宽度缩放。
- **开放 `grid-template-columns` 字符串。** 否决：这是任意 CSS 注入面，违反 ADR-0003。
- **按组件类型或页面 id 推断列宽。** 否决：布局事实不在组件类型中，页面 id 不得是渲染开关。
