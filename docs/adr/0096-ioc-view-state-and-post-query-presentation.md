# 内容切换与详情视图共享组件，分别持有状态

IOC 的整块内容切换、章节定位和图表详情需要复用页面数据源及统一渲染组件。沿用页面实例、内容分区、筛选状态和数据快照，不引入递归页面渲染或业务路由。

`sectionGroups` 引用既有内容分区，每个分区至多属于一个组；未归组分区持续显示，默认组为 `defaultSectionGroup` 或第一组；`sectionGroupParam` 可引用 string 页面参数初始化入口组，未知组拒绝，不作为可变筛选。统一运行时持有选择，默认渲染保持隐藏内容挂载，自定义组合接缝接收可见分区。`sectionAnchors` 先显示目标所在组，再在当前页面实例根内定位和移动焦点，不写URL、不创建查询。表格局部状态仍由页面实例持有；全页筛选变化重置全部受影响表的页码，包括隐藏组，保留排序和局部筛选。

`detailViews` 是页面内受控内容定义，没有独立页面身份。`openDetail.view` 引用它，或继续使用既有 `fields` 行详情；两者互斥。表格列可以独立声明互斥的 `navigate` 或 `openDetail`：前者分别绑定行日期和页面日期，后者用于同一行的趋势/明细两种入口。全页始终只有一个浮层。详情内容只允许说明、柱/线/饼/仪表和表格，不允许容器递归、写筛选、导航或再开浮层。

- `mode: snapshot` 复用主页面当前快照；所需源进入页面初始依赖闭包，不因打开而重查。
- `mode: query` 只在打开时调用现有编排器，使用复制的全页筛选加显式绑定的独立参数。参数引用隐藏的扁平维度、时间点或时间范围筛选声明；不得被主页面或快照详情消费，必须被该视图的数据源消费。行、页面参数与全页筛选是封闭绑定来源；缺值或无效日期不启动查询。独立请求不复用冻结 initial 行，不覆盖主页面快照或筛选。
- 关闭、重开或全页筛选变化取消订阅及在途请求，代次检查丢弃迟到结果。用户关闭后恢复触发控件焦点；全页筛选引发关闭不抢走筛选控件焦点。浮层不进入返回栈。
- 本批详情表格支持展示、原始数值排序和完整行集上的本地分页；列筛选、选择和跨页链接显式拒绝，不能显示一个实际不生效的入口。

完整查询结果可显式声明 `resultScope: complete` 后参与本地表格分页；有 limit/offset 的查询窗口仍拒绝。返回 totalCount 时必须等于实际行数。没有 totalCount 时该声明依然只是上游完整性契约，不能作为生产联通证据，也不解决现有查询分页全量搜索缺口。

同批呈现增量：柱图系列可显式选择 `bar | line`、`primary | secondary`，轴单位需一致且显式，拒绝与旧堆叠/横向角色混用。缺点保留 null，折线不连接缺口。字段绑定增加可选 `missingText`，只改变该消费者的缺失展示；原始 null、0、负数继续保留，百分比刻度不自动乘100。非有限数不再输出NaN/Infinity文字，按缺失呈现；有限数格式不变。

同批时间算子：`timeFill` 只补明确日/月范围，输出缺口为null；按显式groupBy隔离组，拒绝重复期和非法日期。范围可来自显式起止、时间筛选或当前系统年偏移；系统年在页面查询会话起点固定，不替换其它显式历史窗口。`selectField` 只允许有限模式映射，不提供表达式；未知/多选模式拒绝。

未采用：组件自行取数、详情套完整页面、共享可变详情筛选、任意 formatter/公式/ECharts option、从分页窗口猜全量。来源 T/D/P 等价验收继续按证据逐项推进；协议和匿名浏览器场景通过不等于21入口完成。
