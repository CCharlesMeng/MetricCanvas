# 查询语义预检可切换，公共模块拥有统一语义投影

对接中，发现未交付维度/时间能力、源编码差异和不完整治理声明造成查询持续被前置校验阻断。用户确认引入单一严格校验开关，默认关闭，并要求由公共代码修复本轮缺陷。此决策部分修订 ADR-0032 的“名称层与取值全部先经闭集校验”，保留真实执行和结果验真再进入页面的边界。

公共查询链采用可信部署策略，默认宽松：可确定构造且已授权的查询，在粒度/取值/组合能力证明不足时返回警告并交给 DQE 验证。严格模式恢复语义预检；两种模式共用确定性构造与已知等价输入规范化。无法确定来源、歧义名称、非法协议、身份权限、敏感性、确认授权、版本、预算、结果契约和保存规则不随开关放宽。未知业务事实不得被默认值或样例类型推断伪造。

配置每批读取并固定，更新后下一批生效。模式与规则版本进入结果身份，历史引用保留原模式，不能将宽松结果冒充严格验证证据。模型不能改变部署策略。更正业务范围仍须绑定相应授权，关闭校验不会自动补“中国区”或改写时间范围。

公共模块拥有语义投影、规范查询名称、时间类型映射和治理诊断。公司 Adapter 保留认证、源协议转换及真实治理事实，通用算法不再复制维护。既有 DataContextPort.current() 保持中立 Schema；可选 current_for_query(policy) 提供带标记的私有查询视图，允许缺失非安全治理信息保持未知。缺失执行字段类型或安全事实仍拒绝，不允许以此视图绕过页面协议。

实现与内部采用细节见[Adapter 迁移说明](../../metriccanvas-authoring/QUERY-VALIDATION-MIGRATION.md)。该决策不引入新的查询语言、任意脚本、自动重试未知写入或新页面资产类型。
