# 统一运行时读取声明次版本偏低的可执行页面

能力下限让独立校验器和发布流程能检查页面声明与嵌入宿主的兼容性。统一运行时已经具备属性对应的实现时，继续以声明版本拦截整页会妨碍阅读既有修订。

当前引擎支持的 6.x 页面通过实际结构、引用和语义校验后，运行时将能力下限错误降为调试诊断。页面版本本身的支持范围、5.x 只读兼容、保存与发布的能力下限校验沿用现有规则。页面字段净增减为零，修订原文与版本相关的历史行为继续按既有读取规则处理。

直接提升版本会改变一部分既有页面的筛选行为。统一放宽写入会使旧宿主收到声明版本匹配但实际无法执行的配置。将兼容规则限制在读取路径可以保留两个边界。
