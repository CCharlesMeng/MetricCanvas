# 跨源计算仍属于页面数据源，6.12 保留 6.11 读取

IOC 的客户主行与收入、目标等辅助行集需要按稳定业务键关联。继续扩展 ADR-0046 的受控计算阶段：`joinAggregate` 在数据源就地声明依赖、非空组合键、度量映射、`unique | sum` 和 `onMissing: null`。它没有独立身份，不产生计算资产，不引入公式，也不修改 DQE 协议或数据网关。

关联采用左关联：成功但无匹配保留主行并输出 null；加载与源失败通过快照状态传播，不能当作无匹配或 0。`unique` 拒绝重复键，`sum` 要求显式可折叠，同类型、同单位、同币种；输出字段就地声明且不得有 queryField，缺键和循环失败关闭。键编码保留元组结构，不以分隔符拼接、不猜字段同名、不按数组位置。

查询源参与时显式声明 `source.resultScope: complete`，静态拒绝查询分页和查询体的 limit/offset；运行时若 totalCount 与返回行数不同则拒绝计算。该声明是作者提供的输入契约，不是网关探测结果；没有 totalCount 时不能证明后端未做隐式截断，真实集成必须单独核验完整性。inline 天然为完整行集。

运行时递归收集依赖闭包，缓存原始快照，在同一当前输入图上推导计算快照。筛选变更先使所有受影响输入失效，再发布重算；沿用现有取消与代次判定。采集时间不一致或缺失的关联初始行不与新查询混用，改用当前查询；不完整的执行启动快照同样重取关联查询。依赖失败保留错误分类，传播固定脱值消息。组件不查询、不持有依赖调度状态。

6.12 为增量能力版本。经用户确认，新写 6.12，同时保留 6.11、6.5 与既有 5.0–5.4 读取；不恢复其余历史 6.x。6.11 不能声明 6.12 新能力，已有页面无需批量迁移，原文和不可变修订不原地改写。规范化继续输出当前规范版本（既有6.5兼容分支不变）。

未采用：独立派生数据源资产（引入多余身份与生命周期）；放入组件（多个消费者重复计算且无法协调批次）；将分页窗口当完整源（会静默低估）；隐式拉全量（改变查询协议、成本和权限范围）。

同批封闭算子补充 `sumFields` 与 `cagr`：字段合计显式声明部分缺失取空还是忽略，全空始终取空；CAGR 使用显式期初、期末、期数字段和可选100刻度，非正基期/期数、负期末、缺失或溢出取空，不猜测消费者的年份窗口。

本决策确认已实现的 C1、上述专用算子及版本读取策略。时间补齐、内容切换、图表浮层与混合系列仍按后续实现逐项登记，不因本 ADR 自动成为可用能力。阶段性创作契约漂移必须在最终整合关闭；不得提前把本地测试通过称作全任务完成。
