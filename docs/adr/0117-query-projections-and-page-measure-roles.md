# 查询投影位置与页面数值度量角色分别声明

DQE 可通过 `output_dims` 返回已存储的项目数量等数值，但既有映射强制其页面角色为维度，与图表系列的度量要求冲突。自 Schema 6.56 起，允许该位置的 `number/money` 字段显式声明为页面度量，保留图表消费度量的约定；不按样例值或数字类型自动提升角色，也不改写查询、聚合或结果行粒度。普通查询、静态分支与平铺/分组字段遵循同一规则，查询数值归一化沿用页面度量契约。

本决策局部修订 [0017](0017-page-schema-v3-hard-cutover.md) 中查询输出与字段角色一一对应的限制。查询筛选仍由显式绑定决定，`output_metrics` 标量仍须映射为度量；维度字段的严格类型、图表系列角色及折叠算子的显式可加总授权保持原义。选择调整映射而非逐个放宽组件角色检查，以使现成数值复用同一份结果字段契约。声明见[字段规范](../page-metadata/fields.md#dqe-output-measures)，本地验收见[记录](../evidence/stored-count-measures/acceptance.md)。
