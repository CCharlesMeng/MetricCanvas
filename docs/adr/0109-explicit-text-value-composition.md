# 文本取值用显式片段组合动态引用与固定文字

报告主标题需要把所选时间与业务名称组合，整值替换无法表达。6.23 为所有既有文本取值位置增加 `{parts:[字符串或参数/筛选引用]}`：1—64个片段，单层、有序、不自动插入分隔符。选择结构化片段以保持依赖、格式与缺值规则可检查，不引入字符串模板语法、表达式执行器或页头专用拼接字段。

每个引用继续遵守既有类型与格式约束；参数在打开时固定，筛选读取已应用状态。任一参数片段缺值则整项文本缺席，必需标题不能依赖可选参数。物化后仍是字符串，运行时按整个属性投影组合，导出捕获静态结果。dataSources 与自定义组件源码/行为输入不参与文本解析。旧文档不迁移；新能力由版本门禁和导出的契约/Skill 校验器同步支持，外部校验器须更新契约，真实集成另验。

本决定部分修订 [0047](0047-first-class-page-parameters.md) 与 [0100](0100-explicit-filter-text-values-and-period-format.md) 中“不支持组合”的限制，保留参数/筛选可变性边界、单个引用整值取值以及统一 period 格式。
