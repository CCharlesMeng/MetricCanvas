# 表格保留异常标量原文并以独立查询呈现置顶汇总

查询结果的展示异常不应使整张表不可用，也不应通过隐式字符串转换改变计算、行键和查询输入。顶层标量失配时保留有效类型值及独立原文证据，表格与导出展示原文，计算及交互继续使用有效值；空值不补零，结构与权限规则保持。原文证据随快照、行变换、计算投影和序列化传递，不能仅在单元格 formatter 中补救已丢失的数据。本地排序将真正缺失、空白及纯横杠文本在两个方向都排最后。

中国区汇总采用指标表已有区域取数逻辑，单独声明页面数据源及字段绑定。它不属于地区明细行域，不写回 main，不参加明细排序、搜索、列表头筛选或分页，不占 totalCount 和默认序号。地区选择只影响明细；共同时间、产品等通过两源各自绑定生效。两源均保留当前用户的权限约束，前端不得为取得中国区汇总移除授权条件。

采用组件级及列级 pinnedTop 声明，一个独立完整查询结果最多一行；不改 pagedJoin 的横向补列语义，也不把独立汇总伪装为 grandTotal 计算产物。每页第一行显示且暂不纵向吸顶。零行不生成汇总，错误或多行使该行不可用而不阻断明细；Excel 完整导出必须校验汇总成功，不能将失败视作合法空结果。

该决策修订此前查询结果中“除数值度量以外的标量失配一律失败”的处理，但不放宽 inline、文档字面量、字段映射、结构化明细和安全规则。[ADR-0049](0049-table-server-side-and-presentation-capabilities.md) 的表格只识别呈现、不自行计算汇总继续成立；[ADR-0108](0108-paged-join-and-unified-source-program.md) 的执行与状态所有权继续成立。新增声明引入 Schema 6.60，已有页面无需迁移；实施与真实服务验收状态见[主计划](../plan/2026-10-26-table-tolerance-and-pinned-row.md)。
