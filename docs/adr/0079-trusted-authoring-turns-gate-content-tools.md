# 可信创作轮次约束内容工具，最新页面与模型上下文分通道

依据用户批准的统一创作规格与 S2–S4 分片，Platform 每条用户指令先收敛人工输入并同步，然后由可信程序读取服务端最新页面。聊天摘要、模型提供的 token 或浏览器缓存都不能声明本轮新鲜性。为保持已有消费者可运行，同时阻止新入口旁路，统一内容工厂强制消费可信 current-turn 端口；旧内容工厂只作为迁移兼容入口，统一部署缺端口时明确不可用，不能回退旧工厂。

可信程序带外注入身份、工作区、请求/运行/轮次、页面、精确修订/hash、能力版本与有效状态；完整页面留程序通道。模型仅传不透明 contextRef，执行点每次与当前可信轮次核对，并对完整文档校验引用和hash。明确新建有分配的页面身份及空基线；缺少已存在页面不是新建。只读配置问答同样受新鲜性门禁，禁止内容写操作；控制消息只作用于既有轮次。

`contracts/authored/authoring-turn.schema.json` 是程序通道的最小共同结构作者；结构向量不证明授权或latest。只读工具仅输出有界结构与任务配置，补读绑定同一身份、页、轮次和修订，省略有明确总数/范围。当前目标使用顶层稳定ID，文字明确目标优先，选择状态只解决指代；删除、跨页、歧义均拒绝猜测。没有真实latest、身份或摘要分流Adapter时，统一入口失败关闭。

工作台在等待同步前封闭新的人工写入口，先flush已开始输入，失败保留本地工作。准备完成后保留本轮编辑租约；澄清/只读结束释放，取消与迟到响应按阶段隔离。真正已发写入的未知结果继续沿既有恢复门禁处理，不因取消或页面重新读取解锁。

本决策细化0060/0061/0077，延续0064内容工具不持久化和0078的Platform草稿保存边界。S3/S4由可信协调选择最终候选并调用生命周期，Relay继续拥有模型循环与持久执行协调，Java继续拥有页面修订和写入结果权威。候选与操作持久端口随消费者实现，不以S2内存轮次或文件token宣称重启恢复。普通问数的临时页面态与显式沉淀边界保持。

选择受门禁的统一工厂，而非在Skill中要求“每次读最新”，因为后者无法阻止迟到调用或旧token。兼容面必须有部署级反例验证；S8单写切换前不能把兼容工厂注册为统一入口。
