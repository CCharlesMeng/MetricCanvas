# 展示格式属于组件字段绑定

看板页面把字段的数据语义与当前视图的展示方式分开：页面数据源只描述字段类型、角色和名称，最终 `format` 写在组件字段绑定；元数据快照只提供可被组件覆盖的 `defaultFormat` 展示建议。这样同一字段可在指标卡、表格和图表中采用不同格式，同时格式化实现仍集中在统一运行时，不进入纯渲染组件或数据服务。

## Consequences

- 对象形式的组件字段绑定可声明 `{ "data": "main", "field": "gmv", "format": "compact-wan-1" }`；字符串简写继续继承默认展示建议。
- 元数据快照的旧 `format` 改名为 `defaultFormat`。schemaVersion 2.0 早期页面在 inline `fields` 或 `fieldOverrides` 中声明的 `format` 继续读取，并由统一运行时归一为默认展示建议；组件字段绑定始终优先。
- action 和表格选择写入使用不含 `format` 的字段引用，因为它们读取原始值而不是生成展示文本。

## Considered Options

- 格式继续属于页面数据源：声明较少，但同一字段被多个组件使用时无法按视图变化。
- 由纯渲染组件自行格式化：局部灵活，但规则会散落在组件实现中，失去统一运行时提供的复用和一致性。
