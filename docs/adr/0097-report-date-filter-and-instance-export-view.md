# 报告日期筛选、实例静态导出视图与内置 PDF 下载

报告日期选择既影响受控查询，也影响报告期间文字。Schema 6.13 让 `reportHeader.filterIds` 显式引用既有时间筛选器，在封面上方 C 工具带展示。形态在创作时确定为月/日单选或范围；页面参数只初始化筛选器。提取确认原子生成时间参数、筛选器、查询绑定与页头位置，可信业务身份控制多个查询的合并，单点窗口显式声明。该决策沿用 [0047](0047-first-class-page-parameters.md)、[0088](0088-orthogonal-page-parameters-window-on-the-reference-and-layers-by-purpose.md) 和 [0089](0089-page-parameters-can-seed-time-point-and-hierarchical-filters.md) 的参数/筛选和窗口边界。

直接隐藏输入再打印当前页面会遗漏非活动内容和未加载的分页行。每个实例提供异步 `withExportView`：捕获已应用查询作用域，使用相同数据网关重新取得完整结果，复用组件展开全部内容分区组和 Tabs，隐藏交互控件及详情浮层，保留捕获期间文字，等待字体图片并固定图表。Svelte 与 HTML 挂载入口共用该实现；无第二套业务渲染器或全局导出单例。

原始6.13决策由集成应用消费静态DOM并负责PDF编码；下述6.28修订把标准下载收进引擎，集成应用仍可选择自定义编码。DOM 生命周期截止回调结束或取消。页面更新、销毁、错误和超时清理临时视图；单实例并发拒绝。首期固定每结果 10,000 行与准备 60 秒（编码保存除外），完整性不足明确失败。冻结查询作用域不等于数据库事务快照，AI 总结保留捕获的已完成内容。参考 [公共方法与验收边界](../report-export.md) 与 [实现验收](../evidence/report-date-filters/acceptance.md)。

保留 6.12/6.11/6.5/旧布局读取兼容；日期能力声明最低6.13，内置PDF下载最低6.28，修改模板不得降级既有能力。部署 Adapter 可提供绑定精确 DQE 验证基线的时间身份和标量日期字段证据；没有证据时保留独立身份。此变更不要求 Java 页面资产接口调整，实际 Relay Adapter 与集成应用编码器仍需分别集成验收。

## 2026-10-15 下载失败策略修订

用户要求“有哪些就下载哪些”：整页下载不再因部分取数失败而拒绝整个文件，保留其他成功内容及失败前取得的分页；重新取数失败时可保留点击下载时捕获的就绪页面数据。失败源没有可用数据时按空数据呈现，AI 总结导出已取得的文字。下载成功不承诺完整性，控制台记录失败及部分数据诊断。取消、60 秒准备期限、10,000 行上限和分页结构校验继续生效；单表完整 Excel 导出继续执行自身完整性要求。此修订调整实例导出策略，不新增页面协议字段。

## 2026-10-15 引擎内置 PDF 下载修订（6.28）

用户批准把PDF下载与Report上方日期筛选一起通过配置提供，并要求按钮名称可配置。反复在Angular等集成应用复制样式、分页及下载代码会暴露ShadowRoot和生命周期细节；这些行为统一由引擎拥有。

`reportHeader.props.pdfExport: {label?, filename?}` 存在即启用，默认按钮“下载 PDF”，默认文件名取触发页头标题。与filterIds共用工具带，无日期也可显示。文本值复用现有参数/筛选/parts机制，点击时冻结。

统一运行时复用withExportView，提供并发控制、取消、错误反馈及更新/销毁清理；标准编码器、分页和下载依赖随引擎分发，不要求集成应用安装html2canvas或jsPDF。HTML单文件分发捆绑依赖，体积会增加；npm运行时在需要时加载编码依赖。保留withExportView供需要不同编码策略的集成应用使用。

本版A4图片正文：默认竖向，发现宽内容时整份横向，保留计算样式与伪元素、冻结图表、逐页编码、表头与页码，全部编码成功后发起下载。过高的不可拆分块明确失败。日期和下载工具带不进入PDF。原部分取数失败策略及10000行/准备60秒规则继续生效。实施计划见[本批次记录](../evidence/report-pdf-engine/delivery.md)，按用户要求未执行验证。


## 2026-10-15 连续保存修订

用户使用商务SDT报告发现大片空白、截断及导出缓慢，要求按页面原样保存。标准编码器采用零外边距、铺满纸张宽度，取消图表分区另起页、块避让、重复表头和额外页码，按原有静态布局连续切片写入A4；高于纸张的块也连续承接，不移动内容或丢失像素。有界截图批次减少整份DOM重复解析，使用快速无损PNG压缩。页面协议、withExportView及数据准备契约不变。本轮先修引擎，按用户要求暂缓Skill同步。

## 2026-10-16 后台编码与旧入口移除裁决

用户确认withExportView作废、不兼容旧方案，认可Dedicated Worker后台编码与主线程分批截图，并移除用户取消。该裁决取代本ADR此前关于公共DOM回调、取消按钮和每批重建截图视图的现行要求；历史实施描述不作为兼容承诺。

公开HTML/Svelte方法及ExportViewOptions、PreparedExportView、ExportViewConsumer删除，内置任务捕获实例状态并使用内部静态视图。Worker拥有图片裁切、无损编码、PDF组装与文件序列化；仅收取可转移像素和分页数值，不收DOM、网关或业务查询。主线程按时间预算处理样式及截图遍历；截图复用一次解析结果。没有全局导出状态或新的页面协议字段。原查询范围、部分数据、10000行和准备60秒策略保持。

每个任务独立Worker并实行一块在编码、一块在准备的背压；消息无响应60秒失败，完成、错误、超时、页面更新或销毁时释放资源。用户没有取消入口，但内部生命周期仍能中止。npm与HTML单文件均携带内嵌Worker，宿主允许worker-src blob:；不支持时明确失败，不自动退回阻塞主线程编码。纯浏览器方案不承诺关闭页面后继续下载。

6.30新增`reportHeader.props.pngExport: {filename?, scale?}`，名称固定“导出图片”，默认3倍、可选4倍。用户明确要求成功只保存一张完整PNG，不接受多图、ZIP或其他格式；因此长报告采用有界截图块、Worker持续行过滤与Zlib压缩形成一个PNG文档，禁止申请整图画布后再拼接。截图块限制与最终文件支持范围分别检查，超限明确失败、不降低倍率；生成后的唯一文件显示实际尺寸，保存/关闭/过期或实例失效释放。

PDF与PNG共用独立文档准备，从挂载静态视图起不进入原页面文档；正式组件自带注入式CSS，主题仅带入引擎已知属性且拒绝URL背景，字体资源单独传递，不复制门户样式表/伪元素/背景图。原页面水印保持可见；这保证正常父层内容不被导出，但同源脚本仍可主动修改iframe，真实门户水印方式必须另验，必要时由集成应用提供干净运行环境。图表和渐变文字在绘制时使用导出倍率，不能只放大最终截图。既有PDF文件名、A4连续分页及可用数据策略保持，实际浏览器回归负责证明。产品配置与范围见[报告导出](../report-export.md)，本地及安装消费者结果见[单张PNG验收](../evidence/report-png-export/result.md)。

原生不透明RGB PNG的IDAT流直接嵌入PDF FlateDecode并用Predictor 15复原行，避免jsPDF重复解压再压缩；不符合该格式时使用原有无损PNG处理。版本锁定的截图Adapter及Worker代码由工具生成并校验漂移，承认上游适配维护成本；实际浏览器像素与主线程阻塞必须验收，Worker存在本身不是通过标准。现行接入与限制见[报告导出](../report-export.md)，实现测量及视觉结果见[后台编码验收](../evidence/report-pdf-engine/worker-performance.md)。

## 2026-10-19 统一按钮配置修订

用户要求同一种按钮放两份，通过配置区分PDF/PNG与清晰度。6.31新增 `reportHeader.props.exportButtons: [{format, label?, filename?, scale?}]`，顺序呈现，一项一个按钮，每种格式最多一项。点击即捕获状态、生成并下载，移除导出菜单、清晰度弹窗、待保存结果及过期计时器。PDF支持2/3/4倍、默认2；PNG支持3/4倍、默认3。图表、渐变文字和截图同步使用倍率，设备DPR不叠加。PDF的有界块可写入同一纸张多个位置，保持配置倍率与原有分页几何。

旧 `pdfExport` / `pngExport` 在读取接缝转换为相同按钮，新旧声明禁止混用；编辑器修改导出项时统一写6.31结构。保留每实例任务、独立文档、水印隔离、单PNG和数据范围规则。原6.30修订中菜单/生成后保存/过期流程由本修订替代。

同日倍率容错修订：不支持的scale按未配置处理，页面读取和规范写出移除该项，PDF采用默认2倍、PNG采用默认3倍。有效数值保持，不隐式转换字符串；旧pngExport共用规则。其他协议约束和实际输出尺寸限额保持。
