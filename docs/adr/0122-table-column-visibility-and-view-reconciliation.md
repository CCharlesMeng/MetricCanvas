# 表格列展示条件与已有会话视图调和

6.62 在字段列和分组列就地增加可选 visibleWhen，复用统一条件求值，不允许读取当前行。按表格声明中是否使用列条件启用新行为，旧表格及列入口条件保持原语义。搜索字段必须关联已声明列的主、次或徽标字段；实际检索当前可见 main 字段。隐藏列清除相关用户排序、表头条件及草稿，保留默认业务排序；有效搜索范围变化保留仍有效关键词并重新计算，失效搜索选项回退时清空关键词而不自动重搜。

统一纯投影计算有效列，表格视图整理也为纯计算；已提交状态由原 TableSession 一次提交，草稿、候选及展开生命周期留在原控制器。正文、详情、子表和导出只适配上下文，不复制算法，不引入第二套状态管理器。涉及远程表格操作的条件列表格要求独占查询页面数据源，以避免清理一个表格影响其他消费者；本地完整结果仍可共享。

局部修订 ADR-0112：列组是表头结构，无可见叶子时不输出；不推广为空业务容器自动收起。零业务列的表格保留标题与“当前条件下无可见列”，释放展开实例并暂停该表操作/导出。Excel、PDF、PNG使用同一冻结列规则，已有子表导出限制继续保留。

2026-11-12 用户明确确认进一步调整列及柱状图／折线图系列的取数语义，不新增 Schema 字段：无其他消费者或执行依赖的数据停止取数，共享查询保留必要依赖，重新显示按当前筛选恢复。执行端合并消费者，停止无使用者的数据槽，并可裁剪普通单项 DQE 查询中的独立字符串指标输出及本次字段映射；类别维度、主行集、关联、计算、业务条件及默认排序保留，复杂查询保守保留。页面声明与完整字段契约不改写；在途取消、迟到隔离、单次执行和冻结导出共用规则。此处取代本决策最初的“列隐藏不自动停查”限制，一般节点显隐仍沿 ADR-0112。具体边界以页面元数据专题为准，合成查询入口 `/pages/conditional-query-demand`。

规则、状态和文件均按所有权组织：协议与列身份归 page/table，纯投影和会话归 runtime/table，UI接入与导出归 runtime-ui/table；公共条件语义和结果快照只有一份真源。先验证普通表格纵向闭环，再复用到其他作用域。取舍是保留必要接入工作，以避免规则分散、状态双写和大文件继续堆叠；新能力增量表达，不全面收紧旧文档。
