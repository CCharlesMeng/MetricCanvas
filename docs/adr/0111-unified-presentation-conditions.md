# 展示条件就地声明并由统一运行时集中求值

页面需要根据组织层级、已有权限和业务事实控制内容，分别给每种组件增加专用字段会放大元数据和维护成本。采用统一的 visibleWhen/enabledWhen，条件只读已声明筛选状态、已有权限、有限具名事实或合法当前行，支持有界的结构化比较与 all/any/not，不引入脚本、规则库或节点之间的条件依赖。条件错误、等待、允许和拒绝分开，未知输入不得经取反或短路放行。

节点的展示资格由自身和祖先决定。父级隐藏覆盖后代；子项全部隐藏不改变父级，保留标题、外观和原布局占位。不增加空容器检测、必要子项列表或容器完整性策略，需要整块隐藏时直接声明父级条件。数据空态与业务显隐分开。

当前分区组和Tab选择仍由原实例状态持有，与展示资格分开；没有可用项时允许无活动项。展示投影不修改Page、源级快照、compute或查询依赖，隐藏不自动停查；查询刷新继续走filterBindings和SourceProgram。完整本地表格行条件形成私有展示投影并复用TableView/TableSession，远程窗口禁止局部删行冒充全局范围。

预览、动作触发、详情、PDF/PNG及XLSX共用条件语义。导出冻结筛选和事实，展开全部条件允许的内容，保留允许的空父容器。已有权限修订变化先停用旧实例和导出，再按当前身份重新初始化；旧initial、inline、缓存和详情不得跨权限回退。

公共协议、版本门禁、人工/AI创作和独立Skill同批闭合；TS为条件语义真源，Python通过产品Bridge校验。相对ADR-0003增加封闭声明能力；相对ADR-0022，writeFilter允许在存在显隐消费方时产生可观察效果；ADR-0096的导航选择与ADR-0105/0108的执行范围保持。
