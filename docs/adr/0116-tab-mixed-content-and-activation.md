# Tab 混合内容与活动面板生命周期

Tab 从多表切换扩展为普通内容及组合卡切换；禁止页头与嵌套 Tab，组合卡子内容限制继续有效。显式 `contentLayout: "grid"` 使用已有栅格，缺省纵向全宽保证旧页面布局。能力下限 6.49。

页签只决定呈现与取数需求，不创建页面身份或另一套查询协议。页面公共筛选与组件局部筛选通过显式绑定消费，同字段条件取交集；局部控件继续按现有独立数据源规则隔离，不新增 Tab 筛选栏。SourceProgram 统一解析上游依赖，首次访问才取数；隐藏内容失效后再次访问补取，已访问面板保留挂载和会话。输入失效中止旧 AI 流，切换本身不中止。

活动页签以 `tab.<componentId>` 查询参数保存，复用 navigation.replaceSearch，不新增后退记录；局部筛选复用既有 URL 编解码。Report 导出仍展开全部内容、补齐普通数据、仅捕获已有总结，Dashboard 不新增整页导出入口。

本决策扩展 [0053](0053-composite-card-component-level-grouping-container.md) 的有界组件树：允许「分区 → Tab → 组合卡 → 普通组件」，组合卡内部不得再放容器。维持非递归布局语言。详细决定及分层验收见[实施方案](../plan/2026-10-22-tab-mixed-content.md)。
