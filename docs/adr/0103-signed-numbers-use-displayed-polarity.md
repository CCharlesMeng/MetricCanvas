# 带符号普通数值以展示精度统一方向

商务SDT报告的时长及次数月变化是绝对差值，既有 `percent-2-signed` 会错误追加百分号。沿用格式归组件字段绑定的模型，在6.17新增 `number-signed` 与 `number-1-signed`，分别保留普通数值精度与一位小数；正数加正号、负数保留负号。用户否决原始正负直接生成 `+0.0` / `-0.0`，确认显示零时数字无符号、正负颜色普通、变化箭头隐藏。

统一运行时共用同一舍入结果判断数字文本、表格正负颜色与指标卡变化方向；继承字段默认格式与显式绑定格式均遵循此规则。固定颜色仍按显式声明处理有效零；已有格式与旧页面继续保留原始方向语义。本次仅将这8处变化绑定改用新格式，查询、原始数值、计算与排序均不变。

选择新增格式预设，避免本次引入独立符号开关及其继承规则。延续[ADR-0013](0013-format-belongs-to-component-field-binding.md)和[ADR-0051](0051-additive-minor-versions-for-page-schema.md)，针对新格式增量补充[ADR-0101](0101-explicit-value-colors-and-chart-labels.md)；保留6.16读取，新格式需要6.17。生成契约同步覆盖产品及创作侧校验器。

2026-10-13补充：用户要求全部 `number` 格式都有对应的带符号版本，6.18新增 `number-2-signed` 与 `number-grouped-signed`，完成原精度、一位小数、两位小数和千分位四种格式的一一对应。每种格式继承其原格式精度，共用展示零的中性方向；千分位判断零时处理格式化文本中的分组逗号。6.17继续可读，但不能声明两种新格式；商务SDT既有8处绑定无需改变。
