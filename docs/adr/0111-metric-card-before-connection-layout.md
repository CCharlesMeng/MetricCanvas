# 指标卡前置连接文字由父级统一排布

指标卡之间的等号、加号和短连接词需要按内容占宽，并与两侧卡片保持精确间距。独立 text 加权重列只能近似压缩空白；把文字放进指标卡内部则无法控制到前一张卡的距离。决定增加 `metricCard.layout.before`，由统一运行时拥有连接文字及其两侧的布局，不进入指标卡纯渲染实现。

外层保留默认 12 列；连续连接成员占 span 之和，内部扣除连接文字和间距后按 span 比例分配卡片空间。内部排布盒不是页面文档中的新实体。连接文字处于卡片 inline-size 隔离盒之外；每张卡的直接组件布局盒与行对齐契约保留，各直接 Grid 只管理自己的单元格。

第一版只开放 Dashboard、plain/card、默认 12 列的顶层相邻指标卡。gap 缺省 8 CSS px，闭集为 4/8/12/16/24。短文字按内容占宽；长文字有界省略，预算不足时改为单列。暂不支持 after、Report、自定义权重列轨、嵌套、backdrop 或 connectPrevious 混用。无 before 的页面保持原渲染路径。

这部分修订 ADR-0038/0054 对 gap 的全面拒绝，只允许显式连接关系的双侧档位，不开放通用 margin/padding、坐标、宽高或任意 CSS。新增能力按 ADR-0051 登记次版本，旧消费者明确拒绝新页面。

隐藏只判断原相邻两卡是否都呈现，不补位、不重连。数据错误不充当隐藏条件。页面搭建移动或删除打断相邻关系时清除失效连接，并纳入同一次撤销。连接文字不执行计算，不校验等式口径。
