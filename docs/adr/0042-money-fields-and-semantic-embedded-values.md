# 人民币金额使用专用结果字段语义，受控语义 HTML 用 data 标记内嵌值

流水分析报告中的金额此前只声明为普通 `number`，再以固定的“万”格式展示。这既不能表达货币语义，也不能在元、万、亿之间按数量级自适应。另一方面，DQE 已组合完成的归因文案需要让当前组件格式化其中的精确数字；沿用预格式化文本会把展示策略固化在数据层，通过括号或位置匹配数字又没有稳定协议。

## 决策

**结果字段契约新增货币金额字段。** 第一版形状固定为 `type: "money"`、`role: "measure"`、`currency: "CNY"`，原始单位为元，字段值只接受有限数字。查询页面数据源仍以 `queryField` 显式声明查询字段映射。`money` 表达数据语义，不能用普通计数、百分比或无货币含义的数值代替。

**人民币展示新增 `cny-adaptive` 格式预设。** 展示仍遵守 ADR-0013：组件字段绑定的显式 `format` 优先，结果字段契约的 `defaultFormat` 只是可覆盖建议。格式化按原始有限数字的绝对值选档后舍入：小于一万为整数元；一万至十万为两位小数万；十万至一亿为整数万；一亿至十亿为两位小数亿；十亿及以上为一位小数亿。符号保留，`-0` 显示为 `0元`，极性依据原始值而非展示文本。

**受控语义 HTML 新增无属性 `<data>` 语义内嵌值。** `<data>` 只能包含一个规范数字文本节点，允许可选正负号与小数部分；属性、子标签、单位、千分位、科学计数、空内容、前后空白或错误闭合使整段内容失败关闭。解析结果继续由共享安全 AST 和 Svelte 节点分支渲染，原始字符串永不进入 `{@html}`。数据网关保持字符串不透明，只执行既有类型、长度、可空性与查询字段映射校验。

**Table 成为 `semanticHtml/detail` 的显式消费者。** 表格列必须通过字段绑定点名该明细字段；列绑定的 `format` 应用于字段内全部 `<data>`，未包裹文本和数字保持原样。`visual: "signed"` 只给内嵌值映射正、负、中性样式，不给整个单元格染色。省略格式时保留规范原始数字文本，省略视觉策略时不分色；字符串简写不继承明细字段的展示建议。

本决策窄修订 ADR-0028 的两点：表格加入语义 HTML 明细字段的显式消费者集合；被 `<data>` 标记的数字由当前组件字段绑定格式化，不再要求 DQE 预格式化。ADR-0028 的数据网关不透明、安全失败关闭和数据层不拥有具体视觉样式等结论保持不变。ADR-0029 的共享渲染 Module 边界保持不变。

## Consequences

- 页面创作和结果契约可以区分货币金额与普通数值，并阻止错误角色、币种或非有限值进入统一运行时。
- 普通金额字段与语义内嵌值复用同一个 `formatValue` 实现，不在 Table 或 DQE 中复制换算规则。
- `<data>` 是封闭协议，不支持 `data-key`、任意选择器、正则、内联样式或单字段混合多种内嵌格式；真实需求出现前不扩张 Interface。
- 存量 `number` 与 `compact-wan-*` 继续有效，不做全仓机械迁移；只有确认属于人民币金额的字段迁移为 `money/CNY`。

## Considered Options

- **继续使用 `number + cny-adaptive`。** 展示可行，但结果字段契约无法表达货币语义，也不能阻止计数误用人民币格式，不采用。
- **让 DQE 继续返回预格式化金额文本。** 数据层会固定当前视图策略，同一字段无法在不同组件中复用，不采用。
- **通过括号、位置或正则寻找数字。** 当前文案偶然有括号，不构成通用协议，不采用。
- **使用 `data-key` 与另一份内嵌值映射。** 调用方需要重复声明，当前每个 `<data>` 都使用同一列策略，复杂度没有收益，不采用。
- **直接使用 `{@html}` 或允许任意属性。** 无法维持安全白名单与严格声明式页面协议，不采用。
