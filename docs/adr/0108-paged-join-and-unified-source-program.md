# 组合查询源引用普通查询定义，SourceProgram 统一执行规则

多查询表格按任意成员列排序时，第一页成员可以变化。对当前页补列后本地排序或过滤不能实现全局语义；动态反转 resultBindings 又会改变固定依赖、产生循环并覆盖独立图表结果。复制查询定义会让同一业务口径产生多个真源。

6.22 新增封闭的 pagedJoin 组合查询源：成员引用已有完整普通 query，保留固定结果绑定语义。domainMember 定义业务行域，单个非空标量业务键关联，projection 显式归属每列；序号独立于行键。无计算、无结果绑定、无业务窗口的成员由普通结果和内部执行角色分别消费，内部结果不得写回成员公开快照或 initial。

同一成员能够覆盖全部排序和条件、声明 canSelectPage 且原始排序字段非空时，先全局选页再按编码补列，并补键升序稳定排序。跨源条件、多来源排序、可空原始排序字段或搜索用有界完整关联，最大 1000 行；超限显式失败。canSelectPage 是需要真实验真的行域、粒度、计数与排序能力，仿真不证明它成立。

SourceProgram.read 统一普通 raw/compute、固定级联、组合源、单次入口和完整导出的规则。QueryRunner 只拥有共享请求、总并发、缓存和独立消费者取消。读取范围、initial 资格与写回、纠偏属于执行规则；内部执行角色不暴露给 UI。TableSession 唯一持有已提交视图，UI controller 保存草稿并投影会话状态；纯 TableView 拥有比较、过滤、搜索与分页算法。

这局部修订 ADR-0105：仅供组合定义引用的普通源不自动成为普通执行根；独立组件或固定结果依赖消费它时仍执行普通源。单次入口返回的普通 initial 是 DQE 原始字段行，组合 initial 是最终投影行和默认第一页视图。导出的完整范围策略和具名算子迁入共享执行包，浏览器与单次入口都消费同一个 read。

完整导出冻结已提交条件，最多 10000 行/60 秒，使用新鲜请求作用域但共用页面请求池并发限制。窗口截断、总数变化、重复业务键和网关失败不给部分文件；没有上游事务快照令牌时不宣称多次请求具有事务一致性。

新组合语义校验只在产品 TS 中实现。Python 通过 Bundle 内 Node Bridge 调用，同版生成协议、契约、知识、独立校验器与锁文件；缺 Node 22+ 或 Bridge 明确失败。旧 Python 语义按能力逐步迁移，不在本批整体重写。
