# 文本显式读取参数或筛选状态，期间只使用统一 period 格式

原先 `reportHeader.filterIds` 在放置日期控件时还会覆盖 `asOf.value`，让静态文字与实际呈现不一致。6.15 将摆放与文本消费分开：文本取值增加 `{filter, format?}`，与既有 `{param, format?}` 互斥；所有既有文本取值位置共用整值替换规则，不新增组件专用 `filterId`、`rangeSeparator` 或模板插值。参数在打开时固定，筛选文本读取当前已应用状态，未提交草稿不参与。

只增加 `period` 预设：月份/日期单点原样显示，范围显示“开始 至 结束”，相同端点折叠，空筛选显示“全部期间”。不增加只有连接符差异的 `period-compact`。保留 `asOf` 名称兼容，不在这次变更中引入同义字段。

引用必须在物化前校验存在性、输入类型与能力下限；物化后的组件仍只接收字符串。统一运行时保留原始引用路径并投影当前筛选文本，不重新初始化参数或查询。导出在第一次等待前捕获投影后的文字与筛选状态，后续交互不改变本次导出。时间参数提取确认原子产生显式期间引用，保留用户已声明的其他静态文字。

此决定部分修订 [0047](0047-first-class-page-parameters.md) 的仅参数文本取值与 [0097](0097-report-date-filter-and-instance-export-view.md) 的页头隐式期间派生。6.13/6.14 保留原读取行为，6.15 的 filterIds 只决定控件位置；新版字段不能声明在旧版本文档中。契约与创作分发由 Schema 单向生成；不要求 Java 资产接口变更，外部校验器需更新生成契约，真实 Relay 与集成应用联调另验。
