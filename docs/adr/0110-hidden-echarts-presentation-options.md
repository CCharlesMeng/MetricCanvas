# 图表以隐含协议入口支持 ECharts 呈现透传，失败单次降级且只向 console 输出诊断

现有图表把组件字段绑定、数据快照和封闭属性翻译为 ECharts option，特殊呈现需求必须反复扩展协议。用户决定增加 `props.echartsOption`，作为正式协议认可的高级呈现入口。首批仅包含 `barChart`、`lineChart`、`pieChart`；地图涉及 DOM 图例、固定摘要与安全区，单独设计，不在本批开放。Schema 6.32 已在隔离检出完成实施、分发及本地完整验收；实施状态由[唯一主计划](../plan/2026-10-19-chart-echarts-option.md)维护，见[验收证据](../evidence/chart-echarts-option/result.md)。

## 协议与呈现职责

“隐含”指属性面板不展示、常规选型与示例不推广、AI 默认不主动使用；不指绕过 Schema 或隐藏维护知识。完整协议、校验器、文档与独立本地创作 Skill 必须同步支持。只有用户明确要求 ECharts 定制，或现有属性不能表达且用户已接受时，创作才使用此入口；普通编辑保留已有配置。

配置只接受 JSON，不执行函数、函数字符串或表达式。允许 ECharts 支持的 formatter 模板字符串；不开放实例操作、事件回调、导航链接、外部资源与额外下载行为。该子树是不透明的 ECharts JSON，不参与页面参数、筛选文本、parts 组合的收集、版本探测或物化。

引擎先生成基础 option，再应用透传补丁，最后执行布局和静态导出约束。同一允许路径以显式透传为准，包括替换显示格式的模板；不改变原始数据、结果字段契约或组件字段绑定。删除透传后恢复基础呈现。

对象递归合并；`series` 按页面 `props.series` 声明顺序补充既有系列，柱状图后续按 `stackOrder` 绘制时保持这个对应关系；饼图只有一个可补充系列。轴配置只能补充已有轴，不能增删。颜色、半径等普通数组整体替换；空系列补丁不删除系列。越界、非法成员形状及受保护路径明确拒绝，不静默删除。

数据与结构仍归引擎：不开放系列数据、类别轴数据、dataset/encode/变换、系列数量/类型/顺序、堆叠与坐标系关系的接管，也不允许通过 baseOption/media/timeline 等嵌套入口绕过约束。图表绘图区边距可以作为布局输入，直接绘图容器内的几何计算保留必要的防裁切修正；页面外框和组件布局不由透传控制。静态导出继续关闭动画、去掉缩放控件并展示完整结果范围。

## 失败与诊断

1. 非法 JSON、已知受保护路径、系列/轴越界等在校验阶段拒绝，返回包含精确 JSON Pointer 的结构化错误；这类错误不通过降级绕过。
2. 对已通过协议校验的配置，扩展生成、合并、布局或应用阶段抛错时，清理失败实例，用未含透传且未受污染的基础配置重新绘制一次。回退仅影响当前渲染，不修改页面文档。
3. 回退成功用 `console.warn` 记录降级；基础图表也失败则清理实例、保留容器和标题、绘图区留空，用 `console.error` 记录异常。尺寸变化不反复尝试同一失败配置；配置或数据等有效输入变化后才开始新一次尝试。
4. 本能力的诊断均不显示在页面、toast、按钮失败文字或 tooltip 中。console 记录组件 id、类型、阶段、可定位的配置路径与原始异常；ECharts 未提供具体路径时使用选项入口路径，不伪造精确位置。CLI/工具/校验器仍返回完整结构化错误。此规则只改变本能力的诊断，其他既有错误展示不整体改造。
5. 导出视图出现降级或基础绘制失败时，本次 PDF/PNG 导出终止，不生成文件；原因只写 console，释放 busy 状态。不能因为基础图已 ready 就忽略降级，也不能复用现有页面导出失败文案来显示该诊断。

协议只保证 JSON、产品约束与已知保护规则，不维护完整 ECharts 属性 Schema。ECharts 静默忽略或只警告的配置不保证触发回退；不能把“校验通过”解释为所有透传属性都有效。

切换图表类型时清除旧透传，向 console 说明影响，并纳入既有可撤销编辑；同类型操作、普通属性修改、保存与重开保留配置。兼容承诺以实施时登记的协议能力下限及所用 ECharts 版本为准，升级 ECharts 须回归本能力。

## 对既有决定的局部修订

- [ADR-0003](0003-strict-declarative-spec.md)：只在三类图表的此子树开放受保护的 ECharts 呈现 JSON；不再承诺完整校验其全部属性语义。页面其他位置的脚本、表达式、自定义样式限制保持。
- [ADR-0013](0013-format-belongs-to-component-field-binding.md)：组件字段绑定仍拥有标准格式；高级透传可在当前图表用模板覆盖显示格式，不更改数据语义。
- [ADR-0101](0101-explicit-value-colors-and-chart-labels.md)：允许此高级入口声明绘图区边距；引擎仍负责必要的几何修正。常规标签策略和默认页面行为保持。
- [ADR-0097](0097-report-date-filter-and-instance-export-view.md)：本能力导致的导出失败只向 console 输出；导出仍必须终止，其他导出错误与数据完整性策略保持。

## 取舍

不采用完整 option 接管，以保留统一运行时的数据与交互职责；不采用未登记后门，以保持保存、校验和独立 Skill 一致；不复制完整 ECharts Schema，以控制维护成本。接受呈现子树对 ECharts 的版本耦合，并以协议保护、定向测试和单次回退控制失败。讨论中曾短暂提出取消降级和页面原位错误提示，均已被用户后续确认取代，最终以本 ADR 的单次降级、console-only 规则为准。
