# URL 导航使用普通查询参数，页面协议切到 6.0

#109 grill 中用户确认动态传参，要求跳转保持超链接语义，不检查外部目标是否缺必填参数；不投入旧导航兼容。图表直接点击跳转，不增加提示框链接，也不要求 Canvas 图形点具备右键复制链接菜单。文本、表格与指标值使用真实 anchor。

组件 `navigate` 与文本链接共用 `href` + `query`。query 的键是目标参数名，值明确声明来源：当前行 `source: row, field`（表格/图表取 main；指标卡取点击值所在数据槽，所有可点击行来源必须拥有该字段）、当前页面参数 `source: param, id`、当前筛选 `source: filter, id, part`。筛选 part 封闭为 value/from/to/level，默认 value；范围必须分别声明 from/to。固定参数写在 href。没有脚本、模板或目标页面解析。

普通标量直接编码；多选使用重复 query key；范围和层级分别绑定多个普通参数。MetricCanvas 接收端按页面参数与筛选器声明解析，不猜类型，不再要求 p:/d:/h:/t:/m:/b:/n:/s:。筛选 `urlParams` 可显式指定 value/from/to/level 对应的查询键，默认单值/多选为 id，范围为 id.from/id.to，层级另用 id.level。参数命名不得在同页产生歧义。页面参数仍以自身 id 为查询键。

仅允许 HTTP(S) 与相对 URL；相对 URL 按承载文档 baseURI 解析。绑定有值时替换同名查询键的所有原值，未绑定键及 hash 保留；缺值（null/undefined/空字符串/空集合）省略本次绑定，不阻止链接，也不推断外部必填项。0/false 是有效值。hash 内部的路由和查询不解析。静态校验仅证明源引用、分量、URL 与协议结构合法，不证明目标存在或业务含义正确。目标自己的参数默认值与缺参处理不由导航更改。

## 版本取舍

这是 ADR-0051 的主版本变更：删除旧 page/carryFilters/setFilters/setParams，同时改变 URL 参数读取语义，不能在 5.4 上静默切换。技术上可增量增加 5.5 分支，但那会长期维持用户明确不要的两种导航契约与旧宿主解析责任；本次明确接受破坏性代价，使用 6.0，全部原有能力成为 6.0 基线。

不原地改写不可变页面修订、模板引用或冻结报告。仓内可编辑页面与契约样例显式迁移；历史 5.x 资产继续需要原版引擎，或由资产所有者提供部署地址映射后另存为新修订。6.0 引擎遇到旧文档失败并提示迁移。离线迁移工具必须提供 pageId→URL 映射，绝不在引擎内猜部署地址。

宿主可选择接管普通主键点击；修饰键与原生链接操作保留浏览器行为。filter-change 由宿主选择同步 URL，不立即回灌 update；真实切页、同页不同参数以及前进后退按完整输入初始化。导航事件只报告 href 与来源，不恢复 pageId 目标解析。#100 对账该公开面；#103 按新协议验证真实宿主。
