# 当前态客观文档重写设计

## 目标

主文档以参考手册的方式描述 MetricCanvas 当前有效的产品模型、领域概念、协议、架构和运行规则。读者无需了解项目演进历史，即可理解系统边界并正确使用当前实现。

迁移原因、历史方案、删除记录、方案取舍和实施过程只存在于 ADR 与设计记录，不进入主文档。

## 写作规则

1. 使用现在时描述系统事实。
2. 规则采用直接陈述或约束表达，不使用项目参与者视角。
3. 主文档不出现“旧版、曾经、这次升级、已删除、取代、迁移”等演进叙述。
4. 主文档不包含任务状态、实施阶段、临时安排或未来设想。
5. 同一概念只在一个主文档中完整定义；其他文档提供摘要和链接。
6. 示例必须符合当前实现，并能够通过对应校验器。
7. 规范文档区分“必需规则”“允许行为”和“示例”，不把建议写成协议要求。
8. 页面元数据与数据上下文 Schema 元数据使用不同名称和入口，避免“元数据”指代不清。

## 当前模型的客观表达

### 看板页面

看板页面是统一运行时直接消费的声明式文档。顶层结构为：

```json
{
  "schemaVersion": "3.0",
  "id": "page-id",
  "meta": {},
  "dataSources": {},
  "filters": [],
  "sections": []
}
```

页面数据源具有三种组合方式：

- `inline`：页面内保存静态数据；
- `query`：统一运行时通过数据网关执行查询；
- `mixed`：同一页面包含静态数据源和查询数据源。

DQE 是 `query` 数据源的一种执行语言。它不代表平台的全部数据形态。

### 数据上下文

数据上下文是页面创作期使用的受控信息集合。Schema 元数据描述执行环境、Schema、对象、字段、关系、安全边界、资源约束和已验证查询。

数据上下文不属于看板页面，不进入统一运行时，也不包含业务数据行。

### 页面构建

页面构建过程描述系统的正常业务工作流：

1. 明确页面目标；
2. 选择静态数据或检索数据上下文；
3. 形成页面文档；
4. 校验并预览；
5. 保存页面修订；
6. 人工确认发布；
7. 统一运行时消费发布修订。

该文档只描述可重复的业务操作和系统状态转换，不记录项目实施过程。

## 文件级调整

### `README.md`

- 删除协议迁移和模块删除清单；
- 用核心模型和文档导航组织内容；
- 保留可以直接执行的安装、启动、校验、测试和构建命令。

### `origin.md`

- 只陈述业务问题、目标、边界和非目标；
- 删除调整背景和方案演进表述。

### `CONTEXT.md`

- 保留当前有效的领域术语；
- 删除仅用于解释历史模型的词条；
- `Avoid` 只用于消除当前术语歧义，不承担迁移说明。

### `docs/solution.md`

- 以系统组成、依赖方向、创作流、发布流和运行流组织；
- 删除兼容策略、旧工具说明和 ADR 取代关系正文；
- ADR 索引只说明决策主题。

### `PAGE-METADATA.md`

- 从顶层结构开始定义当前页面协议；
- 保留 `inline`、DQE `query`、`mixed`、字段契约、筛选绑定、组件绑定和 action；
- 删除旧版本迁移章节和历史角色命名对照；
- 明确它是页面元数据的唯一主要说明。

### `docs/schema-metadata.md`

- 以数据上下文、执行环境、Schema、对象、字段、关系、约束和已验证查询组织；
- 删除指标目录对比、退出结构和未来扩展表述；
- 在标题和开头明确“数据上下文 Schema 元数据”，避免与页面元数据混淆。

### 页面构建与运行态文档

- 页面构建文档只描述正常工作流、输入、输出、门禁和错误恢复；
- 运行态文档只描述端口、状态、数据流、渲染职责和部署拓扑；
- 不记录旧链路、迁移措施和阶段状态。

## 验证

改写完成后执行：

1. 在 ADR 与设计记录之外扫描迁移性关键词；
2. 校验全部 `pages/*.json`；
3. 校验 Schema 元数据示例；
4. 检查 Markdown 本地链接；
5. 运行与文档契约相关的测试；
6. 对照实现类型与校验器检查规则准确性；
7. 检查每个核心概念是否只有一个主要定义入口。

## 完成标准

- 主文档只描述当前有效事实；
- 页面元数据与数据上下文 Schema 元数据边界清晰；
- 静态 `inline` 与动态 DQE 场景平行呈现；
- 主文档不存在迁移过程、删除记录或历史架构说明；
- 示例与当前实现一致并通过校验；
- 历史信息可在 ADR 和设计记录中追溯。
