# 合成指标说明：用于本地工具验收

## 当期签约金额

业务名：签约金额；别名：合同金额。
DQE 指标：contract_amount；物理字段：ads_contract.amount_cny。
单位：元，币种 CNY；按组织可求和，按月份求和。
时间维度：签约月份；查询维度：region_name。
业务口径：统计期内已签约且未撤销合同，按合同编号去重。
说明：页面尚未指定使用当期还是累计，不能仅按名称自动匹配。

## 累计签约金额

业务名：签约金额；别名：累计合同额。
DQE 指标：contract_amount_ytd。
业务口径：当年年初至所选月累计，按组织求和，跨月不得再次求和。
单位：元，币种 CNY；可用维度：region_name。

## 达成率

业务名：达成率；别名：目标完成率。
物理字段：ads_contract.achievement_percent。
返回百分数刻度 0..100，42 表示 42%，不可平均已有比率。
缺少目标金额口径、零分母规则和 DQE 查询标识；需补充。

## 区域

业务名：区域；DQE 维度：region_name；物理字段：ads_contract.region_name。
区域代码与显示名的映射未提供；不能猜测固定过滤值。
