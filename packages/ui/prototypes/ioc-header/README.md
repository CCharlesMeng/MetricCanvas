# IOC 公共页头：可交互原型

当前阶段：**第一阶段原型已补齐，供用户体验和反馈。** 第二阶段正式组件 API 审查、第三阶段生产编码尚未开始。功能范围仍以 [88项主计划](../../../../docs/plan/2026-10-16-ioc-header-feature-plan.md) 为唯一真源，执行顺序见 [交接](../../../../docs/plan/2026-10-19-ioc-header-handoff.md)。

## 启动与入口

仓库根目录执行：

```sh
pnpm --filter @metriccanvas/ui exec vite --host 127.0.0.1 --port 4184 --strictPort
```

[打开原型](http://127.0.0.1:4184/prototypes/ioc-header/index.html?scene=overview&variant=A)。顶部切换8个场景，底部切换 A 标准上下排 / B 身份筛选并排 / C 筛选优先；场景与布局可通过 URL 分享。业务选择、草稿和返回栈均保存在内存中。

顶部「演示设置」属于实验控制区：配置时间形态、候选响应、身份信息和可选动作。业务页头保持内部视觉 A 的方向。右上「观察状态」显示已应用值、有效维度、模拟请求、草稿、候选、来源视图和任务快照；「88项规划」为每个编号提供状态、说明、步骤与场景跳转，不再用默认标签推断已完成。

## 建议体验

| 场景 | 主要操作 |
|---|---|
| 项目概览 | 年／季／月／近一年；9月→季→月仍保留9月，近一年隐藏输入且排除当前月。演示设置还能切独立单日、单月、日/月范围。 |
| 密集列表 | 展开筛选；区域和行业是真正可展开、可切层级的树，保存演示代码；地区部与代表处不能跨层混选。选择产业→业务类型→小组，再清产业；只清失效后代。区域改变保留无关行业。 |
| 多选业务 | “是否突破／上量”的是、否对应字符串1/0；两项均选不加条件。先选SMB，再关闭“允许SMB客户”，旧值同步清理。 |
| 项目详情 | 保留独立单月；名称、编码与标签来自行实体。通过演示设置修改名称、模拟身份加载/失败/缺字段；缺字段不留空标签，缺刷新时间不造当前时间。直接进入无返回箭头。 |
| 精简合同 | 无标题；最近12月集合以2026-09为候选锚点。仅选2026-01和2026-03时不包含2月。 |
| 复杂时间 | 独立日/月、范围、ISO周、年/季/近一年；日/月分别记住合法选择。近1/7/30/90天含统一演示锚点；近1/3/12完整月与天数分开。最新期、仅完整期、允许未完成期、缺数可分别演示。 |
| 金额与币种 | 不同币种预设；有限非负金额、单边与空范围；相等上下限报错；取消不提交；确定后换币只提交一次并清金额。 |
| 候选异常 | 在演示设置选择区域/模型/协同小组，分别切未请求、加载、空、失败、不可用、只读、无权限、无配置。失败可重试；合法选值保留；不回退全量候选。模型可模拟旧成功/旧失败晚返回。 |
| 跨页流程 | 概览→列表→不同行详情→返回。显式继承区域/期间/币种和项目键；年/季进入只收单月的详情会被明确拒绝；缺实体键也阻止导航。返回恢复筛选、页码、排序、Tab、搜索、表头阶段条件、展开和滚动，来源月份锚点不被目标污染。 |
| 可选操作 | 勾选操作区，再逐项选择主题/全屏/XLSX/PDF/刷新/重置/应用/搜索。可模拟成功、失败、不可用；失败可重试，离页旧回执作废。导出目标明确，捕获已应用快照。草稿模式多条件一次应用，也可取消。全页搜索缺能力时保持禁用，表内搜索仍在正文。 |
| 身份失效与初始化 | 模拟身份失效后清理旧筛选/返回/导出/异步任务，隐藏旧正文；重新初始化演示“默认→参数→导航覆盖→候选门禁→一次查询”。 |

## 覆盖口径与实现边界

[coverage.ts](coverage.ts) 对全部88个稳定编号逐项声明：70项为**交互样例**，13项为**契约草案**，5项为**集成边界**。这些是原型覆盖类别，不是生产功能完成率，也不是88项已通过正式验收。

- 直接复用现有 DatePicker、Button 和 PeriodFilter。`PeriodPrototype.svelte` 仅在原型中补足月份锚点及来源快照隔离；`SelectPrototype.svelte` 保留现有 Select 外观，在原型中隔离浮层焦点/滚动。两处生产组件均未改动，正式修复与 API 取舍留待第二阶段。
- 页头默认采用文字依据的白底、22px/32px内边距、24px/36px标题、16px控件横向间隔；保留现有32px控件点击区。折叠高度按首行复合控件实际尺寸计算；没有把观察尺寸当成来源断点。
- 金额面板仍使用顶层对话框，树与多选使用顶层 Popover；最终面板形态待用户反馈。
- 结果数值、身份、候选、最新期和请求均为本地演示。正文用于观察布局和回显，没有执行真实 DQE 或按所有条件重算真实指标。RMB/USD是独立样例字段，不做前端汇率换算。
- ISO周、累计窗口、动态货币、候选请求身份、业务档位边界等明确标为草案；内部周编号保持不可用。模拟 XLSX/PDF 只演示任务，不生成文件。
- 真实filterIds归属/冲突校验、候选端口、权限、完整查询/导出、跨窗口及业务URL/刷新恢复属于后续正式接线。刷新原型只恢复场景和布局，不承诺业务状态持久化。
- 新增文件仅在本原型目录；生产 Schema、版本、运行时、业务页面、根启动脚本与包导出未改。未提交、推送或部署。原型不会直接晋升为产品代码。
