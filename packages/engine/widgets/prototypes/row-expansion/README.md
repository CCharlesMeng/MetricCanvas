# 行内子表格交互原型

仅用于确认交互、数据形状与实例生命周期。合成数据，不使用真实 DQE、不进入产品构建、不代表正式协议已支持。

双击 `index.html` 即可打开，或在仓库根运行：

```sh
python3 -m http.server 5198 --bind 127.0.0.1 --directory packages/engine/widgets/prototypes/row-expansion
```

打开 <http://127.0.0.1:5198/>。原型状态只在内存中，刷新重置。

1. 点击北辰、远山的展开箭头，再点击“返回所有请求”，分别翻子表页；查询来源翻页后需再次点击“返回下一页”。每次响应只载入2条窗口和匹配总数。
2. 场景页签“空结果与失败重试”会切换到海川/青禾所在父页；展开、返回、重试并再次返回。
3. 场景页签“取消与迟到响应”中按按钮从左到右执行，观察旧请求被丢弃。
4. 在顶部原型配置中按需勾选“搜索”或“列排序”，再在子表搜索“扩容”，可找到未加载页的记录；查询来源会请求上游模拟结果，搜索/排序回到第一页。
5. 可自由切换“父行自带明细”、单行展开、期间或父表页；在下方观察实例与事件。
