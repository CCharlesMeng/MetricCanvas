# 层级筛选联动父子表格行为原型

一次性逻辑原型，用于确认顶部选择、父级定位、父行范围、展开状态及完整 Excel 导出是否符合用户预期。合成数据、模拟异步查询，不连接真实 DQE，不修改正式 Schema，不进入产品构建。所有状态仅在内存中。

2026-10-27用户确认：“没错，就是这个意思”，并授权交接新会话完成正式功能。后续执行见[实施交接](../../../../../docs/plan/2026-10-27-hierarchical-row-expansion-handoff.md)。

双击本目录 `index.html` 即可使用。ExcelJS 4.4.0 已从仓库现有依赖原样内嵌，离线打开也能导出，不访问 CDN。

也可以从仓库根启动可选预览：

```sh
python3 -m http.server 5208 --bind 127.0.0.1 --directory packages/engine/widgets/prototypes/hierarchical-row-expansion
```

访问 <http://127.0.0.1:5208/>。预览服务器并非运行依赖。

## 需要确认的行为

顶部有自由探索和五组引导演示。引导操作请等待每次查询完成，也可以直接使用页面筛选和表格控件。

1. 首屏查询四个地区部的完整结果，父表每页两行展示；定位和子表查询次数均为零。
2. 选择华东地区部，仅保留该父行且默认收起；展开后查询它的五个代表处。
3. 选择上海代表处，先模拟独立定位请求 O101 → R01，再匹配父表 region-id=R01；仅保留并自动展开华东。父行仍为 1200 万元，上海子行为 360 万元。
4. 切换年度或产品保留展开/收起、搜索、排序和每页条数；父页保持，已展开子表回第一页。手动收起后改变共同条件不会自动打开。
5. 切换地区范围恢复父子表默认视图；代表处选择重新定位并自动展开。相同成功选择不会反复打开手动收起的子表。
6. 导出忽略父表当前页、子表展开状态、子表局部搜索/排序/页码，遵守顶部条件与父表已提交搜索。实际生成包含“地区部汇总”和“代表处明细”的 .xlsx，并在页面显示文件内容预览。
7. 右下角可模拟定位失败、无结果、歧义及下一次导出失败；定位异常不退回全部、不执行子查询。快速切换代表处时，旧定位响应只记为丢弃。

原始代表处响应只有 id、name、amount、projects，没有 parent。原型中的独立 LOOKUP_RESPONSES 是模拟定位服务的返回夹具，不代表实际业务已有此接口；实际定位查询仍需创作期定义和真实执行验真。顶部“查看查询输入、定位结果与原始明细”可观察两者区别。

## 本次浏览器观察

2026-10-27，在 Codex 内置浏览器以实际按钮、下拉框和下载完成下列检查，未新增自动化测试：

| 操作 | 可观察结果 |
| --- | --- |
| 选择上海代表处 | 定位阶段没有父行或子查询；完成后仅华东父行展开，整体 1200、上海 360；父查询1、定位1、子查询1 |
| 上海选中后改年度 | 仍展开；2025整体960、上海288；定位次数不增长 |
| 全部地区下展开华东、子表第2页，改年度 | 华东仍展开，子页回第1页，显示上海和江苏 |
| 手动收起后改产品 | 保持0个展开；没有新增子查询 |
| 父表第2页展开欧洲后改年度 | 父表保持第2/2页，欧洲仍展开 |
| 只展开华东，子表搜索上海，再导出 | 屏幕只显示上海；实际下载文件有两个工作表，数据行数分别4和17，包含从未展开的欧洲及亚太代表处 |
| 模拟定位失败 | 父表区域显示定位失败；不扩大范围，不发目标子查询 |

实际下载文件通过 ZIP/XML 回读检查工作表名称和数据行数；不是仅核对页面提示。原型仍接受实时查询模拟，不证明真实服务、生产性能或正式协议能力。

## 复杂度与交付范围

编码前职责分为纯状态与模拟查询模块、DOM呈现与事件壳、既有 ExcelJS 文件编码。未修改既有函数。新增作者脚本的全部函数/回调用 `metriccanvas-ts-ast/1`、TypeScript 5.9.3 实测：119个，自身 CC 为1–10，均不超过15；前值为无，未关闭超限为0。第三方 ExcelJS 原样内嵌，不计入新增作者函数。测量结果见 `complexity.json`。

验证口径是浏览器交互观察、实际下载文件检查及复杂度测量；未运行产品全量测试，也未添加正式 Playground 页面或生成 local-authoring，因为本次只提供评审原型。业务行为已获用户确认，正式能力已按主方案实现。2026-10-28 按用户批量合入要求，将试验分支 `codex/prototype-hierarchy-selection`（`65fb7ed3c`）的原型文件留在 main 的独立 prototypes 目录，供历史行为回放，不接入产品构建。
