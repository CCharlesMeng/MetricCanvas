## 4. 测试与验收设计

### 确定性必需验证

新增 focused tests 消费公共接口与数据契约，不逐个私有函数复制实现。将 SPEC AT01–AT20 对应到最少的场景组：基础匹配、多需求/主题、模型/知识故障、来源与覆盖、交互/续接、查询衔接。完整验收目标包含真实持久存储跨子进程、两个并发答案和处理过程中进程中断。本次验证了 SQLite 跨子进程读取、并发 claim 和模拟租约超时恢复；未执行真实 kill 进程故障注入，不把后者标成通过。

主流程仅保留创建页面和调整页面：创建使用发现→一次取数核对→查询→页面产物；调整从真实保存基线开始，确认不继承旧授权。mock 只提供可信外部事实，不能通过工具参数塞身份/基线/确认后门。只改样式的调整不得额外查询。

按用户最新“必要简单测试、不要全量测试”要求，仅运行受影响的 3 个测试文件和创建/调整主流程；修改 Skill/MCP 后按仓库现有 DS 分层流程做无模型预检与确定性主流程。业务实现前先冻结用例映射；没有代码变更时不运行整套业务测试冒充实现通过。

### 效果验证

先用本批 mock 构建可复现案例，再由内部补充真实问法和真实口径的脱敏评测集。训练/开发样例与评测集分开，模型不可见答案。报告：Recall@K、需求项覆盖、错误自动选择次数、必要澄清识别、无匹配正确拒绝、额外澄清轮数、P50/P95 延迟、模型/元数据调用量。不得仅报告“模型回答看起来合理”。

固定负例集错误自动选择为零、权限/版本/确认失败关闭用例全通过、同需求修订无自动第二轮追问，是硬门槛。Recall/延迟目标在语料与环境冻结后制定，不凭 mock 分数宣布生产效果。

真实模型使用受控工具链与固定输入，分别记录外层 Skill 模型和可选解释模型的调用量。真实 Relay 卡片/文本回传、Java 权限过滤和知识库检索另做内部验收，不由本地模型通过替代。默认不新增浏览器截图验收；交互用协议事件验证，确需真实 UI 的部分由内部 Relay 验收记录证明。

### 契约与分发

按源生成，禁止手改 lock/export：

```sh
pnpm authoring:contracts
pnpm authoring:contracts:check
python3 metriccanvas-authoring/scripts/check_bundle.py
```

Harness 使用 `metriccanvas-authoring/tool/.venv/bin/python`。若生成器因根产品源变化会写入目录外文件，先识别并单独处理范围；不得默默越界。内部 adapter hash 和无关 staged diff 前后比较。公共模板变化须在内部迁移说明列出，不自动覆盖内部树。

## 5. 发布与降级

1. 先交付兼容的公共接口/默认文本实现，legacy 模式通过回归。
2. 用显式 mock factory 开启增强模式，验证全部确定性状态与无模型路径。
3. 接可选解释模型，验证超时/非法提案降级；mock 配置不进入生产默认值。
4. 内部实现可信消息/续接与持久化，能力握手后启用取数核对。没有可信端口时只提供基础发现，不能靠模型记忆宣称续接可用。
5. 接内部知识库，校验权限、版本、coverage、草稿与来源，最后用内部语料验收。
6. 索引或向量能力将来只替换 CandidateRetrievalPort；不改变确认、安全与状态协议。

关闭增强能力时，暂停中的任务明确 unavailable/expired，不退回 legacy 后自动执行未确认部分。旧记录使用 recordFormatVersion，升级不支持时明确重新发现。回退不会清理未知查询/保存记录，更不会重放旧执行。

## 6. 风险与待验证事项

| 项目 | 当前默认/处理 | 必须获得的后续证据 |
|---|---|---|
| 内部知识库结构未知 | 先支持结构化术语和文档片段；adapter 转换 | 权限、分页/截断、项级版本实际语义 |
| 真实元数据规模未知 | 有界加载，coverage 明确；不假设全量可放模型 | 数据集规模、分页协议、请求耗时 |
| Relay 的可信交互能力 | 定义 current port 与事件契约，提供 mock | 原始消息、跨轮会话 ID、确认事件来源、卡片或等价文本回传 |
| 原始需求保留期 | 默认示例 24 小时；公司明确策略后配置 | 消息重取能力、存储清理、取消/过期策略 |
| 当前未提交 remediation | 作为集成前置，不修改归属 | 独立提交与基线回归 |
| 现行 ADR 与新计划协调 | DESIGN A13 已登记 | 向量阶段化、会话原句保留、查询策略一致性审查 |
| 自动选择覆盖不足 | 初版只在确定性证据充足时自动，模型候选核对 | 真实语料漏召回与澄清率，不凭模型置信度调阈值 |

这些不是继续写公共基础模块的前置阻塞；它们分别限制对应内部能力的“生产已接通”声明。涉及破坏性协议或现行领域规则修订时需在实施门槛处明确确认，不能以默认配置悄悄扩大已批准范围。
