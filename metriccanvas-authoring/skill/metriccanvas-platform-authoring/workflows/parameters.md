# 页面参数流程

先读[参数工具与临时实例](../references/parameters.md)，输入和引用语义以活动完整工具 Schema 为准。参数选择、文本确认和模板采用由 Skill 决定。

1. 提取模板时从本轮工作稿或生成/编辑的精确产物提取候选。向用户说明标签、类型、覆盖范围、dateForm 与跳过项；让用户确认候选及涉及实例值的文本处理。省略旧值时交可信工作台展示，不猜原文。
2. 按确认选择形成 selected_ids/text_choices，使用工具返回的候选与文本位置。来源变化或引用失效时重新提取，不重放旧选择。解析需要的预览值后，将临时 instance_ref 交程序执行；取得执行结果才报告运行成功。用户在工作台决定保存无值模板。
3. 召回模板时由外部提供方打开精确模板并建立新轮次。读取参数类型与 hasValue，明确本次输入；无法确认的旧值请用户提供。真实业务值、期间或区域有歧义时澄清。
4. 按缺值/非法值修正解析输入；成功解析与执行、保存、发布分别核对。模板检索或部署提供方缺失时报告具体缺口。

日期身份、查询绑定、页头联动、窗口、无值模板和实例初值遵循 MC 参考；同值文字不作为期间相同的业务依据。已有能力保持原语义，新增能力按产品能力下限检查。
