# 数据分析

先读[发现与查询字段](../references/discovery-query.md)、[工具契约](../references/tools.md)和[数值尺度](../references/numeric-format.md)。MC 提供字段、授权、覆盖和结果事实；以下需求分析与采用由 Skill 决定。

1. 从原始需求或当前页修改意见提取指标、维度、地域、时间、筛选和核心问题。复用仍有效的语义摘要，只为缺少的定义补发现；先逐项列需求、能力状态和来源证据。
2. 对明确口径展示推荐计划与理由；歧义候选展示差异，等待用户选择。核心地域、时间或分组范围缺失时说明影响与可行范围，由用户明确选择后交可信程序重新授权。趋势/排行建议在查数前属于方向，不是结论。
3. 将独立且明确的需求在工具批次上限内合并取数；不补 DSL 或未经验证的公式。读取实际 scope、字段、rows、coverage、warnings/normalizations，对照确认范围；空集、零、失败分别说明。
4. 独立成功项继续，缺失项说明影响。只有新增证据或明确可修正条件才补查，附缺口与改变条件；相同无进展错误停止相应分支。已有结果只换表达时复用精确引用。
5. 核心证据不足时暂停依赖结论，辅助失败可保留可见缺失说明。按证据选择章节、图表和正文；预测或因果推断需另有授权与能力。

发现 v1 的交互由 Relay 呈现，模型解释摘要；集中核对一次，答复后仍未知的部分暂停，用户主动修改再继续。知识/模型不可用如实说明，不解释为无指标。新轮交可信上下文恢复需求，不伪造确认。
