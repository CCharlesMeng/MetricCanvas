# 修改页面

编辑前读[精确编辑与操作回执](../references/editing.md)；操作闭集与字段来自本轮完整工具 Schema。MC 提供基线、依赖和回执事实，以下步骤由 Skill 决定。

1. 明确用户要修改的页与组件；同名歧义先澄清。用本轮 context_ref 读取当前 pageId、ref、workVersion 和目标配置，补齐这次操作需要的依赖。截图或摘要不替代完整基线。
2. 纯呈现与重排直接形成受控操作；新增取数或改变口径先走[数据分析](data-analysis.md)，复用仍有效的结果。已有章节适合时直接新增内容；只有用户要求或章节都不适合才新增章节。
3. 跨分区移动、删除章节、替换内容按 MC 的逐操作校验与 dependsOn 约束形成可执行计划。保留未要求修改的身份项、日期/筛选顺序、高级配置及业务正文；未取得正文先补读。
4. 提交 edit_page，逐项检查 applied/failed/skipped、工作版本和保存状态。独立成功项继续，partial 说明未完成项。可修复输入按具体路径定向修复并重读版本；竞争、权限、旧基线或未知保存交程序核对原提交。
5. 按[保存、预览与标记](../references/delivery.md)准备精确产物交付，结合[执行检查点](../references/execution.md)核对用户授权项、业务证据与可见表达。结构有效与业务/视觉正确分别报告。
