# 经营场景

先识别读者关注的业务对象及问题。整体、Core、云通信是对象层次的示意；具体对象来自已发现维度取值，不将示例名字写进别的业务查询。

若同对象有年累计、本月及相关变化，可在同卡分成两行，年累计附有证据的同比、本月附有证据的环比。变化值帮助理解主值，不应机械拆成与主值同等强调的裸数字卡。对象之间并排比较，每卡保留自己的表面与对象标题。

随后按需求选择时间变化、重点业务或核对内容。趋势已经说明的问题不靠一个笼统“结构分析”章再说一次。分布要有可信分母及完整数据；核对表只有读者需要精确对照时保留，并标明 reconciliation 用途。

经营阅读的可选组合：整体摘要先行，子对象紧凑比较，年度目标与年度推演用同量纲对比图，待关注客户用精简名单。只有相应数据与阅读任务都存在时采用；无目标或客户数据时不补造对应章节。查询字段可多于显示字段；客户核对任务需要宽表时不强压为少列名单。年度推演不是实际完成额，增长名单不能直接命名为增长贡献。
