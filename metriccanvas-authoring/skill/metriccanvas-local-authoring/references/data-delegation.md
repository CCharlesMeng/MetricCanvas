# 按需委派数据分析

默认由单个 Agent 完成。仅当指标语义分析较复杂、可拆为互不依赖的部分，且宿主支持并已授权委派时使用本页；初始尝试至多两个 worker，再依据实际收益决定是否调整。宿主不支持子 Agent 时串行完成同样的分析。

主 Agent 固定修改范围与输入身份，为每个 worker 提供独立问题、相关组件/字段摘要、必要指标原文及数据契约路径。只提供完成该问题所需内容，证据以文件路径、行号或 JSON Pointer 引用；不默认转发完整页面、全部 Skill 参考或其他任务历史。

worker 只分析，返回匹配结论、来源、条件、缺口与冲突；较长结果写到页面扫描范围外的证据文件，仅回传摘要和路径。主 Agent 读取相关证据、合并共享口径并处理冲突，作为唯一页面写入者执行修改、校验和交付。委派结论仍须满足[数据分析](data-analysis.md)的证据与真实查询验真要求。
