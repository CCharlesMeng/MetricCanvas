# 页面排障交接

1. **定输入。** 记录实际加载的页面路径、内容 SHA-256、页面 Schema 版本、脱敏的复现输入及原始错误。整页替换先拼接并检查来稿的 JSON、`Page.id` 和页头。局部编辑保留原件，只有能力下限不足、实际旧形状需迁移或用户要求升级时才走迁移。
2. **验一次。** 仓内由页面排障入口执行单页检查，独立安装使用自带校验器。交接保留校验器身份、退出状态和 `type/path/message`。页面内容、校验器身份、文件名及检查选项一致时复用回执。文件改过后校验新版本。
3. **按证据转向。** 静态错误从首个根因路径读取最小对象及引用。静态通过且运行失败时，先从原输入走到首次偏离。候选拒绝优先核对解析层级、当前候选回执、数据源和是否观察到 DQE 请求。只有定位所需证据缺失时再打开对应协议章节或源码。
4. **按根因交付。** 配置问题交接所涉 JSON Pointer、预期行为和范围给页面编辑入口。运行时问题交接最小复现和阻断位置给仓库实现。静态校验、合成复现和真实服务各记录自己的环境与结论。
