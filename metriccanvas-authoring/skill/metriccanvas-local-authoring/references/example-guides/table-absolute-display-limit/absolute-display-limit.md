## 绝对值展示阈值（6.119）

复用用途：数值变化列超过指定绝对值时显示简短阈值，例如绿色 `↑ > 500`、红色 `↓ > 500`，保留原数值用于排序和计算。

参考对象：页面 JSON（原入口：`table-absolute-display-limit.json`），入口 `/pages/table-absolute-display-limit`，主表 `limit-table` 的 `change` 列复用 `absoluteDisplayLimit:500`、正负颜色与前置箭头映射。`compact-limit-table` 展示紧凑变体。

移植边界：映射实际数值字段和数据槽，阈值填写原始基本单位的有限正数。箭头与颜色保持显式声明；未配置阈值的列不受影响，次字段/徽标不继承。示例为 inline 合成数据，不能移植为真实业务事实。

可观察预期与环境：运行 `pnpm dev:playground` 后打开上述入口，无需 URL 参数或 DQE。650 显示绿色 `↑ > 500`，-650 显示红色 `↓ > 500`，±500 显示普通数值；±500.0001 显示阈值，±499.9999 沿普通格式舍入显示500。箭头只显示在数值前，零无 sign 箭头，缺失为 `--`。点击阈值列表头排序，超限行仍按原值排列；点击导出，Excel 超限格保留数字原值、阈值格式及颜色。宽窄屏均检查箭头和文本，静态 PNG/PDF 复用表格显示。非法配置可将 `absoluteDisplayLimit` 改为0、负数、字符串或配置到情况文本列，均应在该配置处报错。此场景不证明真实 DQE/Relay、生产部署或外部模型接入。
