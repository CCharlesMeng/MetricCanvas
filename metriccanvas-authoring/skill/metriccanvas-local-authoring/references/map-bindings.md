# 地图输入与运行核对

地图字段结构合法只证明声明可解析。创作时核对三件独立的事：行在当前层级可见、名称命中底图、度量及图例正确。按[地图协议](page-metadata/components/mapChart.md)声明。

## 层级字段使用 id

hierarchy 中 id 是机器值，label 是展示文字。若 defaultLevel 为 global，levelField 指向 scope，则初始行必须 scope="global"，不能写 scope="全球"。层级切换后还需该层的行与明确父子编码；只有全球行不能支持地区部/代表处完整下钻。

```text
hierarchy: [{id: global, label: 全球}, {id: region, label: 地区部}]
levelField: scope
可见初始行: {scope: global, ...}
不可见初始行: {scope: 全球, ...}
```

codeField 是当前地域编码，parentField 是父编码，不能把显示名称、层级label和编码当同一空间。静态 country 地图无需虚构 hierarchyFilter；若没有真实层级数据，报告静态地图能力与下钻缺口。

## 地名与宏观地区

随 Skill 的[地名目录](map-regions.json)来自真实 china/world 底图。nameField 值直接匹配该目录，或显式 nameMap。方向为“数据值→底图名”：例如 {"中国":"China"}，不是反向。名称翻译不改变地域粒度。

Europe、亚太、北部非洲等业务宏观地区不等于 Germany、Singapore 或某个单一国家。不能把宏观地区总量映射到一个国家并声称是同一范围。要宏观地区地图，需要独立的业务地域→几何/国家集合/点位投影契约；缺少则单列，而不是猜中心点或挑一个国家代替。

本次数据若明确为国家，可使用 country 图；若明确有地区部与代表处，只展示实际有证据的层级。数据缺少某地域不能靠补0来声称完整；允许另造演示行时也要单独标识，不与真实/输入值混算。

## 度量与图例

比率先按分组重新汇总分子、分母，再除；不能取各行比率平均或复用某行比率作为整个地域。分母为0、负值、缺失匹配和超过100%分别按已确认口径处理。图例阈值与字段刻度一致，边界值实际测试；不为了落入图例而钳制原值。

## 能力分开记录

| 项目 | inline | query与必要接入 |
|---|---|---|
| 静态地图和提示 | 地名/可见行匹配后可展示 | 同样需匹配 |
| 设置层级声明 | 可声明，不证明有对应行或可点击切换 | 仍需完整父子行、候选值与绑定 |
| writeFilter、重新取数 | inline 不支持，不能假称地图选择改了查询 | 合法声明、可信查询、filterBindings及数据网关分别到位 |
| 导航 | 合法行命中后可生成链接 | 目标页消费和权限仍独立验收 |

浏览器要看到着色/点位与Tooltip，并实际点选；全灰底图、空行或没有区域命中不能叫“地图完成”。区分地名问题、层级行被过滤、零值/缺值、真实查询未接通，不把它们混成一个“浏览器未验证”。

## 缺少宏观区域几何时

这是数据/几何输入缺口，不是选择“代表国家”的设计自由。不能通过标题附注就把欧洲映射德国、亚太映射新加坡变成已授权方案。只绑定输入明确证明的国家；其余宏观区域保留原名称和值，在普通表格或分类明细中显示，并用 text 说明地图覆盖缺口。已有底图地名清单只证明几何存在，不证明业务对应关系。

“全球→地区部→代表处”的文字可以作为未接通路径说明，但不能配置无数据依据的点击下钻。地图用默认变体作普通卡位；regionalOverview 有专用投影与注释布局，只有来源明确需要这种展示且实际预览通过时使用，检查图例是否越出所属组件。
