# 专项任务路由

只有本次改变下列职责或诊断其失败时读取对应行，再读命中的参考。页面已有多源/查询不触发选型；URL或导航参数不等于数据源查询。仅补同型参数时沿用当前结构并核对字段，不执行全部路径。

## 选择任务路径

| 本次任务 | 读取与动作 |
|---|---|
| 新建、调整或迁移 IOC 页头 | 先读[IOC 页头创作与迁移](ioc-header-migration.md)的筛选布局顺序；旧 header 替换另按该文盘点功能、默认行为与依赖，最小替换并双向对账；沿用原布局形态。 |
| 局部呈现或已有可信字段绑定修改 | 定位相关对象，沿用原形态、数据和查询，直接改最小对象；只查受影响属性。大页面按对象提取，不打印全部数据行。 |
| 指标表、详情表、级联或多来源等逻辑选型 | 按[场景索引](scenario-index.md)选择操作与数据逻辑，只读命中的主题和示例。 |
| 新增口径、指标匹配、查询或数据源替换 | 读[数据识别与接数](data-analysis.md)，先确认数据依据和项目已提供的执行入口，再分析受影响范围；换源保留原组件意图并核对全部共享消费者。完整关联报告按需生成。 |
| 新建、整页重组、切换形态 | 形态未确认或存在冲突时读[形态识别与确认](page-form.md)。已明确形态且有匹配合法功能示例时，保留示例布局和结构，按渐进读取移植；需要重新组织内容或没有匹配示例时，再选[看板](dashboard-patterns.md)或[报表](report-patterns.md)的一张相关范式卡。 |
| 已确认Report的区域划分、背景或卡片布局调整 | 读[报表范式](report-patterns.md)指向的PC章节组合，先判断表达与卡面边界，再查相关组件属性；沿用已确认形态和数据。 |
| 删除列、组件、数据源或筛选 | 按[场景索引](scenario-index.md)核对完整引用与共享依赖，删除目标后完整校验。 |
| 季度选择仍传 month，或需要调整年／季／月的查询粒度 | 按[期间选择定位与修复](period-selection-repair.md)核对精确页面、查询分支和显式策略；普通指标按选择查询，固定月趋势及自定义账期字段按各自契约处理，以实际 execute 请求验收。 |
| 联合查询／多表关联报错、成员筛选不适用、补列未请求或关联后缺行 | 按[多源查询定位与修复](multi-source-query-repair.md)区分关联与合并，建立成员筛选矩阵，分别核对行键、关联键和实际请求；结构校验与真实服务能力分别举证。 |
| 新建／调整 IOC 区域与局部筛选联动，或切换／URL 恢复后筛选消失、隐藏后仍过滤 | 按[区域与局部筛选联动](region-local-filter-repair.md)同时检查 Region 选中值与层级、控件显隐和全部相关查询绑定；用原始 URL 及返回全球的流程验收，不能只测空参数入口。 |
| debug：报错、没数据、数不对或交互失效 | 按[页面调试](page-debugging.md)保留复现证据、定位失败层和复验；再按[场景索引](scenario-index.md)选择所涉数据逻辑。 |

用户已明确指定形态或已有有效确认且无冲突时引用选择后继续；实质冲突按形态说明针对性确认。未确认时只交识别摘要和问题，不生成 JSON、模板或章节骨架。局部修改沿用原形态；新页面显式写 layout，省略会默认 report。
