# 本地创作与验收

## 输入与输出

本地创作形成页面文档；页面数据源、结果字段契约、筛选器、内容分区和组件由文档显式声明。数据上下文快照提供创作依据，不写入页面；查询定义在创作期确定，渲染期只执行已有查询，不临时发现数据或生成查询。

输出文件用页面 id 命名，例如 id 为 operations-dashboard 时保存为 operations-dashboard.json。新增文件的身份由用户项目约定确定，不把本地 id 冒充已分配的线上资产身份。

仅衔接平台云宝创作时：每轮输入为前端当前完整工作副本，含未保存修改。本地 Skill 仍输出页面文件；线上会话、访问链接、sessionId、编辑锁和管理路径由平台/部署接口管理，不写入页面 params 或 meta。线上页面身份以实际服务回执为准。

## 自然语言与设计源

新建、整页重组或切换形态按入口的[形态流程](page-form.md)处理。范式摘要只提供结构，不能作为完整页面或业务数据输入。

自然语言创作先将需求对应到章节、组件、字段与交互；完整页面保留必要的口径和数据范围说明。仅在需求明确要求时配置动态 AI 总结；已有文字说明可使用 text 或 fieldText。

设计稿或旧系统截图还原时，先列出可检查的对应关系：内容顺序、完整字段/列、布局、图形、单位与颜色、日期控件、点击目标和窄屏行为。截图里的示例数值不证明业务数据或字段映射。用已有组件表达；扩展展示能力以目录内现有组件契约为依据，缺少能力时记录表达缺口。

在目标运行时预览，按相同视口对照源图并记录实际截图；覆盖需求涉及的切换、筛选、排序、翻页、详情与导航。用户没有指定的交互不从截图猜测。只有 JSON 校验时保持“结构通过，视觉还原未验收”。这些步骤可独立执行，不要求安装另一份设计还原 Skill。

## 数据配置

按改动查阅数据源、字段或查询主题；已有可信绑定直接复用，新增口径、指标匹配与查询修改见[数据识别与接数](data-analysis.md)。

- inline 行使用稳定页面字段 id；query 初始行保留实际查询响应字段，按 queryField 映射到页面字段。
- 组件引用数据槽与稳定页面字段 id；筛选器 dimension、页面字段 id、DQE 字段属于不同空间，显式配置绑定。
- query.initial 必须对应该查询与初始条件。改变查询条件后重新取得匹配结果，或移除不再有效的初始快照；不能保留旧行制造查询正常的假象。
- 缺失值、零值、比率、金额与已缩放数据按实际契约区分。显示格式负责缩放，原始数值不为呈现而改写；金额身份和单位不能只由字段名称推断。
- 计算只使用目录内[具名算子](page-metadata/compute.md)，保留完整性与依赖证据；不把样例行证明为完整结果。

完整参考：[内联页面](page-metadata/examples/inline-report.json)、[查询看板](page-metadata/examples/query-dashboard.json)、[跨源计算](page-metadata/examples/cross-source-page.json)。复用后重新核对版本、实际字段与业务口径。

## 业务口径复核

新增计算或汇总时，从原始输入独立计算验收值，保留本次相关分组的分子、分母与结果，用容差比较页面值。比率先汇总分子与分母再除；按实际期间、粒度和完整性对账，验证相关的零、缺失、负数及超出常见范围的结果。

复用已有比率字段只需核对来源、单位与刻度：percent-* 只加百分号、不乘 100；ratio 输出百分数须显式 scale:100，原始百分数不能先除 100。数据值、图例阈值和 tooltip 保持同一刻度，有浏览器时核对最终文字。未知值不补零，样例明细不冒充全量汇总。

分类数据需核对完整性、图表和列表的同色同序、合计与主指标是否同一口径。允许自造分类演示行时单独说明它们不代表真实分类。涉及地图读[绑定检查](map-bindings.md)，涉及概览读[常见布局](overview-layouts.md)。

## 日期、参数与交互

只有需求需要日期选择时增加筛选器。dashboard 通过统一工具栏呈现页面 filters，report 通过 reportHeader.filterIds 选择日期控件；二者都通过对应查询的 filterBindings 传递应用值。dashboard 页头不能写 filterIds。多个控件使用 `dashboardToolbar: "visible"`（或省略该字段）的可换行默认工具栏；“标准”不是 variant 枚举值，不要写 `variant: "standard"`。多个控件优先使用该工具栏，紧凑工具栏须实测窄屏溢出。readOnly 会禁用控件，不能仅因 inline 数据自动添加。inline 控件变化不会自动过滤数据，必须明确标注未接通的行为；期间文字使用已应用筛选的显式引用。展示日期变化不证明重新取数成功。查询参数与展示参数分别声明；时间点绑定查询时给出合法窗口。

参考：[日期筛选完整页](page-metadata/examples/report-date-filters-page.json)、[期间文字](page-metadata/examples/report-filter-text-page.json)、[参数与文字](page-metadata/params-and-text-values.md)。

点击、详情与导航查[交互与导航](page-metadata/actions-and-navigation.md)。表格行字段、页面参数、当前筛选和固定值按实际来源绑定；验证目标 URL 与目标页接收值，再验证它们是否影响真实查询。静态校验不检查外部 URL 是否存在或目标业务是否正确。

## 尝试快照

每次完整 JSON 生成后、校验前运行[快照脚本](../scripts/snapshot-attempt.mjs)。省略目标目录时自动创建独立的系统临时目录；用回执中的 file 校验，保留校验回执与修复原因：

```sh
node "<skill-dir>/scripts/snapshot-attempt.mjs" "<page-file>"
node "<skill-dir>/scripts/validate-page.mjs" "<snapshot-file>"
```

需要持久保存时可传第二参数指定新目录，父目录须已存在，目标放页面扫描范围外；重复目录会失败。快照保留未经解析的原始字节（含错误 JSON）、SHA256 清单并设只读。修复只改工作文件，每轮新建快照，失败样本不得覆盖或由最终产物重建。`--check <snapshot-folder>` 核对当前字节与捕获时哈希；只读权限不等于操作系统级隔离。交付已通过校验的工作文件。

## 预览与修复

存在目标运行时与浏览器时，结构通过后预览实际工作文件及相关交互。整页创作检查宽度变化、容器卡面、图表与精确值的关系、主辅数值、变体前缀、长文本和末列；局部任务只覆盖受影响区域与关联交互。Report的容器归属与具体判断读取[PC章节组合](page-patterns/report-composition.md)。

发现可由自身页面声明修复的问题，继续调整并在相同视口复验。每次完整输出按前述流程先快照，再校验与预览；记录问题、修改及结果，不用最终产物重建首版。相关问题已处理时交付；能力或环境不足时保留明确未关闭项，不改产品、协议或校验器掩盖缺口。

独立评测仍允许创作者查看和修复自己的页面，只限制旧页面与评测答案等外部提示。首版结果和浏览器自助修复后的结果分别报告；缺少浏览器时说明视觉未验，不声称完成整套呈现验收。

## 错误定位与证据

从[校验模块](page-metadata/validation.md)读取错误类别，沿 JSON Pointer 找到最上游的错误声明，修复后重跑独立校验器。目录内 errors 文件是触发片段；只有 examples 中的完整页面可作为生成起点。文件名校验与单文档校验不证明跨页面业务正确。

若 pagedUnion 报“来源排序与合并比较规则不一致”，先对照实际请求排序与原始响应的相邻逆序行，区分主数值排序未生效和并列键比较问题；服务 SUCCESS 不证明排序执行。再核对来源 rowKey 非空且符合完整行粒度，例如人员×组织不能仅用人员作键。保留请求、最小逆序行对和重复/空键证据，回到查询适配或上游修复，再检查跨批连续性；当前批重排不能证明完整结果有序。

| 验收层 | 可用证据 | 不能据此声称 |
|---|---|---|
| 文档与文件名 | 独立校验器退出码及 JSON 回执 | 真实 DQE、视觉和业务口径正确 |
| 视觉与交互 | 目标运行时、实际截图、交互结果 | 外部服务或生产部署完成 |
| 数据与口径 | 明确的数据上下文、真实查询请求/结果与字段映射 | 其他身份或部署也已接通 |
| 线上交付 | 项目提供的实际保存/发布回执 | 本地文件已自动成为线上资产 |

缺少某层环境时说明未执行与所缺条件，继续完成可以验证的部分。无需为了文档生成主动接通生产服务或发送业务数据。
