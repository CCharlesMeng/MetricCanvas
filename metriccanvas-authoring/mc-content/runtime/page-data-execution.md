# 已有页面召回与刷新

已有完整页面仅更换实际参数或重新取数时，由集成程序调用共享页面数据执行入口。保持已有查询定义、查询结果绑定、字段契约、compute和组件；新的业务口径仍走数据分析流程。

1. 集成程序读取准确的完整页面文档。填参使用程序参数能力；实际查询条件改变时清除受影响源及其下游旧initial，同条件刷新保留。
2. 集成程序通过已部署的Node入口执行完整metadata，绑定当前调用身份和DQE配置。业务调用为execute(metadata)，返回只有完整metadata；模型不手工转录完整页面或拼接级联行。
3. 产物通过程序通道交给引擎。成功查询替换initial，失败保留旧initial；有initial直接显示，缺失由浏览器补查。既有数据存在不证明本次查询成功，收到完整文档也不表示已保存或发布。

该入口消费已有查询，不承担数据发现、查询生成、业务分析或保存。计算声明由引擎执行；调用结果不构成保存前计算验真。query详情继续点击后取数。部署未接入时报告已有页面刷新能力缺失，不把query_data冒充已部署的召回执行程序。

Node入口是集成程序能力，不是本Skill新增的MCP工具。沿用既有工具白名单；模型只消费集成程序提供的状态或摘要，完整metadata保持在程序通道。Relay部署方负责安装执行包和注入可信配置。
