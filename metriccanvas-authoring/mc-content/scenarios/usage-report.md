# 用量场景

从使用者关注的资源或对象开始：当前用量及有依据的变化可以同卡，再选择能解释容量、区域或模型使用差异的视角。只有被发现的指标、对象和维度可进入计划。

章节选型与PC检查使用[PC章节组合](../layouts/report-composition.md)：对象摘要、指标对照、分布精确值和趋势明细按阅读目的选取。数量变化仅表达增减时正绿负红，本期值保持默认颜色；业务方向另有定义时以可信字段语义为准。

按对象组合主辅值；没有受信变化关系时保留单值概况或独立指标。趋势、区域分布与明细是可选表达，不是必备章节。相同结果的趋势图和核对表可共存，后者须服务精确核对；不因存在表格能力就机械添加整章。
