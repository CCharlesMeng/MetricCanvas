# dashboard 创建与修改基线

面向持续监控、指标概览与多模块浏览。用户明确选择优先；用途不明确先澄清。创建前说明采用 dashboard，并显式传 layout。返回[公共约定](../platform-authoring.md)。

## 新建默认

自动 reportHeader 使用 plain 页头分区；内容模块采用缺省分区的组件卡面，模块标题属于 props.title。生成的分组标题需要独立表达时，用显式 card 共卡分区保留 section.title；单组件与分区同一标题可在新建时只保留组件标题。数据装配的不同口径标题不得丢弃。带图表且需保留分组标题时保留 panel：当前 card 会去掉图表单元格最小高度，不能为共卡默认牺牲图表可见性。

占满集成应用提供的宽度，不固定为某个屏幕像素值。布局仍使用共同12轨道/span，组件卡面与间距由统一运行时决定；当前容器760px断点转单列。columnTracks、connectPrevious和铺底安全区沿用共同机制。地图追加需满足工具的可见高度条件，缺省分区可提供该条件。

## 既有页转换

显式 set_page_layout 只切根形态并说明可用宽度、工具栏及响应式影响。保留已有 section.title、props.title、容器与组件布局，不能用新建默认替换旧页。dashboard + panel 是合法组合；多组件共卡保留原card和分区标题。铺底与窄屏回流不另造实现。

默认不是 dashboard=plain 的限制。出现真实非法候选时整项回滚，先说明错误路径及需要决定的调整；用户未要求的标题/绑定/查询/手工设置保持原文。
